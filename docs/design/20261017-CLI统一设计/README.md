# Roami CLI 统一设计 · 2026-10-17

当前方案：[统一架构与技术报告 v4](index.html)。完整技术方案、代码架构、CLI 目录整合、数据库和开工同步规则已合并在同一 HTML 中。

## 设计决策

- 一个应用核心 Go module、一个 `cmd/roami` 入口，原 `cli/ttmux-cli-go` 迁入内部领域与应用服务。
- Web 和 CLI 复用业务服务，完成态不内嵌第二个会话 CLI，也不通过子进程调用自身处理普通会话操作。
- Chrome 自动化归入浏览器模块，保留 Node、Playwright 和 Chrome 外部运行时。
- 内置插件并入根 module，外部插件通过公开 SDK 与既有协议扩展。
- 现有后端、提示模板、skills、安装与启停、插件、测试和 CI 调用全部迁移；以无旧独立 CLI 的干净 PATH 做主链路验收。
- 安装模式自有库统一在 `~/.roami/database/`；独立配置/数据根/数据库根，统一版本迁移、维护锁、完整备份与可恢复的旧布局切换。
- 新任务 worktree 必须基于本次成功 fetch 的远端固定 OID，失败停止创建和 Agent 启动。
