# 首页委派任务执行记录精简

## 产品设计

首页对话保留 Main 自身的调用过程、委派任务的主题与真实状态、最终结果和交付链接。委派智能体内部的工具调用不再生成单步提示或「执行过程」汇总卡；内部重试失败不再让首页出现与任务结果无关的失败提醒。

任务失败、状态未知、需要用户处理和 Main 回合失败仍按原状态展示。完整执行记录继续从任务详情展开。首页与项目 Main 共用聊天组件，因此采用相同的展示规则。

## 用户故事

- 提交委派后，看到提交调用、任务状态和交付结果，不被委派智能体的 bash 等内部动作打断。
- Main 自己执行的调用仍可展开查看输入和输出。
- 任务确实失败时能看到失败状态，并进入详情查看执行记录。
- 刷新、实时更新和手机访问采用同一规则。

## 技术设计

`agent-timeline.ts` 仅在聊天投影中排除带 `taskId` 或 `parentTaskId` 的 `kind=tool` 活动，沿用交付工具的过滤规则。任务归属由运行时提供，不依据工具名称、时间或执行成功与否猜测。`kind=task` 和 `kind=turn` 保留。

不修改活动快照、SSE 投影、缓存或记录接口。`AgentTaskRecord.TaskProcess` 继续读取原始任务活动，`AgentActivity record` 保留完整记录。没有新增请求、轮询、设计值或用户文案。
