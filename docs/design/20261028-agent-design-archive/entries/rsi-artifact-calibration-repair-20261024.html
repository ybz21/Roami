Product Design

实验页为记忆角色提供可选模型与推理强度；历史Run单列产物评分用量。未保存配置不能启动诊断。评分校准不满足时保留待评，问题列表不能因代码已修改就显示修复。

User Stories

维护者先审阅12项独立完整/缺陷样本，再运行双模型校准；每一分绑定原始证据。超时后先对账，避免重复费用。修复记忆截断和题面歧义后，查看同合同复测证据；题目修订单列为不可比较。

Technical Design

离线材料生成 → 人工参考 → 两个视觉模型 → 校准证书 → 固定7项产物评分
Run配置快照 → 独立Agent镜像 + 冻结渲染镜像 → 生成/评分分别计量
异常用量 → 阻止后续付费 → 请求ID对账 → 明确恢复
Issue证据 → 补丁 → 独立检查 → 同合同复测 → 连续日观察
