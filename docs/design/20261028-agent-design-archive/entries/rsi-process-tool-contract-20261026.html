执行工具的进程生命周期合同 · 2026-10-26

Product Design

工具说明明确既有生命周期：一次调用结束会清理其进程组。临时服务与客户端检查在同一次调用内完成，按已捕获的子进程 PID 清理，不按命令文本匹配进程。

User Stories

Worker 不再假定后台服务能跨工具调用存活，避免连接失败后反复改探针或用广泛匹配的清理命令终止自身验证步骤。

Technical Design 与验证

压缩并补齐 foundations 的 bash 和底层 shell 说明，保留工作区、授权主机操作、非沙箱、写入、取消、回执及托管资源边界；不修改 process.execute 的清理或权限行为。工具输入文本变化单列 container-uds-v7-process-lifetime，不能与 v6 混算同合同收益。

40 项工具、上下文边界和评测通道回归通过。零模型独立对照确认临时 HTTP 服务在当前调用内可访问，进程组清理后后续调用无法复用；服务器与客户端同一调用、按子 PID 收尾的路径成功，未作用于其他进程。对照只证明工具合同，不改写正在运行的 v6 真实案例或声称预算失败已全部解决。
