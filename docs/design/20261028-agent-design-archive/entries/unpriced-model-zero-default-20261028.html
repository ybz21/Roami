未配置模型单价按零使用 · 2026-10-28

Product Design

未配置单价的模型按零价兜底，不再因无费用回执被每日限额拦住。有效上游费用回执仍优先计费；已有非零单价、实际消费、历史估算与限额规则保持有效。零金额不因币种不同阻断后续调用。

User Stories

  • 不填写模型单价也能连续使用主、后台与记忆模型；缺用量、失败或流中断不会因默认零价锁住后续请求。
  • 升级后，旧的无单价未知账目自动按零价估算恢复，保留已有 Token、错误及失败状态；上游真实消费仍计入每日限额。

Technical Design

providers/model_billing.py 在准入时为没有单价的模型冻结当前限额币种的零价快照，结算优先采用有效上游回执，否则零价无需假设 Token 即可结算为本地零估算。model_pricing.py 提供零价判定，非零价格仍要求完整用量。恢复在原事务内处理缺快照或零价快照的未知记录，不改已有金额及历史估算，不新增 schema、接口、轮询或前端控件。
