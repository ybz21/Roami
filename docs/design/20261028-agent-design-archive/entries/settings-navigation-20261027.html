设置导航整理 · 2026-10-27

Product Design

移除常用页的重复入口，外观与语言回到界面分类，提问弹框留在新会话，推送归通知设置，语音按钮归语音输入。快捷键合为一页；移除状态条设置入口。统一记忆在设置内浏览，桌面始终保留左侧分类。

User Stories

用户能在对应分类找到设置，并一次查看全部快捷键；查看记忆列表、筛选与详情时可直接切换其他设置。手机沿用全屏二级页，先从详情返回记忆列表，再返回设置，保留搜索条件。

Technical Design

registry.tsx 统一分类、搜索和手机列表；route-hash.ts 将旧常用、状态条与更多快捷键链接映射到现有页面，设置记忆不再重定向首页。SettingsPage 的记忆区域固定可用高度，AgentMemory 的 embedded 模式省略重复页头；手机复用其已有 MobileSubPage 与路由返回行为，不叠加第二层返回栏或历史。
