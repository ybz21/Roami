首屏加载预算 · 2026-10-26

Product Design

保留现有页面、导航、消息徽标和加载反馈。非首页不预取主对话历史、任务及聊天页面模块；文件、会话和设置页面使用已有路由懒加载与失败重试。主对话可见时继续提前读取历史，历史分支由当前视图按需读取。

User Stories

用户打开项目或工具时，无需为尚未查看的聊天记录付出下载和缓存成本；进入首页仍可读取完整历史，切换设置、文件和会话页面保持原有入口与操作。

Technical Design

app/AppShell.tsx 根据路由控制 useAgentInbox 的 preloadMain；useAgentInbox.ts 保留主会话和通知请求及节点缓存隔离，移除页面模块的无条件预取。app/AppRoutes.tsx 将 FilesPage、Sessions、SettingsPage 接入 lazyRetry 与现有 Suspense；Projects 已因新建项目弹窗静态引用而进入首屏包，直接渲染以移除无效的异步边界。agent-data-cache.test.tsx 验证非首页徽标独立可用、打开主对话后才预取、慢通知不阻塞主对话。认证与节点引导顺序不变，不修改接口、刷新周期或历史分页语义。

验收记录

基线 f3622829。生产构建静态依赖闭包从 3,257,797 降至 3,010,849 字节（减少 7.6%），gzip 从 945,913 降至 883,881 字节（减少 6.6%）。受控生产包项目页验证少发两条聊天数据请求，500 条示例历史时避免约 1.09 MB 无关响应；响应大小随真实历史变化。现有 loading 为 Spin，动态页只有一个边界；活动页项目占位固定四行，未发现大体积骨架证据，保持现状。
