RSI源码文件交付修复 · 2026-10-25

Product Design

原生与专业任务显式生成的Python、TypeScript、Go等源码和脚本，与文档一样保留可下载原件。不同路径写法指向同一份产物时只展示一份，用户已删除的文件不因换用链接写法重新导入。

User Stories

维护者在Worker完成编码后直接取得代码与测试文件，Main可以用真实产物回执交付，不因后缀不支持误报缺文件、重复检查工作区或重新派发任务。

Technical Design

NativeExecutor / 任务详情 → TaskDeliverables
→ 工作区输出后缀白名单 + 原有no-follow读取
→ 文件链接解码后的sourceFile去重；兼容旧sourcePath
→ 私有ArtifactStore → 已归属任务的artifactRefs → Main任务结果

目录边界、隐藏文件、符号链接、文件类型、体积、所有者和删除保护继续由已有读取与存储协议校验。sourcePath保留原始证据；sourceFile只作当前尝试内的别名归一化，不能把字面百分号与空格文件名混同。历史成绩与产物评分要求不变。

验收：83项定向回归、Native机制20/20及整仓full门禁通过，运行时共1289项。相同v11合同的真实CODE-01再次通过，app.py与test_items.py各保留一份可下载产物，不再出现TASK_RESULT_REQUIRED与WORKSPACE_REQUIRED；14次请求、69,373 Token，前一轮为16次、79,420 Token，单次差异不证明稳定节省。另对原DOC-05与DEMO-01产物执行无模型调用的独立硬检查与渲染；两项仍待评分，方案图存在文字裁切。人工校准参考分尚未确认，Issue #446保持开放。证据和源码产物位于/tmp/roami-rsi-source-report/；未提交或部署。
