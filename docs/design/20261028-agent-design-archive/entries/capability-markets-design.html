开放能力市场与 MCP 传输接入 · 2026-10-23

产品设计

能力中心新增“市场”，首批接入 skills.sh、官方 MCP Registry 和 npm。来源可启停、编辑服务地址，或新增兼容相同接口的来源。搜索按用户操作发起；结果展示名称、摘要、版本，查看时解析真实配置，再进入现有可编辑确认表单。导入成功后在 Skill、MCP、CLI 原分类管理；保留来源、固定版本和 Skill 附件，不覆盖重名项。MCP 不因浏览或保存而启动；CLI 明示首次调用由 npx 下载固定版本，参数使用 args 数组。

MCP 的本地程序、SSE、Streamable HTTP 三种传输均可新建、编辑、导入、连接和调用。type 与 transport 冲突时拒绝导入；保留现有 HTTPS、凭证环境变量引用、取消和连接生命周期边界。手机详情与来源配置复用全屏 MobileSubPage，表单滚动和保存栏沿用现有令牌。

用户故事

  1. 我能搜索公开技能，查看上游来源和固定提交，确认后保留指令、引用文档、脚本和附件，重启后继续使用。
  2. 我能从官方 MCP 目录选择 SSE、Streamable HTTP 或支持的 npm／PyPI 本地程序配置，修改名称、参数和凭证环境变量引用后保存，再显式连接。
  3. 我能从 npm 查找具有命令行入口的软件包，固定版本并注册；普通库没有入口时给出明确提示，不假装可调用。
  4. 我能停用市场来源而不删除已导入能力；主 Agent、后台工作 Agent 与平台派发的 Codex／Claude 任务共用已安装能力和停用策略，专业任务也能读取 Skill 附件和调用 MCP／CLI。
  5. 我能在手机完成市场搜索、来源配置、详情、确认导入与返回，失败保留输入和最近结果。

GET／PUT /api/agent/capability-markets 管理来源，GET /api/agent/capability-markets/{source}/search 按需搜索，POST /api/agent/capability-markets/preview 获取待确认导入项。来源配置私有文件 0600，原子替换；禁用来源拒绝新查询。目录请求最多四个并行，合并同请求、缓存一分钟，不新增常驻轮询；关闭运行时取消所有目录请求。

GitHub 技能按固定提交下载，拒绝符号链接、路径穿越和冲突路径，最多 100 个文件、384000 字节，保留仓库许可证。附件随注册数据保存，运行时只读副本按内容散列放在节点 agents/capability-packages 下；旧版本保留以免破坏正在运行的任务。单个带附件的 Skill 请求最多 600000 字节，总目录仍最多 1 MiB。脚本不在导入时执行，后续运行继续经过已有工作目录与进程权限边界。npm 只从包元信息中的 bin 登记命令，固定版本并以 argv 数组调用。

平台主 Agent、后台工作 Agent 和托管专业任务使用同一注册表。Codex／Claude 任务通过任务级 CLI 入口读取 Skill 和引用、发现 MCP 工具、调用已注册 MCP／CLI；不用为各专业程序另装一份能力。专业程序原有的全局配置继续由其自身管理。Docker／MCPB 和需 OAuth 的条目不伪报已接入；不支持的包装格式明确报告。

每次专业派发生成 0600 上下文文件，服务端以节点私有密钥签名；提示仅包含路径，不包含签名。上下文绑定所有者、任务、尝试和版本，取消、完成、来源忘记、排队改派或预算到期即拒绝新调用。只允许 Skill 读取、MCP 发现和外部注册操作，不借此开放内部调度工具。执行期间持续复验任务状态，撤销时取消底层操作。

请求号在执行前原子登记到已有事件存储；相同号和参数返回原回执，不重跑。参数冲突拒绝，进行中或进程重启后的未完成调用保持未知结果，不能自动重放。每个任务最多 1024 次登记、每节点最多 16 个并发、单次最多 90 秒；CLI 等待预算为 100 秒。完成结果与失败进入任务执行记录，主聊天仍只显示任务进度和可行动阻塞。

CLI 与 Roami 自主接入 · 2026-10-23

终端增加 roami agent capability market sources／search／preview／install，JSON 参数与现有命令族一致。主 Agent 与普通 Worker 通过同一动态 CLI 目录按需发现；专业任务可使用自己的 --context 与 --call。研究只读角色不开放安装。市场指令与描述作为待审阅数据，只有用户要求安装时才执行 install。

server/market_installations.py 保存最多 32 份、十分钟有效的固定版本预览，CLI 只返回说明摘要、附件名和完整配置，不把附件 Base64 放入模型上下文。安装以 previewId／option／可选 name 选择原包，复用托管注册、名称冲突和原子保存；失败保留预览。来源停用或改址、预览过期均拒绝继续安装；相同选择重试返回同一回执，被编辑或移除后报冲突。sources／search／preview 为读取，install 为写入，沿用当前调用上下文、任务撤销和执行记录。MCP 保持未连接，CLI 首次调用下载的规则保持一致。

实现模块：tools/market_commands.py 注册按需工具；commands.json 维护公开路径；cmd/roami/agent-market.go 同时服务普通终端及已绑定的 Agent 调用；POST /api/agent/capability-markets/prepare 与 /install 复用登录网关。平台常驻模型 schema 数量保持原有基础工具集合。
