Agent 模型下拉选择 · 2026-10-22

产品设计与用户故事

四类 Agent 的模型字段统一为可搜索、可手动输入的下拉框，保留已有模型和未保存输入。用户可点击“获取模型”，按当前服务地址、协议和密钥读取真实模型列表；修改连接信息后清空旧服务返回的候选，失败保留模型选择及表单。服务不支持列模型时允许继续输入自定义模型。

技术设计

AgentModels.tsx 复用 antd AutoComplete，候选来自同服务已有预设和显式查询结果。新增 POST /api/agent/professional/:kind/model-options，复用预设私有密钥和输入验证；按协议读取 OpenAI / Anthropic 兼容的 GET models，Anthropic 支持分页。请求有时限、响应和条目上限，不跟随重定向、不返回上游错误正文、不执行模型推理，不新增轮询或隐式应用。网络读取在预设锁外执行；变更连接会取消旧请求并丢弃过期结果。
