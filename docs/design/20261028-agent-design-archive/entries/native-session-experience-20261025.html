产品设计

项目列表的本地智能体复用专业会话的图标、单行标题、状态、时间和平面分隔线，整行进入会话。详情使用紧凑身份栏与对话／执行过程／产物三个入口；长用户需求收为三行，可显式展开。底部统一输入卡跨入口保留草稿并续接原任务，失败不清空，关闭仍需确认。

产物页先显示真实任务结果与验收状态，再列文件。按当前执行／历史执行分组，提供名称、文件类型、大小、生成时间、预览和下载；无执行归属的文件单列，不猜测版本。图片、PDF、PPTX、文本和 HTML 复用安全预览，其他格式保留下载。手机预览是全屏二级页，返回原产物列表；无法留存的文件明确提示。产物存在或执行器声称完成都不改写任务状态。

用户故事

  • 用户在同一项目中能像打开 Codex 一样识别和打开本地智能体。
  • 用户直接在会话中查看中间输出和工具调用，展开查看结果，再追加要求，沿用原任务与会话。
  • 用户可以区分本次与旧版文件，在手机预览、返回并下载，不会把旧产物误认作本次交付。

技术设计

NativeProjectSessions → 既有 native-sessions 目录与 session 路由
NativeSession → useAgentTask + native conversation + 原任务 steer
  → TaskProcess / TaskResult（按需读取执行记录）
  → NativeSessionArtifacts → TaskArtifactPreview / MobileSubPage
NativeConversation → ChatMessage / ToolRun / ToolView + TaskDescription（三行用户正文）

复用既有节点感知接口、版本号与幂等请求键、草稿持久化及任务变更事件。沿用既有端点，补齐会话的工具消息与状态，不新增结束任务轮询。产物合并目录与 delivery 后按 ID 去重，按 metadata.runId 区分执行。页面使用既有主题、国际化、SVG 图标和输入卡样式。验证覆盖续聊失败和重试、过程按需加载、产物分组与预览、结束后不轮询，以及桌面和 Android 真触控、键盘与返回。
