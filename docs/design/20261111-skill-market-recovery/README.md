# 技能市场失败恢复

## 产品设计

市场暂时加载失败时说明网络、当前节点智能体服务或市场来源的已知错误，保留一处「重试」。错误码与 HTTP 状态放在可展开的错误详情中，不展示原始服务消息。

重试恢复失败的操作，包括首次榜单、榜单切换、搜索分页和技能详情；保留已有结果、输入草稿及成功榜单。搜索结果的返回箭头位于标题左侧。

## 用户故事

- 首次榜单失败后，即使已经输入下一次搜索草稿，重试仍加载原来的榜单。
- 详情加载失败后重试打开原技能，返回时焦点恢复到原来的入口。
- 下一页失败后重试续接原搜索的分页，不清空已有结果。
- 可以区分当前节点不可达、节点智能体服务不可用和上游市场错误，并展开错误码辅助排查。

## 技术设计

`CapabilityMarket.tsx` 将错误信息和失败操作快照保存在同一状态中。快照明确区分来源发现、带来源/查询/游标/榜单的列表请求和带来源/条目的详情请求。重试按照快照分派，不读取尚未提交的输入。新请求、来源切换或成功响应清除旧错误；取消的旧请求不能发布错误或覆盖结果。不自动重试安装写入，不增加轮询。

`market-error.ts` 优先读取 API 的结构化 `error.code`，兼容旧的错误码消息，为网络失败和未知错误提供页面相关提示。诊断仅接受受限格式的错误码与有效 HTTP 错误状态，不直接展示服务消息。两份语言包同时提供新文案。
