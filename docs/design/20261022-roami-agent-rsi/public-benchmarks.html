4. 建议的接入方式

  1. 第一批以SWE-bench Verified、Terminal-Bench、TheAgentCompany、DSBench和LongMemEval建立编码、工程、办公、分析和记忆基线。按测试机能力挑选可复现子集，冻结题目清单与上游判定器，报告为内部子集结果。
  2. 再扩展PPT/表格、AgenticVBench、GAIA/BrowseComp和MLAgentBench，分别补媒体、工具研究及前沿实验；不能因为某任务需要更大环境就静默跳过后仍宣称全面覆盖。
  3. FinQA/ConvFinQA作为金融推理组件基线；新闻时效和策略研究继续用点时数据与独立oracle，不以短期涨跌判定Agent有效。
  4. 逐项记录benchmark、upstream_sample_id、split、dataset_revision、input_hash、environment_hash、grader_revision与改造说明。保留上游原生分数，额外测Roami端到端效果、时间与全链路Token。
  5. 公开题与自建隐藏题分开；官方测试题不进入经验提取、候选反思或选择策略。对公开训练/开发题可以优化，但正式比较使用未参与调参的任务并记录暴露情况。
