模块实际能力边界
contracts.py / sampling.py冻结 suite、分层抽样、版本与哈希；FinQA / ConvFinQA 导入只导出正文、表格与问题给 Agent；不是官方完整榜单
executors.py真实 Runtime 文件任务；外部 worker 请求 / 响应、超时清理文件模式不开放 shell 或现用会话；外部环境仍需实际适配
measurements.py所有模型角色共用 episode 预算；调用、重试、观测 Token、过程耗时未来维护成本不伪造为0；完整 Token 未知则阻止晋级
grading.py数值 / JSON 独立断言；双评分人盲评、分歧待复核客观通过不替代 PPT、视频的视觉质量
comparison.py基线通过保护、独立 cluster bootstrap、私有验证 / 隐藏集门槛小样本、夹具、未知用量和不受控缓存不能晋级
policy.py记忆条数 / Token、上下文保留量、目录页大小四个有界参数单因素候选；权限、角色、评分器与隐藏数据不可修改
ledger.py / cycle.py / cli.py私有SQLite账本、原子日预算、同机同日不重跑、A/B随机顺序、独立每日worker不自动重放中断工作；暂不回收预留预算
status.py / Go 网关登录后按 owner 读取周期摘要摘要不返回隐藏输入、完整输出或参考答案；首页面板未实现

当前默认参数保持原行为，只有隔离实验应用候选。完整模块入口在 agent-runtime/src/roami_agent/improvement/；命令与机器配置见 运行手册 与 scripts/dev/agent-evaluation/machine.example.json。

与完整设计的阶段差异：当前使用独立私有账本与独立长期worker，标准、机器和策略以冻结manifest保存；尚未迁入主运行库的跨机任务状态机。先验证执行、成本和失败边界，后续再接入跨机调度与发布恢复。
