RSI 设计修订与验收记录

Worker 工作区图片快照 · 2026-10-29

Product Design

视频失败记录中，Worker 已生成帧图，但 read 只返回元数据；后续用 ASCII 与计算机视觉脚本猜画面，30 分钟后仍没有交付。为图像模型补充受限工作区读取：原 read 工具首次读取静态 PNG／JPEG／WebP 时保存不可变快照，在下一次模型请求临时附上像素。Main、文本模型和未绑定任务的读取仍只有元数据；不增加 Token 配置或改变节点模型选择。

User Stories

  • 视觉 Worker 可以查看自己工作区的帧图、图表或合成联系表，继续完成原任务。
  • 我可以核对原文件哈希和模型实际收到的尺寸；文件、历史 Case 与原判定标准保持原样。
  • 另一用户、另一任务、已结束或被取消的运行、伪造工具回执、越界及符号链接都不能提供像素。删除或遗忘快照后，不再开始基于它的新模型或工具调用。
  • 读取帧图属于执行证据，不自动变成最终交付物；真正交付仍按原任务及独立验收判断。

Technical Design

模块职责
storage/workspace_files.py沿既有目录描述符、O_NOFOLLOW、普通文件与源哈希检查，增加有大小边界的快照读取。
tools/workspace_images.py校验活跃 Worker、任务修订、运行与原生分支，验证静态图片及文件未变化，保存 owner／task／run／turn／tool 绑定的原图 artifact。
context/workspace_images.py从真正成功的 file_read 回执定位图片，重新检查绑定、删除及遗忘状态，按 Worker 模型页图片限制准备瞬时模型输入。
vision_inputs.py、app.py、model_settings.py保留浏览器观察链，按最新图片来源选择一个快照；模型配置切换保留显式能力检查。
artifact_store.py将工作区观察与浏览器／电脑观察一样排除默认交付列表；明确引用时仍可作为所需材料展示。

复用原 read 权限和 schema，不增加权限或传输端口。原图只保存于私有 artifact，source SHA 保留原文件身份；图片缩放、编码和 Base64 仅在模型边界发生，对话与 prompt manifest 只保存来源引用。模型输入最多保留最新一个图片来源，文件快照不提供浏览器观察 ID、资源租约或 UI 操作坐标；坐标动作仍走原活资源授权。

源图片最多 32 MiB，并服从更小的 artifact 存储限制；像素沿用 6400 万边界，输出沿用模型页角色图片限制。损坏、动画、不支持格式、源变化及读页偏移不提供视觉快照，不把旧图片当新图片。原文件不修改，原 Case、判定器、质量门槛与模型页每日准入不变。

验收记录

81 项定向检查通过，其中 31 项新增回归；旧版三种图格式反例均失败，新版通过。定向覆盖 PNG／JPEG／WebP、缩放与哈希、原生循环的真实像素、引用式存储、单个最新快照、非视觉路由、禁用 read、跨 owner／run／turn／tool／artifact、撤销与遗忘、旧修订、符号链接／FIFO／越界、源竞争变化及默认交付排除。初始原生循环测试缺少 fixture 的 created_ms 已修正，旧日志保留；不据协议夹具宣称真实模型或视频任务通过。真实网关探测、原任务复测、完整门禁及截图随本次 PR 留证。

真实探测只使用独立合成图片；视频复测保持原输入与判定，若使用不同 Worker 模型会明确记为独立模型／执行协议实验，不保存节点配置、不作为同条件优化收益或全套通过。人工参考与校准缺项另行保留，不把模型生成的标签当作人工确认。
