RSI 设计修订与验收记录

模型桥接传输与错误留证 · 2026-10-29

Product Design

RSI 的私有模型桥接应容纳产品已经支持的图片及其编码开销。模型请求继续使用模型页已有连接和统一每日限额，不增加 RSI Token 配置。执行失败后，运行结果保留桥接拒绝的代码和次数，供排查多轮共性；最终超时仍如实记为超时。

User Stories

  • 符合现有图片大小与像素限制的 PNG，不会仅因 Base64 编码超过旧的两百万字节限制而在到达模型前被拒绝。
  • 运行最终超时后，我仍能从问题汇总看到此前发生的传输拒绝；拒绝不会被计成已发送的付费模型请求。
  • 错误详情不回显请求正文、图片、密钥或异常中的私有地址。

Technical Design

integrations/model_gateway.py 将请求正文的有界传输上限改为 16 MiB，独立将请求头限定为 64 KiB。原有二十秒读取期限、私有 Unix socket 和宿主凭据隔离保持有效。无效 JSON、非对象 JSON 和过大请求头返回明确错误码。领域异常代码通过已有 public_error_code 规范化，不存异常正文。

evaluation/execution/containers.py 在退出桥接上下文后，将错误代码及聚合次数写入原有私有 model-log.json，包括超时路径；主失败原因和模型计量保持原义。evaluation/trial_evidence.py 把这些错误加入既有 signals，后续运行结果及问题聚合复用原链路，兼容缺少该字段的旧日志。没有新增数据库结构或界面。宿主执行协议升为 container-uds-v28-image-transport-evidence，避免新旧执行合同混作同一模型配置；子镜像协议无需变更。

验收记录

八项新回归在原 339c2f89 代码下全部失败，修订后通过；相关定向共 52 项通过。第一次超时测试使用 HTTP 客户端发送与 Content-Length 不符的空正文，被客户端自身拒绝，已改为真实 Unix socket 请求后重新验证，原日志保留。合法随机 PNG 小于 2 MiB，编码请求超过两百万字节；检查宿主收到的消息与原消息完全一致。另验证非对象 JSON、无效 JSON、过大请求头、异常脱敏，以及两次传输拒绝后超时仍保留次数且模型调用为零。

冻结 v31 容器在无网络、只读文件系统与无权限提升条件下，经实际 Unix socket 成功投递同一 PNG。仅使用脚本化宿主模型，外部模型调用为零，容器已按身份清理。证据为 /tmp/roami-rsi-gateway-transport-proof-20261029/proof.json，前后回归日志为 /tmp/roami-rsi-gateway-transport-before-corrected.log 与 /tmp/roami-rsi-gateway-transport-after.log。完整门禁结果随 PR 留证。
