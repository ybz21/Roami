股票报告的五个图表页检查 · 2026-10-29

Product Design

原任务要求五张图分别放在各自页面，没有禁止封面、说明页或可编辑图表。结构检查按含图的不同页面计数，至少五页；支持图片、原生图表、图片占位符和组内图片。它只检查结构，图是否正确、解释和视觉质量仍须独立评分。CSV 原检查、浮点容差和历史成绩保持不变。

User Stories

  • 我可以保留封面与总结页，不再因为整份超过五页被拒绝。
  • 我可以交付可编辑的图表，而不必为了验收把图转成图片。
  • 同一页放五张图、只增加文字页、少于五个图表页仍不满足结构条件；数据不符仍失败。

Technical Design

evaluation/benchmarks/stock_tasks.py 在原隔离判定程序中增加 plot_slide_count，沿 python-pptx 的 has_chart、image 属性及组 shapes 递归识别含图页。以 five_plot_slides 表达结果，替换附加的“总页数等于五且每页有顶层图片”条件。改动留在评测层，不增加工作流、存储、服务或展示层分支；原交付快照、文件哈希、远端上传及源文件保护检查继续执行。

原 CSV equality checkpoint、adapted_csv_values 的 schema／types／row order 与 rtol=1e-12、atol=1e-10 不变；hard pass 后仍 pending_score。评测源码纳入既有 judge_hash，不能将本次评测修正算作模型优化收益，也不能与旧版总成绩拼接。原任务依据为 冻结版本公开任务；形状接口参见 python-pptx 文档。

验收记录

31 项定向检查通过，其中 9 项新增回归覆盖四种图形载体、附加页、少图页、同页多图、纯文字页，以及真实容器中正确和错误 CSV。正确数据加合格结构仍只进入待评分；错误数据保持失败。原完整轮次的股票报告经复制沙箱零模型复核，8 页中 5 页有图：结构由 false 改为 true，CSV 仍 false、总判定仍失败，原生 CSV 分仍为 0/8。原文件、Case 行与轮次状态／总结不改写，补充证据在 evaluate/stock-plot-structure-recheck.json 单列。

额外只读检查确认列名集合不一致、解析后的日期亦不相等，不能把 CSV 失败概括成仅显示顺序差异。证据为 /tmp/roami-rsi-stock-structure-proof-20261029/proof.json 与 /tmp/roami-rsi-stock-date-inspect.json；两项复核均为零模型调用。完整门禁与合入证据随 PR 保留；本次没有产品界面文案、模型调用、现用服务部署或自动日程变更，AGENTS.md 保持精简。
