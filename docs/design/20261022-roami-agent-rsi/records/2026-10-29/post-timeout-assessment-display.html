区分超时运行与产物核验

Product Design

Case 详情先说明核验发生在执行超时后，以及该次运行仍未通过，再展示已有产物的真实分数。产物达到阈值也不覆盖运行超时。核验失败保留未评分，具体错误放进默认折叠的执行记录。

User Stories

  • 我能区分整次任务失败与已有产物的核验结果，不会把局部高分当作运行通过。
  • 我可展开核验错误排查；正常核验不增加无关提示，基线和候选各自显示自己的来源。

Technical Design

RsiCaseEvidence 只接受严格布尔 artifact_assessment_after_timeout；复用既有事实列表、执行记录折叠、中英语言包与样式。无分数时也保留核验时机；native_verifier_ran=false 时继续抑制伪分数。artifact_assessment_error 仅在超时后核验中、且符合后端公共错误码格式时出现在执行记录，不增加请求、轮询、入口或布局。
