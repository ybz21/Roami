RSI 统一限额与交互用量 · 2026-10-27

Product Design

RSI 以概览、运行记录、设置三个 Tab 区分查看与配置。概览首先显示共用的今日记账与每日费用限额、运行入口和最近结果；执行流程只在具体运行中查看，问题与技术细节按需展开。设置集中每日评测、测试机与自动处理，独立模型放在可选折叠项；移除 RSI 每日／每次 Token、生成和输出额度控件，费用统一由模型页管理，保留标准模型能力、执行超时与取消。多段设置以同一保存入口提交，部分失败保留输入及已成功保存的新修订号。

User Stories

用户不再为 RSI 和模型页维护两份预算；原生生成、记忆、评分与 Codex 复盘均进入当前节点同一本账。每日趋势和分时图使用 ECharts 堆叠柱形，鼠标悬停显示精确值，点击或触屏点按后保留总计及分模型明细，可继续查看当天分时。键盘用户可通过日期／时段选择器访问相同数据，未知费用与本地估算仍明确显示。

Technical Design

model_proxy_context 只绑定 RSI 执行任务，configured_provider 在该作用域接入既有 ModelProxy，跨角色模型与容器内 UDS 请求由宿主代理准入及结算。Codex 以明确模型身份和完整回合用量进入同一准入锁、价格快照、费用估算与未知状态流程；重复的已完成操作不重复记账，缺失回执不假设免费。旧 RSI Token 配置与账本保留作历史证据，现代运行不再以其作为费用门禁；测试语料、复测身份、未知操作不重放和独立验收约束保留。

本段为 #464 的原实现记录；合并后的 RsiWorkspace 管理统一草稿与三个 Tab，RsiRunResults 保留真实运行记录和按需产物，见 RSI 简化方案的合入修订。ModelUsageChart 惰性加载 usage-chart-renderer，只引入 ECharts 柱形、坐标轴、提示和 Canvas；独立 usage-charts 构建块避免进入首屏。颜色、字体、空间和主题取现有令牌，点击明细保留 React 可访问文本，不依赖悬停提示或画布读取。
