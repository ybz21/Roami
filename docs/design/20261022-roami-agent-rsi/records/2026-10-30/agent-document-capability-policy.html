Agent 文稿准备遵守执行能力策略

Product Design

自动准备只读取允许的输入，只注入当前可用的内置工作流。执行器收紧能力后，后续请求停止注入已禁用内容。内置能力在产品页仍为只读；本修复针对运行时执行器的能力过滤，不新增设置开关。

User Stories

  • 任务执行策略禁止 read 或 file_read 时，自动 PPTX 准备不能绕过显式工具调用的拒绝。
  • 仅禁止 skill_read 或 presentation_files 时，允许的文档数据仍可使用，禁用的工作流不能自动进入系统消息。
  • 策略集合在任务中被替换后，同一 intake 在下一轮提示投影时立即采用新策略；已经发出的请求不声称撤回。

Technical Design

Runtime 向 context/document_intake.py 传递 Tools 注册表，而非只传 Skill 字典。准备前、文件循环和最终投影查询当前策略；读取 await 中收紧策略会停止后续文件读取并丢弃自动准备结果。每次 attach 再检查当前文件权限及工作流策略，不复用已失效的工作流缓存。文件读取仍通过 tools/workspace_presentations.py 和 storage/workspace_files.py 的工作区边界。关闭读取不撤销其他独立工具，也不新增限额。
