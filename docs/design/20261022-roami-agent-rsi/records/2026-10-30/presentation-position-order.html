Agent 演示文稿位置与绘制顺序

Product Design

文稿读取分别展示原始绘制顺序和幻灯片中的位置。定位“第一个文本框”时检查位置和内容，不能把 XML 中先绘制的正文当成排在上方的标题。缺失、继承或无法换算的几何不伪造顺序；结构边界不声称已渲染或识别重叠、可见性与语义阅读顺序。

User Stories

  • 文本标题在上但绘制在正文之后时，可以观察两种顺序的区别。
  • 组合的局部坐标经过缩放、旋转、翻转及嵌套后，与同一幻灯片中的其他文本框可比较。
  • 读写后保留稳定 shapePath 与原 ordinal，位置未知时继续检查原生应用，而不是猜测目标。

Technical Design

documents/presentation_geometry.py 只换算显式 DrawingML 仿射变换和边界；documents/presentation.py 保留解析、对象身份及段落，新增 slideBounds、坐标单位、objectOrder 和 topToBottomPaths。位置列表只在全部非空文本框有边界时给出，按上边界、左边界及原序号稳定排序；局部坐标和原 shapePath 不变。tools/workspace_presentations.py 与 context/document_intake.py 复用原读取、作用域、哈希及分页。内置 presentation_files 工作流区分绘制顺序和位置。

组合坐标中 chOff、chExt 的含义参考 python-pptx 原始开发文档。变换覆盖平移、非均匀缩放、旋转、翻转与嵌套；位置缺失或无效时保持未知。

Acceptance
