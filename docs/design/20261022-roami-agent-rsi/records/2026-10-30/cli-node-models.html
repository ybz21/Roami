RSI CLI 继承节点模型与每日限额

Product Design

独立原生评测与校准命令统一使用节点保存的模型配置和现有 Go 网关每日金额限额。运行入口不能再因遗漏模型页设置而调用旧模型、截短输出、关闭重试或使用校准文件自带的评分模型。缺少网关绑定时在推理前阻断。

User Stories

  • 修改模型页后，CLI 使用相同的 Main/Worker、参数、能力、上下文窗口和重试。
  • 真实评测不必另填 Token 或调用次数预算；旧预算不能成为第二道限制。
  • 离线协议夹具仍能独立运行，失败和未知调用不能自动重放；缺少人工标签或独立评分能力仍不能生成证书。

Technical Design

entrypoints/node_models.py 负责检查 ROAMI_MODEL_GATEWAY_SOCKET，并复用 load_runtime_model_settings 加载 TOML、私有模型页设置和自动容量。CLI 原生 cycle/watch 将账本及 NativeFilesExecutor 绑定 shared_daily_limit；原生执行器在该模式返回零 Token 预留，冻结评分和执行时限不变。calibrate-artifacts 显式接收 --agent-config、--data-root，沿 configured_provider 和 Go 传输，证书标记 live_models，忽略旧 --token-limit；配置文件中的评分模型不覆盖节点路由。离线 protocol_fixture 保留旧协议预算；无法证明模型与账本绑定的 external 模式在启动前拒绝，与正式工作流一致。未改变服务部署、日程或节点配置。
