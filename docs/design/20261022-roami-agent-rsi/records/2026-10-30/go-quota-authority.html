Go 网关统一模型额度与用量记录

Product Design

模型页的本地 Go 网关是 RSI 与 Agent 唯一的模型额度准入者。RSI 不再分配 Token、请求数、独立每日金额或按日/小时模型评估次数，不再缩减保存的输出参数或重试。Case 新格式无需填写 Token 与请求次数；旧字段保留读取兼容，不能限制调用，也不传给模型。主动消息的通知频率和静默偏好仍由原来的投递策略管理。

User Stories

  • 旧配置中的额度为零、旧预留已满或其他操作用量未知，都不成为 Python 再次拒绝调用的理由。
  • Go 返回额度不足或用量待处理时，按原错误停止；缺少本地网关不能绕过它直接访问上游。
  • 同一笔未知操作不重放；其他独立操作交给 Go 判断。未知用量保持未知，不写成零，也不把历史账目清空。

Technical Design

domain 删除现行配置中的旧额度与 RSI 模型覆盖项，兼容键只接收后忽略；integrations 仅记录调用、已知用量下界与未知覆盖，不做准入或提示剩余额度；persistence 保留操作身份、幂等与未知操作保护，零预留且不修改旧 rsi_budgets；workflows 继承节点模型和 Go 传输，Codex 仅使用操作级 Go 桥接；providers 缺少绑定时在传输前拒绝，历史 Python 计费适配器仅保留记录能力。

执行镜像协议升级为 org.roami.rsi.shared-daily-policy=6，模型运行拒绝仍可能自行限额的旧镜像；无模型的渲染与判定仍使用原有固定镜像。旧正式 Case 与评分门槛、原生判定程序、执行期限和观察要求保持原合同；没有重写历史成绩或启用正式日程。
