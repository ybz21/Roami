RSI 自动绑定本地网关与计费核对

Product Design

独立 RSI 调用只选择本地节点，由 Go 解析该节点的私有模型网关。脚本无需设置网关 socket，也不新增上游地址、凭据、模型或配额表单。缺少网关时在推理前停止，不能绕开计费。业务页面不展示这项传输绑定。

User Stories

  • 从本地节点保存的模型设置运行 RSI，并能在 Go 账本逐笔核对消费。
  • 同时处理两个节点时，各自使用自己的网关，不受另一个节点的环境变量影响。
  • 区分代码回归、真实模型运行和正式日程，只有真实请求产生模型消费。

Technical Design

Go 的 agent gateway binding 复用 agentruntime.Resolve 与 modelgateway.Socket，按 --data-root 选择已有实例，校验 socket 类型、0600 权限与当前属主。结果仅含本地 socket 和实例身份，不含上游凭据。node_models.py 调用此只读命令，并通过内部 Settings 字段将连接传递给 configured_provider；没有写入进程环境或模型页配置。local_gateway_client 保持显式绑定优先于继承环境。原有模型参数、能力、重试和额度仍继承节点，业务配置接口不增加字段。
