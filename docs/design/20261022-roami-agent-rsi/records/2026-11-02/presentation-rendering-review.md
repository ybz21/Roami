# 演示稿字体预检与真实股票任务复核

## 产品设计与用户故事

用户需要可读、有依据且完整响应原题的演示稿。成功生成PPT、文本框未溢出或远端文件存在，都不足以证明它可用。实际任务复现缺失字体被替换为等宽字体后字距异常；同时，标题与讲稿中的错误推断依然存在。

本批在外挂 `presentation-design` 中增加渲染环境字体预检，保留用户明确指定字体的选择权；复核准则明确检查标题、图注与讲稿的一致性。PPT能力继续留在Skill，不向Agent核心加入专用工具或依赖。

## 技术设计与模块

- `skills/presentation-design/SKILL.md`：在生成前用实际渲染环境的 `fc-match` 确认字体解析；没有明确字体要求时选择环境支持的字体。必要字体不可用时报告限制，不静默替换。
- `references/slide-review.md`：字距也属于版面质量，注释中的免责声明不能抵销标题中的错误结论。
- [PUBLIC-20补充复核](../../../../../cases/case-60-public-20/acceptance.md)：冻结输入、原题及原判定器保持，增加最终远端文件重渲染、字体、口径和原题图表覆盖的复核入口。没有新增计入正式套件的题目。

没有Agent Python核心改动。三次任务使用同一冻结Actor `sha256:db9379a43dacf2c5ee5fc185a30d74f4d0c914c8c51be3f3e41e9d2af3ac708d`，204个Actor Python文件与当前源码逐一匹配；其中的旧Go程序不代表#587已经部署。外挂包仅注入各次隔离验收环境，没有安装到正式节点。模型、参数、能力、重试及Go每日额度沿用保存配置。
