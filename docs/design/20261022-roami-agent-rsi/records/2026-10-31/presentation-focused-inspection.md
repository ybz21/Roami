# 演示文稿单页检查与命名颜色

## 产品设计

用户只修改一页时，读取该页的全部对象和编辑器调色板，不用先消化整份文稿的对象列表。命名颜色通过既有names-only命令解析，不混入猜测RGB。完整文稿读取仍可用；结构检查不代表GUI或视觉质量通过。
