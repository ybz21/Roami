# 前台Agent Runtime的父进程生命周期

## 产品设计

前台`roami agent serve`启动Python Runtime后，Go父进程被终止会留下后台Python进程。它继续占用源码目录和数据锁，导致清理worktree后仍有孤儿进程。

前台入口复用Web监督器已经使用的父管道协议。父进程的文件描述符关闭后，Python通过既有`--parent-fd`监听正常退出。初始化短命命令不增加父管道，不触碰另一个已运行实例，不停止独立CLI任务。

## 用户故事

- 结束自己启动的前台服务时，其Runtime也结束，不遗留后台进程。
- Go父进程被TERM或KILL终止时均能释放所拥有的Python进程。
- 其他节点与用户会话保持独立生命周期。

## 技术设计

`cmd/roami/agent.go`仅在前台服务路径创建管道，将只读端作为子进程fd3，并使用已有`--parent-fd`参数。父进程持有写端，退出、崩溃或正常返回均关闭它；Python沿既有退出流程处理EOF。模型路由、Go网关准入与专业CLI协调不变。

Case79的公开TERM/KILL配方由真实Go测试直接读取。父子进程和管道都是真实OS资源，子进程用Python标准库实现已有协议；pidfd确认退出并只清理测试自己创建的进程，不使用宽泛名称匹配。源码、输入和Go事件回执冻结。

## 验收证据与边界

最初夹具缺少存储布局，另存并排除，不计作功能复现。完整夹具下，旧代码TERM和KILL两项均证明所拥有的Python进程仍存活；新代码两项均退出并记录父管道EOF。后续完整质量门禁和CI记录单独归档。本修复不代表音频、视频、量化内容和独立/人工验收已经通过。
