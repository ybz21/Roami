# 最终回复的HTML产物链接

## 产品设计

实际股票原题v121已经生成并回读交付文件，Main最终回复却把HTML `href` 内的产物URL变成Markdown链接。格式因此损坏；HTML标签内出现URL也不能代表Markdown界面已有可点击下载。

普通Agent在最终落库时保留HTML属性里的规范相对URL，同时在正文末尾补独立Markdown下载链接。不新增HTML渲染权限或领域工具；原始 `answerText` 保留，用户显示的 `text` 使用规范化结果。

## 用户故事

- 用户能在任务结束后的总结中打开当前任务真实产物，即使模型用HTML写附件列表。
- 其他任务、其他所有者和已删除产物不能通过复制链接获得当前任务交付身份。
- 普通Markdown、结构化JSON和外部网址保持各自既有语义。

## 技术设计

`replies/artifact_links.py`识别带引号的HTML标签范围，在URL替换与已展示链接统计中区分属性上下文。属性内保留URL字符串，不注入Markdown；HTML属性不计为已展示链接，缺少时补规范Markdown。地址缩短归一化后重新计算标签位置。真实任务过滤仍由 `storage/turn_journal.py` 在同一持久化事务中执行，不读取模型提供的任意产物身份。

`tests/test_artifact_links.py`覆盖引号、无引号、回环地址、含大于号的属性、其他缺失产物、非法身份、重复归一化及真实Runtime终态。`cases/case-76-mech-al01`包含与Runtime夹具逐字节一致的匿名消息结构、工具说明和冻结执行入口，不包含私有任务或产物编号。

## 验收边界

旧实现新增回归8失败、28通过；修复后包含真实Runtime落库的39项通过，0跳过。新Case与后续完整门禁、固定Actor回归均保存私有回执。网页渲染使用既有Markdown解析器另行核对规范化输出有真实锚点；未修改前端代码或增加原始HTML执行。

这是普通Agent回复格式修复，不证明股票、媒体或其他业务内容通过，也不改写旧消息或历史成绩。开发验证不覆盖节点模型、参数、能力、重试或Go限额，不部署现用服务。
