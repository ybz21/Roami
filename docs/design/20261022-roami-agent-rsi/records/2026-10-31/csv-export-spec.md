# CSV字段边界与结构化导出规格

## 产品设计

列名作为数据传递，不依赖shell分词。带空格、Unicode、引号或shell字符的字段使用JSON数组；导出选择错误要返回被拒绝名称及可用列，不能靠删除转换项掩盖错误。

## 用户故事

- 导出金额、记录标识等带空格名称的列时，选择完整保留。
- 清洗副本基于原始输入，分析中间表和绘图格式不替代源数据。
- 查看失败原因及修复前后证据，单次适配通过不等于原题或独立评分通过。

## 技术设计

`skills/tabular-analysis/scripts/export_spec.py` 独立解析工作区JSON规格，拒绝缺项、未知项、重复键、错误类型及错误哈希；`csv_export.py` 提供 `export --spec`，同时保留既有独立参数。两种方式不混用。规格保留数组边界，回执记录规格哈希；输入观察哈希和输出保护沿用既有实现。`table_publication.py` 错误可携带机器可读详情，选择错误返回源字段名和修复路径。

没有新增核心工具、模型配置、Token/请求/消费上限。CSV逻辑仍在可选Skill；更新Case69的合成输入、预期及真实NativeExecutor集成，保留`record id`原样，`unit count`通过规格数组执行明确数值转换。工作规格通过结构化argv以create-only创建，不作为用户交付文件登记。
