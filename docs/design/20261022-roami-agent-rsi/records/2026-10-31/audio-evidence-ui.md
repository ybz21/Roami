# 音频分项在Case详情中的展示

## 产品设计

Case展开后先显示原生总分、原阈值、修复区得分和保留区得分；PESQ、STOI、LSD等放入默认收起的“音频指标”。沿用现有运行结果与Case入口，不增加配置、按钮工具栏或页面卡片。指标不改变运行状态。

## 用户故事

- 排查失败时，直接区分修复质量不足和保留区受损，不必先读原始JSON。
- 按需展开音频指标，对照单轮或A/B结果；缺失测量不当成零。
- 未完成原生核验时不展示残留分项；旧记录和其他类别保持。

## 技术设计

`audio-verification-evidence.ts` 负责已完成原生音频判定的字段选择和有限值过滤，`RsiAudioEvidence.tsx` 负责国际化数字和折叠展示，`RsiCaseEvidence.tsx` 负责组合。复用现有事实列表、44px折叠入口和SVG图标，无新增断点读法、轮询或后端变更。所有标签进入中英文语言包。

前端回归直接读取Case70的合成回执，覆盖完整分项、私有字段过滤、空值/非有限值/真实零、核验未完成、旧协议、小数精度和A/B隔离。界面验收使用隔离HTTPS服务上的真实生产前端包与明确标注的合成Case，不调用模型，不把界面样例作为真实任务得分。
