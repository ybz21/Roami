RSI 记忆证据修复 · 2026-10-26

Product Design

记忆提取读取用户原话、助手可见文本与既有任务／产物证据；助手工具调用参数仅表示执行意图，不作为已观察事实送入提取器。没有可用证据时直接完成空提取，不调用模型。完整转录仍保留工具参数。

User Stories

用户要求的项目习惯保持原会话／项目范围，不因助手的委派指令扩展为全局偏好。维护者可以用原始来源哈希复核记忆，模型引用已排除的来源时仍明确失败。

Technical Design

memory/jobs.py 仅在构造模型输入时移除 assistant 内容中的 tool_calls；保留其他字段和原文，排除空助手证据。来源白名单以实际提供的证据生成，写入仍使用原始来源 SHA 并执行既有所有者、遗忘、作用域与激活校验。空证据分支明确记录零请求与零用量；任何已发出的未知用量不走此分支。模型路由、输出限额、重试策略和原始转录不改变。

验证记录与剩余问题

60 项记忆管线回归通过，覆盖参数排除、可见文本保留、原始来源哈希、已排除来源拒绝、无证据零模型调用。真实低推理 DeepSeek 对照中，原输入以 2,048 个纯推理 Token 截断；投影输入一次得到有效 JSON，隔离 MemoryJobs 复测原任务仍出现同类截断。显式项目偏好样本完成提取，激活记录保留会话范围，无全局激活。两组四次请求共 9,159 Token，用量均已知，失败记录保留；不能据此宣称 MODEL_OUTPUT_LENGTH 或 #443 历史未知流中断已经解决。正式 GLM Memory 路由、质量校准和完整验收仍需各自验证。

本轮诊断配置的 GLM Memory 路由另作隔离运行验证：原任务与显式偏好两种输入均由真实 MemoryJobs 完成，共 984 Token／两次请求，无重试、无未知用量；项目偏好激活保持会话范围。此结果单列路由，不抵消 DeepSeek 的已知截断失败，也不表示现用服务已部署或改配。

后续修订提取指令：一次性任务验收清单和未执行计划不属于可复用记忆，不为凑满条数拆分要求；持久事实、已观察结果／决策及长期偏好继续提取。仍使用原 DeepSeek low、2,048 输出上限、20 秒运行时限且不重试，原 CODE-01 输入完成空提取；显式项目偏好保留会话范围，持久部署事实与发布结果分别生成事实候选。四次真实 MemoryJobs 共 3,009 Token，用量完整，原始失败保留。这是四种输入的修复验证，不能替代全套或历史未知流中断的根因证明。

用户随后授权将每日上限改为 20,000,000 Token；已同时保存运行和评测配置，自动调度仍关闭，原 Case 上限保持。原全套单轮预留 13,292,000 Token 的预算阻塞已解除；四份修订样本人工参考分和完整验收仍独立待完成。

相同 DeepSeek low 路由的真实 NEWS-01／QUANT-01 回归，六个 MemoryJobs 均完成且无异常码。QUANT-01 独立验收通过；NEWS-01 五条事件字段值与合同一致，但擅增顶层元数据而失败。两项合计 178,183 Token／26 次请求，原失败继续保留。
