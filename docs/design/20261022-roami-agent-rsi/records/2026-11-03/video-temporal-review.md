# 视频素材的时序预览与可核对回执

关联 [Issue #618](https://github.com/ybz21/Roami/issues/618)，类型 feature，优先级 P1。

## 产品设计与用户故事

作为按分镜选择视频素材的用户，我需要看到同一片段随时间的变化，区分人物朝向、转身和镜头运动，随后再拼接。预览是外挂视频 Skill 的能力，保持现有模型页配置和能力声明；生成预览不代表视觉语义已经确认。

输入为工作区中的单个MP4及采样位置，输出PNG联系图和JSON回执。图片保留完整画面，逐格标注实际解码帧号和相对时间。回执保留请求位置、实际时间、原始时间起点、帧哈希与源文件哈希。一个实际帧对应多个采样请求时合并画面，保留全部请求。

## 技术设计

`skills/video-assembly/scripts/frame_samples.py`读取第一个视频流的逐帧时间线，并明确解码同一流，避免探测与画面来自不同视频流。可变帧率使用逐帧时间，不用平均帧率换算；采样范围同时考虑声明时长和末帧结束位置，避免较短的时长头隐藏尾帧。声明值和观测值分别保留，缺失的末帧时长保持null。接口依据见[FFprobe官方文档](https://ffmpeg.org/ffprobe.html)。

`clip_inspection.py`负责请求验证、联系图及回执，复用`video_workspace.py`的源快照、哈希校验、符号链接围栏和不覆盖发布。已有`assemble.py`继续处理选定片段的编码与连续时间线。该目录按解码、预览、文件发布与拼接分层；没有新增Agent核心视频专用工具或模型请求。

SKILL入口提供时序预览与拼接两种操作，要求依据可见证据判断用户要求的场景、方向、景别和动作。缺少可用视觉能力时保留未决状态，不把文件名、分类器输出或抽帧成功当成语义通过。预览依赖已准备的Pillow>=10.1与ffmpeg/ffprobe；不在离线任务中安装依赖。

CI的FFmpeg8.0.1与冻结渲染环境的7.1.5对同一合成末帧分别报告0.24秒与0.04秒停留时长。回执保留各环境的观测值；测试使用更密的请求位置，仍严格检查五个已知呈现时间和对应颜色，不假设五次请求一定得到五个不同画面。这是合成测试的跨版本兼容修正，未改原任务的判定器或阈值。
