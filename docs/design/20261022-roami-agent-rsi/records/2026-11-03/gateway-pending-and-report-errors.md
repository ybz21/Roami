# 网关结算状态与回报失败原因

对应问题：[#611](https://github.com/ybz21/Roami/issues/611)。

## 产品设计与用户故事

Go返回“正在结算”时，用户应稍后重试；费用未知则需要核对。Python本地适配器原先把前者改为后者，导致错误归因。另一个实际缺口是Main无法生成后台任务回报时，核心已经保存`reportError`，界面只显示通用失败句，隐藏了已知原因。

聊天收尾、执行活动和RSI要显示对应的下一步。任务结果、任务自身失败原因和回报生成错误分别保留，回报失败不能改写任务状态。历史记录未保存回报错误时维持原提示。

## 技术设计与模块

- `providers/local_gateway.py`删除结算码替换，继续由Go决定准入，Python仅保真传播并记录可信拒绝；不增加重试或Python额度。
- `agent-models.ts`加入结算中的提示映射，中英文补齐RSI错误和工作流信号。复用既有活动和任务失败原因映射。
- `AgentMessageView.tsx`展示已保存的回报生成错误，使用现有i18n、状态样式与组件；不追加模型调用、改动实际任务结果或将错误码摆到主流程。
- 不改模型、参数、能力、每日额度、未知账本、日程或生产安装。现有401未知费用与本修复无关，不能据此回填为零。
