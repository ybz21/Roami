# 新协议参考池与定量演示稿

## 产品设计与用户故事

用户要判断PPT是否有信息表达能力，不能只核对是否写了几个数字。参考池需要同时包含内容缺失、内容正确但呈现不足，以及清楚表达事实关系的稿件，避免将“几页白纸”直接视为高质量正例。白底本身不扣分，图表必须传达有依据的关系。

## 技术设计

沿用PR582的外挂 `presentation-design` 方法、显式委托AI参考策略及既有固定渲染镜像。没有增加Agent核心工具、PPT依赖、模型覆盖或独立消费限额。本次新增的是参考材料与验收记录，生产代码没有变化。

销售参考保留原任务：两页、Q1为20、Q2为35、合计55，引用 `synthetic-sales.csv`。修订稿以第一张原生柱图表达季度比较，第二张原生堆叠图表达合计；图表零基线、单位、数值及结论对应同一CSV。可编辑图表及其工作簿保留在PPTX中。图表不是截图，数字没有从外部模型生成。

[打开修订稿、旧稿和源数据](../../evaluation/references/20261101-quantitative-sales/README.md)。旧稿原文件及历史人工分保持；另建AI负参考候选，四维建议为正确性3、完整性3、可用性2、依据3。该判断针对新建演示稿的组织与呈现要求，不用于要求局部编辑任务额外重设计。
