# 数据快照绑定的数值比较

## 产品设计与用户故事

股票原任务v171虽然生成了可通过适配比较的CSV，讲稿仍把成交量中位数从58021450降到18493800说成“roughly halved”。公开交付数据复算为下降68.1259%，同时存在最低价阈值、相关性措辞和无来源行业比较的问题。用户需要报告数字、实际统计口径和源数据一致；CSV通过不代表报告质量通过。

本次新增通用的只读统计比较能力，作为可选tabular-analysis Skill资源交付。它支持用户明确选择两份实际样本和统计量，返回数值、变化比例、样本数、缺失数及源哈希，便于把有依据的数值写入报告。业务分组、预测和行业判断仍需任务本身的证据。

## 技术设计与模块架构

`skills/tabular-analysis/scripts/numeric_comparison.py`沿既有Workspace安全读路径与CSV解析层读取两个快照，显式选择mean、median、minimum、maximum、first或last；不推断日期/分组、清洗或改写源文件。Decimal字符串输出，50位有效数字、half-even运算；均值采用标准库精确求和再除法，保留大数抵消后的残差。零基数百分比返回null，负基数同时保留方向和带符号的比例；拒绝非数值、空样本、越界运算、过期哈希和计算期间的源变化。

Skill入口按需指向`references/numeric-comparisons.md`，资源随现有托管外挂包发现和执行；原7个资源字节保持，新增脚本及说明共9资源文件。Agent核心、RSI评分协议、冻结Actor镜像、Go网关和模型设置均不修改，不增加内建金融工具或Python消费限额，不安装到节点。
