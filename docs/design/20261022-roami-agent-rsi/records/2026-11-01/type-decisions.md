# 导出前检查未决数值表示

## 产品设计与用户故事

真实v150读取外挂并执行导出器，却漏选数值标识列；回执在写出后才报告保留的小数形式。希望遗漏在写操作前被指出，保留文本与转换均由调用者根据任务和输入明确选择。它不把标识列自动当成数值，也不要求用户逐字段人工审批。

## 技术设计

导出器先按既有规则投影和转换，计算仍保留的整数小数形式；每个这样的输出字段须在numeric或新增preserveNumericText中声明。缺少选择返回TABLE_NUMERIC_CHOICES_REQUIRED与完整字段名、计数，发布函数不被调用。保留与转换集合不能冲突，字段必须实际存在；排除在输出投影外的列不要求选择。

JSON规格和CLI的--preserve-numeric-text支持完整字段名，包括实际空表头。回执记录preservedNumericTextFields，原有保留表示观察仍在。覆盖来源的路径检查保留在类型检查之前，输入哈希、创建/替换保护、精度及日期键行为不变。实现仅在外挂脚本与规格层，Agent核心、基础工具、模型路由和任何额度配置不改。

## 验收边界

Case69公开夹具直接用于漏选检查；88项含实际NativeExecutor外挂交付，Case75共享包选择为87项。检查覆盖未决字段拒绝新建及替换、空表头、合法文本保留、冲突、未知字段、CLI与JSON、补零混合标识和投影排除。

隔离回放与真实原题结果分开记录。类型选择检查不能证明分析结论正确，也不解决v151显式选择分析日期表示的问题；后者及另外7项内容仍待验收。不修改原分数、旧产物或模型配置。
