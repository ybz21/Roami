正式评测的共享准入与首发阻塞 · 2026-10-28

Product Design

正式日跑与诊断采用相同的共享准入语义。Go 网关因额度不足拒绝后，后续模型任务保留未执行记录，不重复启动，也不被当成候选质量下降。无需模型调用的机制检查继续。运行结束先保存程序总结，独立 Codex 复盘或正式验收仍使用各自回执。

缺少 Token 回执与费用准入分开处理。网关接受请求时，RSI 不再自行按 Token 未知熔断；计量仍保留未知，效率与正式晋级不能借此宣称通过。原有无代理协议继续保持保守约束，模型费用及额度由配置的 Go 网关处理，旧本地账本只保留历史材料。

User Stories

  • 用户能区分首发 Case 与后续受阻 Case，并看到配对中的 baseline、candidate 和各自证据。
  • 确定未发出的后续任务记零调用；首发未知用量和整轮总量仍保留未知。
  • 候选尚未执行时，不显示质量退步或虚假的效率收益，也不能凭缺测晋级。
  • 付费复盘被阻止时，仍能读取评测总结与原因，不依赖再次消耗模型生成说明。

Technical Design

domain/admission_blocking
  共享拒绝与未知用量分类；未执行结果
workflows/cycle
  冻结 Case、执行分支、原因；保留每条 trial 与宿主阻塞凭据
evaluation/behavior_review → domain/comparison
  区分实际尝试和未执行；缺测不生成候选退步或成功收益
workflows/run_lifecycle → pipeline_reports
  保留首发执行分支、双分支证据和完整用量边界；先落盘可读总结

拒绝原因来自宿主终态、Go 网关 HTTP 回执及脱敏模型日志，外部执行器不能自行设置 blocked_by、admission_error 或 shared_admission_managed；宿主依据共享网关配置标记准入管理方式。配对共用网关额度准入，首发原因包含 Case、执行分支与错误码；后续模型 trial 不启动执行器，以宿主生成的 admission-blocked.json 保留来源，调用及 Token 为零。镜像协议标签升为 shared-daily-policy=2，旧镜像在预检拒绝。所有原始评分和已发送请求保持原样，不改写历史未知账。

阻塞对照不参与质量差值、基线退步及成功效率计算，仍明确阻止晋级与完整覆盖结论。正式运行投影保留两条分支，首发记录不被另一条未执行的记录覆盖。生成、产物评分及合计用量分别汇总，空记录或缺用量保持未知，避免省略字段后被付费复盘误认为零消费。

Go 网关整合 · 2026-10-28

主分支 #473 已撤下本地价格、限额及统计入口。当前 RSI 工作流不读取 ModelBilling、不调用旧代理准入、不写旧费用表；模型连接直接请求 Go 网关。MODEL_HTTP_402 是全局额度阻塞，后续模型 Case 不继续派发，额度不足不新建代码缺陷。旧 MODEL_PROXY 错误仅保留历史兼容。Token 缺失仍阻止效率与正式完整结论，不能阻止网关管理的后续请求；独立 CLI 维持既有登录与连接。

验收边界

早期 v27 容器保护演练基于 #473 合入前的本地代理：60 条记录、20 项机制通过、1 项准入拒绝及 39 项未执行，原账未变。该演练保留为历史设施证据，不能当作当前 Go 网关准入验收。

真实 Native 容器已复现并修复宿主误报：文件成功生成，缺少 Token 回执却被提升为 RSI_RUNTIME_REPORTED_FAILURE。共享模式仅对宿主同样确认的 unknown_provider_usage 保留计量阻塞，交付按独立断言判定；实际执行错误、无法由宿主核对的标记和旧协议仍拒绝。

回归、模拟网关和容器保护对照只验证设施，不代替真实模型完整 60 项、人工参考评分或两次完整日观察。原中断账保留为历史未知，不清零、不重放，也不再代替 Go 网关的当前额度决定。自动日程与现用服务不因这次修复部署。
