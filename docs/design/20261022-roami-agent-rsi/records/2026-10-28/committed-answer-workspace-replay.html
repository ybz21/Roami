已提交答案与工作区重跑 · 2026-10-28

Product Design

验收任务最终提交的答案，自动产物通知单独保留。量化脚本在独立可写工作区重跑，支持公开的 /workspace 路径与本地模块；原始生成文件与失败记录保持不变。严格的数值和结构判定继续拒绝解释文字、错误结果和未重新生成的旧结果。

User Stories

  • 主智能体已正确回答数值题时，后续产物链接不会替换答案导致误判。
  • 脚本使用 /workspace 绝对路径、相对路径或子目录模块时，都能按同一公开环境验证。
  • 我能区分旧失败、适配修正的零模型重放和新的完整真实运行，不能将修正误判计为模型优化收益。

Technical Design

evaluation/execution/executors.py 的 committed_answer 按当前 turn_id 和消息来源区分 content.source=task 的交付通知，排除带工具调用的中间消息，逐轮与最终评分复用相同选择。有本轮 Main 文本时优先使用；没有时沿用既有交付文本，不剥离链接或解释，数值判定器仍要求完整字符串为数值。

containers.py 的 sandbox(copy_workspace=True) 将原目录只读挂载到 /replay-input，在容器私有、限额 512 MiB 的 tmpfs /workspace 中复制完整目录。复制在容器内部进行，保留符号链接，不在宿主机追踪产物链接。保持禁用网络、只读根文件系统、非 root 用户、无提权及原资源限制。QUANT 重跑从副本删除既有输出后执行 analysis.py，保留子目录模块与绝对路径语义，不能沿用旧结果。

共享镜像标签升级为 org.roami.rsi.shared-daily-policy=3，拒绝旧子进程答案选择协议；执行器协议身份升级至 container-uds-v26-committed-answer-workspace-replay。镜像继续移除宿主 Case、输入生成及判定模块，不向执行模型提供答案。
