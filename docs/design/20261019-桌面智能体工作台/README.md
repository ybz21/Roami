# 桌面智能体工作台

依据用户指定视频与 18:29 截图，学习交互后提出 24 项 Roami 改进。视频的功能演示与我们自己的可实现性判断在报告中分别说明，不将演示结果作为真实服务能力证明。

- [HTML 报告与交互示意](index.html)
- [24 项清单](roadmap.json)
- 首批实现：`AgentWorkspaceRail.tsx`、`AgentWorkspaceActivity.tsx`、`useAgentWorkspace.ts`、`agent-workspace.css`；接入现有 `AgentChat`、任务、记忆与提醒组件。

首批复用现有 API 与 SSE，未新增模型工具、鉴权、外部账号连接或执行协议。仅大窗口（useLayout 的 large，1280 起）展示可收起侧栏，较窄窗口沿用任务 / 记忆原有弹窗入口；手机版按用户前序要求暂不 review。输入区、工具流和独立后台任务继续使用原机制。

动态使用当前分支最近 200 条活动，按更新时间倒序分组；任务列表接口最多 200 条，优先展示需要关注与执行中的根任务，不承诺全量全局历史。工具的输入输出沿用既有有界详情读取。统一记忆目录不等同于当前回复已使用的召回证据。提醒复用原所有权校验、时区、来源跳转与取消机制。

布局在浏览器按节点保存展开状态与选中标签，首屏直接读取。动态出现任务条目时批量读取既有任务列表，展示任务标题；纯工具动态不额外查目录。任务、记忆和提醒切换时再加载，各标签卸载时终止订阅 / 请求。任务与提醒在页面隐藏时暂停定时读取。

P1 是下一批建议，尚未实施。条件监控、审批卡绑定、外部账号 OAuth、助手资料与跨设备待发队列都属于待确认项，不写入已批准的框架技术设计、不自动接入账号。

现有框架 goal 仍处于系统暂停状态，本轮创建新目标被拒绝；任务研究和实现继续按本目录记录，未擅自将旧目标标记完成。恢复目标需在用户的 goal 面板操作。

本目录为开发者设计与验证资料，使用中文属于仓库 i18n 文档例外。产品新增固定文案提供中英文，截图与视频素材不提交进 main。

## 实际验证

见 [validation.json](validation.json)。`scripts/dev/quality/check.sh full` 通过；Go 测试、Python 575 项及 Ruff 通过。前端 `npm run typecheck && npm run i18n:check && npm run hover:check && npx vitest run && npm run build` 通过（98 个测试文件、703 项测试、3009 个翻译键）。构建保留已有的大块体积和混合导入警告。

隔离 Go/Python/SQLite/SSE 服务上，用受控模型驱动真实 `roami project ls --json`；仅隔离 CLI 增加两秒延迟以观测进行中状态，不作为性能结论。失败、待验收与未知状态由绑定该隔离用户和来源消息的展示夹具覆盖，不代表实际 Codex / Claude 的任务交付。记忆与提醒通过实际 API 创建。

桌面检查：1600 宽度依次打开动态、任务、详情、定时、记忆、输入输出；在详情打开时发送消息并收到回复；收起后刷新仍保持，再通过工作台按钮打开；发送 `/tasks` 进入同一侧栏。1280、1600、1920 均无文档横向溢出，输入框宽度至少 500；1100 保留原任务弹窗。中英文标签均可见。报告的 24 项筛选（10/9/5）、回执、详情返回、四标签、收起和示例发送均通过浏览器验证。

本轮未通过项：无（上述桌面范围）。手机版、真实专业智能体端到端执行、P1 和待确认项不在本轮通过范围内。截图保存在 `/tmp/roami-workspace-*-desktop.png`，不提交进 main。常规 Roami CLI 派活不增加重复确认，未来授权卡只覆盖实际需要用户决策的动作。
