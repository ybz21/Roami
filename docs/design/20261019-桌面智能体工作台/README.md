## 本次确认与实施：任务 / 记忆双入口

第一项统一叫「任务」，与 Roami 后台任务对齐。原独立的「动态」和「任务」标签合并；一条记录对应一个实际后台任务，展示名称、状态 / 进度、结果摘要、执行器和时间。列表优先展示需要关注和执行中的任务。点击后在侧栏查看结果、折叠的工具 / 命令过程、子 Agent 和产物；主对话继续可用。

普通问答及未关联后台任务的执行过程仍在主对话消息流中呈现，不伪造 taskId、不把每次 read / bash 升格为独立任务。执行记录只能依据实际任务关联归入详情；现有任务 / 详情接口的上限仍保留，不承诺全量历史。

本期产品与交互示意只提供「任务 / 记忆」双入口，右侧首次默认展开、可收起并按节点记住状态；定时提醒仍可从原通知入口访问。审批仅为规划占位，绑定协议仍待确认；已授权的常规 Roami CLI 派活不增加重复确认，任务待验收也不冒充待授权。Roami 的第四项保留统一记忆，与参考产品的身份 / 个性化入口不是完全相同的映射。

桌面侧栏展开时，对话菜单、通知和收起按钮统一放在右侧标签栏，主对话标题旁不再放第二组操作。任务与记忆只从标签进入，桌面菜单仅保留上下文和概览；侧栏收起后，操作回到页面最右上角，展开按钮使用相同的侧栏图标。较窄窗口沿用原任务 / 记忆菜单入口。

本期已修改 AgentWorkspaceRail、useAgentWorkspace、AgentTasks、AgentMemory 与侧栏样式，删除独立 AgentWorkspaceActivity 和无用翻译键。任务卡片区分状态、标题、执行器与时间，记忆保留搜索、筛选、来源、展开和管理入口；样式通过 compact 属性限定在桌面侧栏。旧 activity / reminders 偏好已迁移至 tasks，保留用户的展开 / 收起选择。任务级工具关联聚合与聊天回执直达详情仍待后续，不将未关联的工具步骤拼入任务；当前任务详情复用现有结果、子任务、产物与执行记录。

## 上一版实现边界（fc57a07）

首批复用现有 API 与 SSE，未新增模型工具、鉴权、外部账号连接或执行协议。仅大窗口（useLayout 的 large，1280 起）展示可收起侧栏，较窄窗口沿用任务 / 记忆原有弹窗入口；手机版按用户前序要求暂不 review。输入区、工具流和独立后台任务继续使用原机制。

动态使用当前分支最近 200 条活动，按更新时间倒序分组；任务列表接口最多 200 条，优先展示需要关注与执行中的根任务，不承诺全量全局历史。工具的输入输出沿用既有有界详情读取。统一记忆目录不等同于当前回复已使用的召回证据。提醒复用原所有权校验、时区、来源跳转与取消机制。

布局在浏览器按节点保存展开状态与选中标签，首屏直接读取。动态出现任务条目时批量读取既有任务列表，展示任务标题；纯工具动态不额外查目录。任务、记忆和提醒切换时再加载，各标签卸载时终止订阅 / 请求。任务与提醒在页面隐藏时暂停定时读取。

P1 是下一批建议，尚未实施。条件监控、审批卡绑定、外部账号 OAuth、助手资料与跨设备待发队列都属于待确认项，不写入已批准的框架技术设计、不自动接入账号。

现有框架 goal 仍处于系统暂停状态，本轮创建新目标被拒绝；任务研究和实现继续按本目录记录，未擅自将旧目标标记完成。恢复目标需在用户的 goal 面板操作。

本目录为开发者设计与验证资料，使用中文属于仓库 i18n 文档例外。产品新增固定文案提供中英文，截图与视频素材不提交进 main。

## Muse 列表复刻（本轮，不含头像）

按用户最新确认，先复刻列表，不制作头像。桌面保留任务与记忆两个入口，任务按更新时间倒序分「今天 / 昨天 / 日期」，每条显示浅底圆角图标、标题、两行摘要及时间 / 状态 / 执行器，去掉独立卡片边框。记忆沿用同一列表骨架；筛选按需展开，来源、内容展开、每日足迹与完整管理入口保留。首次默认展开与收起偏好不变，深浅主题均使用既有 tokens。窄桌面的原任务弹窗维持原分组。

任务列表接口增加可选的 latestAttempt.summary：从已落库执行报告读取，最多 240 个字符，仅属于当前任务版本时才返回。没有摘要时显示状态提示，不额外调用模型，不逐条请求任务详情；完整报告仍在详情查看。状态以 task.state 为准，执行器报告不能把失败或待验收变成成功。SQL 层仅提取文本摘要，忽略非文本，不改变任务状态机、工具调用或委派协议。

未接入头像素材，未改动主对话发送机制；任务级工具聚合、审批及专业智能体真实端到端执行仍是之前记录的边界。

本轮验证：98 个文件 / 706 项前端测试、类型 / 3010 个翻译键 / hover / 构建通过；Python 576 项及 Ruff 通过。真实隔离 Go / Python / SQLite 服务验证任务摘要、时间分组、详情中继续聊天、记忆搜索 / 来源 / 按需筛选、默认展开 / 收起恢复、旧标签迁移、中英文、深浅主题及 1280 / 1600 / 1920 宽度；1100 维持原弹窗。截图任务终态为隔离展示夹具，不作为实际专业智能体执行证据。
