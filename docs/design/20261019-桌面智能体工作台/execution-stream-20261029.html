主对话执行过程 SSE

Product Design

主对话实时显示实际工具调用、Skill／记忆读取和任务派生。连续工具步骤可折叠，展开后可看每次调用的输入、结果与状态；任务保留真实生命周期和详情入口。首次快照、实时 SSE、刷新和断线重放使用相同展示规则，普通工具执行不再被隐藏。

User Stories

  • 工具还在执行时，我能看到正在调用什么；完成后同一条记录更新结果。
  • 我能展开 Skill、MCP、CLI、记忆等调用，查看具体读了什么、传了什么和得到了什么。
  • 后台与专业任务的调用回到原对话，派生任务保留主题、状态及详情入口，大量调用不会挤掉任务卡。
  • 刷新和断线重连不重复或丢失已有步骤；删除工具结果后，回放不重新展示该预览。

Technical Design

复用 conversation_activity、activity_event 与已有 conversation SSE。工具元数据附带脱敏且有界的输入／输出预览（2000／4000 字符）；完整预览沿用已鉴权详情接口，只有显式展开长内容时读取。专业能力回执携带 activityId，并向父任务原会话传播。回放按当前可见执行记录过滤已删除预览，保留过去事件的开始／结束状态。主对话任务与工具分别保留最近 200 条，不新增轮询、模型调用、工具协议或数据库迁移。

前端统一保留任务、子任务和工具；AgentActivity 展示工具步骤，AgentTaskActivity 继续展示任务状态。事件按 id 去重、按原分支应用；已知 message.tool_calls 直接更新，不额外读取快照。展开后的短预览随 SSE 更新，无需详情请求；旧事件和没有内联预览的历史记录仍能按原接口读取。
