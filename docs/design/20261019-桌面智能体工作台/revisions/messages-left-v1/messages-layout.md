# 消息导航与持续执行 · 2026-10-19

[可点击原型](messages-layout.html)。本次按用户 22:00 截图修订；原工作台设计与实际验证记录保留。以下设计覆盖先前“右栏更多菜单保留上下文与概览”的安排。

## 布局

| 区域 | 本次设计 |
|---|---|
| 左侧导航 | 首页、消息、项目、浏览器、文件；消息与首页 / 项目同级，直接展示未读数字。收成图标轨时保留消息图标与红点 / 数字。 |
| 左侧树 | 保留项目、任务、专业智能体工作会话、新建项目和任务入口。消息不塞进项目树，也不再作为一个藏在更多菜单里的动作。 |
| 中间区域 | 首页保留唯一主对话；点击消息后切换成普通消息页面，按时间平铺，无消息 Modal、抽屉或嵌套 Tabs。 |
| 右侧 | 首页保持任务、记忆、连接状态和展开 / 收起；删除上下文、概览、空的更多按钮以及消息铃铛。消息页不带无关的任务侧栏，点击来源任务后再回首页定位并展开对应任务。 |
| 输入区 | 模型切换、附件、上下文用量与 /compact 保留在已有输入区，移除右上“上下文”不等于删除上下文能力。 |

消息列表每行只显示类型图标、标题、两行摘要、时间、来源和未读点；不把完整任务卡和长报告再复制一遍。点击整行回原主对话并定位消息，有真实 taskId 时打开其右栏详情；任务结束后可查看执行记录和留存产物。没有 taskId 的主动提醒只定位消息，不伪造后台任务。

未读数只放消息入口，首页不重复计数；进入列表不将所有消息自动标已读。实际查看来源后确认已读；“全部标为已读”为明确操作。消息与后台任务是一对多关系，同一任务可以产生多条真实进展，消息条数不代表新建了多少任务。

当前通知弹窗中的定时提醒、通知偏好、投递记录仍需保留：集中到设置页的通知管理，不在消息列表套四个标签。既有消息原文、来源跳转、原主对话归属、已读游标和后台执行机制继续复用。网页打开消息不代表系统通知已实际送达。

## 用户补充：不设连续调用次数和总执行时长硬上限

新要求优先于上一轮“native 600 秒 / 专业 3600 秒 / 16 轮”的设计。执行持续到完成、用户取消或明确不可继续的实际错误；不能仅因达到固定轮次、调用次数或总耗时而失败。记录次数、耗时和 Token 用于观察，不把展示数值变成执行配额。

重复派活防护按任务身份、工作区和真实操作证据处理；不能靠“失败两次就强制终止”的固定次数门槛替代故障诊断。鉴权错误先修连接；写操作结果未知先对账；可恢复错误在同一任务下接续，避免重新创建一串任务。复杂任务仍由专业智能体负责，主智能体保持快速响应，并能处理后来的独立问题。

单次网络请求超时、工具子进程异常、资源心跳、租约和取消确认仍需要可观测状态。这些属于连接 / 控制权恢复机制，不能当成整个任务的总耗时上限，也不能根据一次断线自动重跑结果未知的副作用。

### 实施时需要一起核对的落点（本轮只设计）

| 代码 / 协议 | 需要调整 |
|---|---|
| `core/loop.py` | 取消 max_steps 的强制退出，持久化轮次统计；保留用户中断与新意图调度。 |
| `dispatch/tasks.py`、`runner.py`、`task_revisions.py` | 不再因 maxTurns / deadlineMs 结束任务；去重、故障诊断和续接基于任务身份与事实。取消本轮旧稿的两次失败门槛。 |
| `executors/native.py`、`executors/roami_cli.py` | 不再从任务总 deadline 包装整轮执行，不给专业任务隐式设置总倒计时。 |
| Go `agentexecution` | `timeoutSeconds` 未设置代表无总时限；不能再强制 1–86400 或默认塞 Claude `--max-turns=16`。用户停止仍精确作用于绑定进程。 |
| `resource_leases.py` | 租约由控制权心跳管理，不取任务总 deadline 的最小值，不因老任务期限误判新动作。 |
| 配置与历史预算 | 去掉固定轮次 / 总时限的控制作用，旧预算记录仍可作为历史证据。已经启动的外部进程须核对实际 deadline 能否更新，不能为了应用新规则擅自重启或重复派活。 |
| Benchmark | 补充超过 16 轮仍能继续、无总 deadline、专业 CLI 不传限制、用户停止、单次网络恢复、主对话继续响应等用例。测试执行器自身的超时不冒充产品限制。 |

上一轮 27 条 benchmark 和通过结果是原实现基线，不能用来宣称新“无限次数 / 无总时限”规则已经通过。后续实现时应修改对应预算与失败门槛测试，再补新规则回归。

## 原型的可验证交互

- 首页 / 消息切换；消息在导航平铺，中间列表平铺。
- 全部 / 未读筛选、点击来源定位、任务详情与已读数变化、全部已读后的空态。
- 首页右栏任务 / 记忆切换、展开 / 收起；去消息页再回首页保留收起选择。
- 深 / 浅色主题；设计说明弹窗；来源缺少 taskId 时只定位对话。
- 复用项目的 280px 导航、360px 工作台尺寸和现有设计 tokens；图标从 `frontend/src/icons.tsx` 提取，没有新增图案。只验证桌面，不冒充手机验收。

本次只新增设计文件和原型，不修改产品导航、消息 API 或 Agent 执行规则。原型为本地样例，不写入真实消息、已读状态或任务。中文为开发者设计资料的 i18n 文档例外，后续产品实现需补齐中英文。
