设计说明

右侧三个同级标签

固定顺序：任务、消息、记忆。消息位于第二个，合并消息与提醒，未读数直接显示在消息标签旁。移除独立铃铛、更多菜单、上下文和概览。

消息与提醒合并

在右侧同一列表平铺任务消息、主动提醒和定时提醒。“待提醒”展示尚未触发的安排，今天 / 昨天展示已发生的消息。点击消息在主对话定位来源，侧栏继续保留消息列表；需要查看任务时再点击“查看对应任务”。

左侧与中间

左侧保留原有导航和项目会话树，不新增消息导航。中间始终保留主对话，不切成独立消息页面。

设置归入设置页

通知类型、免打扰时段、时区、隐私预览及投递诊断放入设置页。消息标签内只保留列表、筛选和已读操作；定时提醒详情仍可查看来源或取消。上下文用量保留在输入框内，/compact 仍可使用。

持续执行，不加次数与总时长上限

取消连续调用次数、工具循环轮次、任务总耗时的硬上限，不再设 16 轮、10 分钟、1 小时的强制终止。用户可随时停止，主智能体持续快速响应新问题。次数与耗时用于观察，不作为到点结束任务的依据。

同一个任务复用 taskId 与工作区；失败依据真实错误和副作用证据排查，不靠固定失败次数阈值结束。单次网络超时、资源心跳与租约仍负责判断连接和控制权，不能冒充任务整体失败或授权重跑未知操作。

原型范围

桌面交互示意，消息与任务均为样例。点击与已读只影响本页面；未调用真实消息、任务或配置 API。设置、项目与文件页用说明占位，展示入口位置。实际产品代码本轮未修改。
