# 桌面工作台实现记录 · 2026-10-19

本轮实现确认后的任务 / 消息 / 记忆布局，并完成此前任务交付修复；不包含生产部署。

## 布局与交互

主对话始终在中间；右栏默认展开，可收起并恢复，首屏从本地存储恢复选择。宽度为 clamp(440px, 34vw, 640px)。切换标签只更新右栏；消息定位原对话时保留消息标签。保留原有项目与会话导航。

右栏依次为任务、消息、记忆，移除独立铃铛与上下文 / 概览菜单。输入框内上下文查看、压缩入口保留。小屏沿用任务弹层，消息与提醒合并；通知偏好和投递诊断迁到设置页。

消息页提供全部 / 未读、按当前可见通知游标标记已读。已读消息仍在历史中，未来提醒不计入未读，标记已读不会取消提醒。提醒取消有二次选择。

任务详情将产物提前到执行结果之前。Markdown 复用现有渲染器；报告、图片可预览，HTML 用空 sandbox 和 CSP 禁止脚本、联网及表单提交；PDF 用已授权读取的 Blob 预览。文本 / 图片预览限制 1 MiB、PDF 8 MiB，其他文件保持下载入口。预览限制只是前端加载保护，不截断下载的原文件。

产物从服务端工作区证据提取并留存，执行器结果不得伪造工作区来读取任意文件。拒绝路径越界、符号链接和特殊文件；按用户与任务隔离下载。历史任务可补收集已有报告，原工作区删除后已留存文件仍可下载，主动删除的产物不得复活。工作会话退出后显示执行记录与产物，不导航到已退出的 tmux。

## 持续执行

新任务 maxTurns / deadlineMs / timeoutMs 为 0，表示不设总调用轮数与总时长上限；模型循环持续到完成、取消或实际错误。旧配置字段兼容读取，但不再决定新任务预算。Go 支持 timeoutSeconds=0，Claude 单次启动不再强加 max-turns=16。计数和耗时仍记录供追踪。

保留单次模型 / 网络请求超时、资源租约、并发和 fork 深度控制。旧进程已经启动的 deadline 不强行修改；旧有限父任务派生的子任务仍继承其截止时间，避免后台工作越过父任务生命周期。用户在原任务上续接创建新 revision 后不再套旧总时限。

不再按“两次失败”统一拦截。同来源相同目标复用任务；未知写入结果与尚未修复的鉴权 / 工作区准备错误根据证据拦截重建。恢复通过已有任务继续，保留历史与产物。失败不能显示成功。

自动化覆盖连续 20 次工具调用、25 次任务统计与取消、无截止时间的 Go context、历史通知读游标、任务产物访问边界、委派去重与失败证据。完整命令、计数和实际截图在 PR 描述中记录。

浏览器和 Android 使用独立 Go / Python 实例及测试 SQLite，产物为明确标注的隔离验收样本；没有改写生产会话、任务或模型连接配置。静态设计稿使用中文作为评审文档，所有新产品文本均提供中英文翻译。

## 手机导航与间距修订

首页对话的任务、记忆直接融入 App 顶栏，与消息和搜索同排；不再经“更多”菜单跳转。通过顶栏操作槽渲染当前对话的两个直达按钮，路由切换与尺寸变化时由 React 清理；移除聊天区独立操作行。任务、记忆弹窗保留，桌面右侧任务 / 消息 / 记忆布局沿用。

顶栏按钮统一 20px 图标、44px 命中区，使用同一底色和分隔线。手机正文与输入卡使用 16px 外侧留白并避开横向安全区，输入卡内文字采用 12px 顶部 / 16px 水平留白，工具条使用 4px 顶部 / 8px 水平与底部留白；输入卡与底栏保留 8px 间隔。所有尺寸来自既有令牌，浅色与深色共用同一语义色定义。

验证覆盖 320 / 390 / 820 / 1600 宽度、中文 / 英文、深色 / 浅色，无横向溢出；手机输入卡左边缘为 16px，顶栏按钮命中区 44px。真实 Redmi Note 8 验证顶栏命中、任务与记忆弹窗、四个主导航往返和触摸滚动。前端 105 个文件 / 728 项测试、类型、翻译、hover 与生产构建通过；构建保留现有 chunk 大小提示。
