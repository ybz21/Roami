# 任务与会话生命周期分离

[打开交互方案](proposal.html) · [验收记录](acceptance.md)

## 产品设计

任务保存目标、执行、核验结论和交付物；会话提供继续交互的入口。项目页红框中的内置智能体行属于会话，可以移除。会话结束或移除不等于任务完成，也不等于删除任务。

| 用户动作 | 会话 | 任务 | 工作区与文件 |
| --- | --- | --- | --- |
| 验收任务 | 保持可用 | 待核验变为已完成 | 保留 |
| 移除会话 | 停止执行，关闭后退出项目会话列表 | 已结束状态不变；执行中的任务取消并保留原因与记录 | 保留 |
| 查看任务记录 | 不重新创建会话 | 展示原状态、结果、交付物、执行记录 | 可查看已保存交付物 |
| 清理工作区 | 走已有项目工作区收尾入口 | 不作为任务验收 | 由用户独立选择并遵守原有保护 |

项目会话行尾增加常显的移除按钮，桌面与手机都可直接操作。短确认说明停止执行、保留任务记录及文件；失败留在确认框内并提供重试。关闭中的行保留“正在关闭”状态，只有服务端确认关闭才退出列表，不用乐观隐藏掩盖失败。

任务列表、任务详情、会话页统一分离验收与关闭动作。待核验任务即使移除了会话，仍可独立验收或拒绝。旧会话深链作为只读记录仍可打开；关闭后不显示“进入会话”或可发送的输入区，未发送草稿以只读内容保留。

## 用户故事

1. 作为手机用户，我可移除截图中十几天前的会话；它从项目列表消失，但首页任务中仍能找到任务、文件及过程。
2. 作为验收人，我移除待核验会话后，任务仍是待核验；只有按“验收”才改变结论。
3. 作为开发者，我关闭已失败的会话后，失败状态和未提交文件保留，工作区由我另行收尾。
4. 作为执行中任务的用户，我确认关闭后先停止执行及其子任务，资源状态确定后才移除；未知结果保持可恢复的错误状态。
5. 作为历史记录的读者，我能使用旧链接查看对话，不能向已移除的会话发送新指令。

## 技术设计

沿用现有身份：`tasks.id` 与 `native_sessions.id` 分别作为任务与会话主键，`task_id` 只记录关联。沿用 `task_session_closures` 的持久关闭栅栏和 `task.close_session` 作业，不删除任务、会话日志、转录或交付物，不增加重复的状态表。已关闭会话继续由列表查询排除，按 ID 的历史查询保留权限检查。

- `dispatch/task_sessions.py`：移除隐式验收与工作区清理依赖；保留 owner/revision/runId 校验、幂等、取消、资源释放与未知结果保护。子任务已关闭但仍待核验不阻塞父会话关闭。
- `app.py`：关闭服务仅注入数据库和执行器，不再注入验收及清理回调；删除仅用于隐式清理的 Python 模块，工作区收尾沿用项目入口。
- `NativeProjectSessions.tsx`：行尾提供独立按钮；点击时读取任务当前 revision/runId，提交既有 `/tasks/:id/close-session`，避免逐行请求和过期身份操作。父组件传入条目时复用父级刷新。
- `AgentTasks.tsx`：验收只调用 `/verify`；关闭只调用 `/close-session`；已关闭会话入口使用“查看会话记录”。
- `NativeSession.tsx`：关闭动作与任务详情一致，关闭后保留只读对话、过程、产物和任务链接。
- `MobileSessions.tsx`：原有项目分组继续展示内置会话，刷新复用现有请求；保留没有 CLI 会话的项目入口，内置会话标题参与搜索，全部和项目计数包含内置会话。
- 中英文 locale 同步更新；样式使用现有令牌、SVG、粗指针命中区和 hover 限制。

兼容性：不修改旧任务状态，不回写过去已完成的任务，不重建已关闭会话。`close-session` 路径保留，语义收窄为关闭会话。工作区仍从项目收尾入口管理。继续工作需要发起新任务；本次不增加“恢复已删除会话”动作。

## 实施前自审

第一轮（概念）：仅加删除按钮不够，旧关闭接口还会自动验收。必须同时移除后端副作用和前端合并动作。

第二轮（数据）：不硬删除 `native_sessions` 或来源消息，否则转录、日志归档和任务详情关联会断。使用现有关闭状态作为逻辑移除，历史查询只读可达。

第三轮（并发）：关闭请求必须绑定最新 revision/runId；关闭栅栏先于取消及执行器关闭。进行中任务通过持久作业处理，失败不消失，重复请求不能重复关闭。子任务的“会话关闭”和“任务已验收”不能再混为一个条件。

第四轮（交互）：删除任务与删除会话不能用同一个文案；项目列表用“移除会话”，任务验收保留独立按钮。关闭状态不能覆盖任务失败或待核验状态。桌面/手机均有明确入口，手机不依赖 hover 或长按。

## 验收计划

- Python 回归：关闭待核验、成功、失败会话不更改任务结论；不调用清理；重复关闭、权限、过期版本、活动取消、父子会话、未知结果保护；关闭后列表隐藏而任务与转录可读取，仍可独立验收。
- 前端回归：行按钮不打开会话，按需加载关闭身份，失败可重试；验收不关闭；关闭后历史入口和只读状态正确。
- 全量前端门禁、Python lint/format/tests、仓库 quality quick/full（按提交/PR范围）。
- 隔离实例验证桌面 1280/1920/2560/3440 与 Android 真机：关闭前后、失败反馈、任务记录留存、真实点按及无溢出。
