当前 token 口径

参考 Pi：优先使用有效模型 usage，加上新增消息的字符数 / 4 估算；无 usage 时估算整次请求，包括系统提示与工具。默认输入预算 24,000 tokens，非模型窗口上限。切模型、压缩或遗忘后失效旧 usage。实测字符预估 4,223 tokens，模型 usage 校准为 6,780，追加消息后 6,880；上下文接口与 /status 一致。上方字节数字仅保留作旧故障溯源。

验收边界

旧会话可以追加消息；完整任务完成回报需要生命周期回调。Git 项目创建远程基准工作区需要选定远程来源。部分发送结果未知时，先核对目标端，不能自动重发。调用链只展示有界元数据，完整执行结果仍在任务记录内。
