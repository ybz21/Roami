# PDF 整页适配与跳页

## 产品设计

PDF 预览默认显示完整单页，同时提供“适合宽度”和 25%～400% 缩放。保留上一页、下一页，以可编辑页码代替只读页码；输入后回车或离开输入框跳转。单页文件隐藏分页，保留缩放。

桌面工具栏居中排列；窄桌面预览区允许换行。手机分页与适配选择合为一行，缩放档位收进选择菜单，支持双指捏合；下载入口放入既有返回栏。按钮、页码输入和缩放选项的触控区域至少 44px。

## 用户故事

- 查看竖版报告或横版演示时，不用滚动也能看到整页边界。
- 需要阅读小字时，切换到适合宽度或放大后在预览区内滚动。
- 长 PDF 可以直接输入目标页码；越界值定位到第一页或末页，空值和非整数恢复当前页。
- 调整窗口、分栏高度或翻到不同尺寸的页面后，当前适配模式继续生效。

## 技术设计

修改共享组件 `frontend/src/components/documents/PdfDocument.tsx`，文件、聊天附件、任务产物和 Office 转 PDF 入口统一生效，无新增接口或依赖。

- `ResizeObserver` 同时读取预览区宽、高；整页比例取宽高比例中的较小值，宽度模式只按宽度计算，百分比模式使用固定比例。
- 每页独立读取 PDF viewport，支持横竖版混排。
- Ant Design `Input` 处理页码草稿与提交，`Select` 提供适配及百分比选项。聚焦页码时选中现值，Escape 恢复当前页。
- 翻页重置内部滚动位置。缩放不以 CSS 压缩画布，放大后允许在预览区内滚动。
- 沿用稳定滚动条、离屏绘制、过期渲染取消和 800 万像素上限，重绘期间保留已完成画面。
- `pdf-pinch-zoom.ts` 负责双指手势：以双指中心保持阅读位置，移动时只缩放已显示位图，结束后绘制目标清晰度；取消手势恢复原尺寸及滚动位置，单指交给原生滚动。
- 手机 `MobileFilePreview` 将本机 PDF 路径直接交给 `DocumentPreview`，减少额外文件预览层；下载复用 `MobileSubPage` 顶部动作位，并保留真正的下载链接语义和原节点地址。
- 样式集中在 `document-preview.css`，顶部下载链接使用现有手机返回栏样式；新增文案同时进入中英文语言包。

## 手机版补充优化与验收

在 PR #532 的基础上减少手机预览的工具栏占用。使用同一六页 PDF、同一 Redmi Note 8 验证，记录存放在 `/tmp/roami-pdf-mobile-check/`。

- 下载从单独一行移入返回栏，分页和适配模式合成一行；阅读区从约 524px 增至 628px。常用档位通过缩放菜单选择，桌面仍显示放大、缩小按钮。
- 返回、下载、搜索、前后翻页、页码输入及缩放选择的命中区域均至少 44px；菜单选项保持 44px，正文独立滚动，页面无横向溢出。
- 在真机通过 CDP 输入双指手势，页面从约 65.5% 放大至约 160%。手势期间画布像素宽度保持 786，松手后变为 1917；浏览器视口缩放始终为 1，滚动位置保持在双指中心附近。
- 缩放后用 ADB 单指上滑，scrollTop 从约 355 增至 689。ADB 点按分页、输入 5 并确认，成功跳页且键盘收起；恢复整页适配后页面边界完整可见。
- 本机 PDF 查询路径直接打开文档预览，保留原始 URL 及文件名下载，不再进入文件编辑器外壳；已有 Markdown 路径仍使用文件查看器。跨节点附件下载回归通过。
- 组件增加手势提交、取消与原生单指滚动回归，覆盖不在固定档位中的缩放百分比；Markdown 预览增加单一返回栏、顶部下载及本机 PDF 路径回归。
- 前端全量 147 文件、1111 条用例通过；typecheck、i18n、hover、生产构建和完整质量门禁通过。中文深色与英文浅色均无工具栏溢出。
