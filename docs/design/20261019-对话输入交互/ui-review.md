# 主对话与管理页逐项 UI 审查

本轮覆盖输入区、待发队列、加号菜单、模型 / 强度面板、记忆页、能力管理六处。沿用现有组件、设计 token 与路由，没有改动鉴权或增加新协议。

| 区域 | 具体问题 | 最终处理 |
| --- | --- | --- |
| 输入区 | 常驻上下文行抢占高度；默认“对话”入口与加号交办任务重复，挤压模型名 | 用量移入加号；默认只保留添加、模型 / 强度与发送。交办模式保留切回对话入口 |
| 加号 | 用量与手动压缩相隔，入口层级不明确 | 顶部相邻展示用量和压缩；点击用量先关闭菜单再开详情，关闭菜单不请求用量 |
| 待发队列 | 手机全局按钮内边距覆盖了紧凑样式，正文空间不足 | 粗指针队列单独收敛内边距，保留扩展触区；首条、数量、优先执行、删除与更多仍可操作 |
| 模型与强度 | 容易误提交、长名不易确认 | 检查同面板暂选 / 应用 / 取消，顶部完整模型名可选取，输入栏与列表统一省略；菜单与输入框对齐、遮罩隔离 |
| 记忆 | 内容与每日计数混排，来源弹窗无法辨认对应记忆，时间没有时区 | 默认记忆内容，足迹独立按日；来源标题带记忆名，时间含时区；正文展开、来源查看、搜索清除与遗忘确认保留 |
| 每日足迹 | 失败与中断和成功计数视觉相同；无数据容易误认零 | 非零失败 / 中断使用已有危险 / 提示色，未知仍显示未记录 |
| 能力管理 | 顺序不符合使用频率；内置固定项同时展示“固定 / 已启用”重复 | Skill / CLI / MCP / 工具，默认 Skill；固定项省掉重复启用标签，内置只读、外部启停规则保持 |

## 实际验证

- 完整质量检查通过：Go、Ruff、Python 575 项、前端类型、i18n 2975 keys、hover、生产构建和密钥扫描；前端 Vitest 97 文件 / 692 项通过。
- 真实桌面浏览器与 Redmi Note 8 触屏：加号对齐输入卡片且不越界，上下文只在加号内，手动压缩不重复，打开详情时加号关闭；模型面板完整名称、暂选取消不改变配置。
- 真实 Go / Python / SQLite / SSE 与可控供应商：忙时入队、优先执行、保留其余草稿、暂停、刷新恢复及 FIFO；每条最终用户消息只落库一次。手机队列正文剩余宽度至少 100px，无水平溢出。
- 记忆通过真实接口写入带来源的隔离记录，验证内容 / 足迹、搜索、来源消息、更多动作。每日统计为隔离夹具，不冒充生产使用量。能力顺序、四项底栏与手机触控通过。
- 全部交互验收在独立数据根完成，没有向生产主对话写测试消息。真实主模型此前返回 HTTP 401，因此可控供应商链路不代表真实主模型语义判断已通过。

原型与历史布局由 README 按时间保留；本轮最新截图随 PR 发布到 pr-shots，不提交到 main。
