分类说明与归置规则

Product Design

左栏固定为使用偏好、智能体、通知与输入、设备与连接、系统与账户五组。分组是文字标题，页面直接可点，不再折叠一层目录；不显示设置项计数。当前可见的 15 个页面全部保留，开发版额外显示“自我改进”。

按用途查找，生效范围放到右侧具体设置中。已有统一记忆不离开设置框架；模型配置、代理与计费、模型单价沿用同页三个 Tab。

User Stories

  1. 我能在使用偏好中找到外观、布局、快捷键和会话交互。
  2. 我能分别找到智能体能力、通知与输入、设备连接和系统管理，不用先理解配置存在哪里。
  3. 手机上看到相同分组；进入一项后可直接返回分类。

Technical Design

正式落地时由 registry.tsx 同时生成桌面分组、手机列表和搜索索引；保留现有页面 ID 与路由。“新会话”改名“会话与交互”，“网络加速”改名“网络与传输”，RSI 在开发版中归入智能体并改名“自我改进”。全屏从外观移到布局，退出登录移到安全；移除按存储位置划分的左栏段落。

本稿直接保存在 AGENTS.md 的 HTML 区块，独立预览从该区块生成，主题令牌来自现有 theme.tsx，响应式复用 layout.ts。不改业务组件、不读写真实设置。中文属于开发者设计稿，不新增产品 i18n 文案；正式落地时补齐中英文。

现有清单里未出现在导航中的会话内存护栏不新增入口。关于页保留证书引导链接，证书操作归安全页。新分组不改变权限、跨 Tab 草稿、保存时机或网络配置的生效范围。
