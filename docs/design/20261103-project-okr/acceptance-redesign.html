产品与故事

首页仅展示已保存目标的项目。新建时选择一个尚未建目标的项目，打开搭建页；浏览或选择项目不产生空目标。以 Roami 宣传为例，先与独立 Main Agent 聊清目标、KR、指标与来源，确认后保存。首屏展示目标、长期与短期 KR、真实进度、日期趋势和下一步行动。
