展示层采用什么形式

先采用配置驱动的 HTML：React 读取已存在的项目 JSON、任务记录、日期数据和产物，使用注册组件展示。数据来自代码、脚本或模型都使用同一协议，不依赖对话搭建器。

自由 HTML 展示包属于第二阶段可选扩展：隔离呈现、只读数据绑定，控制动作由宿主执行；不向展示页面交出账号凭据、Shell 或数据库。第三阶段模型再生成这些经过校验的定义，而不是生成不可核验的完成画面。
