手机主导航原型

点击原型的底部按钮，可切换四个目的地；顶部通知进入跨项目事件流。

各 Tab 的职责

  • 首页：状态摘要、最近会话和活跃项目。
  • 项目：项目、工作区、会话和新建任务。
  • 工具：文件、浏览器、手机与插件。
  • 设置：节点、推送、外观、安装与账户。

自评与修正
