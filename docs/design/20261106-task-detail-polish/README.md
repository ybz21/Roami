# 后台任务详情展示优化

基于 [PR #718](https://github.com/ybz21/Roami/pull/718)，沿用其正文去重与折叠下发说明。

## 任务与对话管理（新增设计）

针对后续反馈补充[生命周期设计](lifecycle.md)与[可点原型](lifecycle.html)，涵盖任务状态、进入对话、关闭任务、关闭对话和删除对话。此部分是交互提案，尚未接入产品接口；下面的已实现验收记录对应前一版展示优化。

## Product Design

任务详情先展示执行结果与可用交付，再展示原始任务内容。标题、真实状态、执行器、版本与工作分支组成身份区；状态紧随标题，避免宽屏拉开。结果摘要保持完整，正文维持三行展开。宽容器主内容与执行侧栏采用同底、单线分隔；窄容器保持单列。

外部命令显示用途标签，长命令完整换行，复制按钮独立可达。工作分支使用元信息字号与已有间距令牌。

## User Stories

- 查看已结束的任务时，先找到结果、PR 和文件，再按需展开要求与执行记录。
- 在手机或窄工作台中阅读时，状态、分支与命令仍可读，折叠操作可直接触达。
- 在宽屏中阅读时，标题与状态保持相邻，产物按可用宽度分列。

## Technical Design

- `AgentTasks.tsx`：语义化身份区；结果与产物前置，任务正文置于执行记录之前。
- `TaskDispatch.tsx`：命令用途标签，保留现有复制行为与 i18n 文案。
- `agent-tasks.css`：容器查询统一两栏规则；侧栏单条分隔线；产物自适应列；解除结果摘要的三行截断；所有改动使用已有设计令牌。
- 不新增依赖、请求或轮询。
