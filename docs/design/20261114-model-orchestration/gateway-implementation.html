本机网关实现与插件账号快捷入口

专题首页 逐页设计 统一原型 历史归档

基于 本机网关交互稿 实现。能力顶部和大模型左侧导航保留；接入与密钥、模型目录继续作为网关内部页签。

Product Design

接入地址和 curl / Python 示例并排展示，编辑器展开后按可用内容宽度自动换列。示例仅列出已保存、已启用且存在可用来源的模型，凭据通过环境变量引用；回环地址明确标注只用于宿主。手机默认折叠示例。

Key 使用统一列表，展示名称、末尾标识和启停状态。新建、改名、固定 Key 设置进入桌面检查器或手机全屏页，分别保留草稿。轮换与删除继续确认影响；生成或轮换后仅临时显示明文，离开页签或迟到响应均不重新展示。固定 Key 替换增加旧值立即失效的确认。

模型目录显示对外调用名称，并在详情中区分上游 ID、来源、上下文、公布能力与标价。没有数据时保留“未提供”，不将未知值当零。支持按来源、类型、能力和名称筛选；仅上游目录模型引导先在源内启用。原有目录分页和 revision 缓存保留，隐藏页暂停尚未完成的目录读取。

用户随后要求从已有插件快速添加账号：插件源卡片增加“添加账号”，调用现有克隆入口创建独立账号源，并在新账号连接页展开授权区。原账号保持独立；普通 API 卡片保持查看入口。

Technical Design

  • ModelGatewayWorkspace 负责两个页签和接入摘要；gateway-call-example 约束示例模型范围、回环地址识别和示例转义。
  • GatewayAccessKeys 管理具名 Key 列表和一次性凭据；gateway-fixed-key / GatewayAccessKey 保留固定 Key 独立接口、revision 校验与错误恢复。
  • 后端具名 Key 列表原本已经包含固定 Key。固定 Key 元数据仅补充现有非敏感 id，让界面精确识别该行，不按名称或后缀猜测，也不重复追加。
  • GatewayInspector 使用既有返回按钮和 MobileSubPage；检查器关闭后释放空间，并回到触发操作。
  • GatewayModelDirectory 保留源所有权和网关 ID 映射，调用源详情或聚合详情时走真实导航。
  • ModelHub.addAccount 复用现有插件账号创建；卡片按钮与整卡查看按钮为独立点击目标，新增账号授权区默认展开。

没有新增接口规范，没有变更计价、限额、调度算法或监控 24 小时滚动与空间上限。新增产品文案进入中英文统一语言包。静态交互稿保留为设计历史。

  • 类型、国际化、悬停规则、生产构建、Go 模型网关测试、完整与快速质量入口通过。

  • Redmi Note 8 经 LAN HTTPS 硬刷新验证输入、一次性凭据、停用确认、模型目录筛选、全屏详情返回、错误保留与内容滚动。
  • 插件账号快捷入口在桌面和真机使用合成插件传输验证单次创建、原账号保留和授权区展开，没有创建或登录真实外部账号。
