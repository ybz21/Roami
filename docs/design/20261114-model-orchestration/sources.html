左侧选来源，右侧管它的连接、模型和定价。发现出来的模型默认不启用，启用后才进入网关和选模。

行为

新建来源按类型分流
API 连接填地址和密钥；OpenRouter 免费用固定地址，验证后直接列出免费候选；插件走插件与账号，授权完回到这里发现模型。
先保存连接，再启用模型
名称是连接表单首项，留空时用服务地址命名。新建来源修改地址后只可保存连接或重新拉取目录，旧目录的勾选随之清除。已有连接取消编辑时恢复原地址和原勾选。
选择连接与证书策略
HTTP 地址显示明文传输提示。HTTPS 默认验证证书，可信自签名服务可在连接选项调整验证策略。更换地址会清除旧地址的证书例外。查看连接配置验收记录。
发现和启用是两步
发现失败时保留上次成功的结果和当前的启用选择。检测超时的模型维持「未检测」，不改写成失败。
删除要先处理引用
来源或模型被聚合、草稿或智能体默认使用时，删除按钮不可用，并列出这些引用和各自的入口。服务端保存时再查一次。
定价分三层
来源默认价、单个模型的覆盖价、最终生效价分开显示。没有规则就写「价格未知」，不显示 0。
