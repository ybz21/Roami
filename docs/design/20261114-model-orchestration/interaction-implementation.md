# 大模型工作区交互落地

2026-11-16。依据 [已确认交互稿](interaction-design.md) 和 [离线原型](./history/prototypes/interaction-prototype.html)，沿用 Roami 的设计令牌、antd 与现有 Radix 控件。保留能力导航和大模型的七个 Tab。

## Product Design

| 页面 | 正式行为 |
| --- | --- |
| 模型源 | 卡片统一尺寸，支持按名称、地址、已启用模型搜索以及 API / 本地服务、插件账号筛选。源详情默认展示连接摘要和已启用模型，管理时才展开勾选、搜索和保存；修改连接与修改模型分别进行，取消恢复原选择。 |
| 定价 | 源默认与单模型共用右侧检查器，手机全屏编辑；只保存当前范围。列表继续显示后端计算的生效价和来源。待保存规则展示基础单价，明确说明倍率与分时规则另行生效，避免把草稿冒充已生效价格。 |
| 聚合 | 继承已实现的左侧选源、右侧选该源模型、跨源成员池、拖拽排序和策略预览，增加列表搜索；模型身份和模型源范围仍以已保存目录为准。 |
| 概况 / 审计 | 概况只展示汇总、额度与趋势，额度收为紧凑摘要，缓存与结算说明按需展开。按模型、源、智能体和小时查看；下钻的筛选写进 URL，刷新审计恢复对应条件。 |
| 监控 | 手机将源与模型筛选按需展开，保留当前条件；无样本指标显示未检测。切换检查目标会中止旧检查并清空旧反馈。沿用一天滚动保留及现有容量上限。 |
| 本机网关 | 接入与密钥、模型目录分开。新增时才填名称，行尾菜单管理密钥；切换大模型 Tab 保留创建草稿，离开页面隐藏并清除已展示的一次性明文。目录区分已接入与仅上游模型，并使用源自己的主模型范围。 |
| 语音输入 | 默认查看当前服务摘要，明确编辑后才出现服务相关字段；取消恢复原配置，切换服务保留其他服务参数。 |

## User Stories

- 查看一个源时，先识别已接入的模型，再选择修改连接或管理模型；普通查看没有待保存表单。
- 改一个模型价格时，确认币种、计价单位与保存范围，输入后看到草稿预览；另一个范围的未保存价格不会夹带提交。
- 维护聚合时，按源找到已配置模型，切源不丢选择；进入调度查看策略效果，再对成员排序。
- 从某个模型或时段检查请求时，进入审计并保留条件，刷新仍能看到同一筛选范围。
- 为新调用方生成 Key 时，先命名再创建；稍后切回仍保留尚未提交的名称，明文只在生成时查看。

## Technical Design

- `ModelHub.tsx` 保持路由、源 / 原生模型草稿和跨页数据所有权，新增源筛选与原生模型对外 ID 编辑。保存替换原条目，保留旧 ID 为别名，不改变上游模型 ID。
- `ModelSourceEditor.tsx` 的源草稿增加管理状态。只读、连接编辑与模型管理有独立入口和退出；管理过程中禁止直接跳进连接编辑，防止保存范围不明确。
- `SourcePricingSettings.tsx` 复用现有 `scope=default/model/account` 接口，源默认编辑也走检查器。基础价格预览独立于后端当前生效价，不复制后端的倍率、分时或价格继承算法。
- `ModelGatewayWorkspace.tsx` 承载两个网关任务区，在第一次进入后保留已挂载草稿；目录按需首次挂载，密钥读取没有新增轮询。离开密钥区后不再显示一次性明文。
- `model-usage-workspace-state.ts` 序列化审计筛选，并校验初始 URL 中的日期、小时与范围；时区继续通过浏览器自动探测，额度结算时区保持后端配置。
- Go 侧复用现有模型别名校验，扩展至原生模型。保留同一拥有者、模型类型、协议、历史 ID、32 别名上限和全局名称唯一性约束；不新增接口或请求路由算法。
- 新增可见文案全部进入现有中英文语言包。运行时没有演示开关、固定指标、真实账号样例或前端计价替代逻辑。
