产品设计与用户故事

  • 模型源只管理连接和已选模型，移除页底“正在使用”列表；使用方在网关模型行与详情中查看。
  • 网关默认进入模型目录，聚合模型优先，单模型随后；未接入的上游目录独立展示。
  • Main 选模与网关复用目录、价格与能力数据；模型名称、调用 ID、输入/输出、工具、推理和价格状态同时可见，长 ID 单行省略且可搜索完整值。
  • 源名称 openrouter-free 仅标识用户保存的来源，不作为价格依据。上游正价格明确标为付费；零 Token 标价单独标识为未确认免费；仅免费筛选只接纳确认免费路线或已保存的仅免费策略。
  • 聚合能力与费用说明由实际成员决定，不把成员能力并集当作每次请求保证；未声明的输入输出保持未知。

技术设计

沿用 Go 网关 /agent/model-gateway/models，补充已有来源元数据中的输入、输出模态及付费标价分类。配置路线保持主身份，来源发现不创建或启用路线；元数据仍使用现有修订和凭据指纹约束。聚合优先顺序同时用于网关 CLI。

前端通过既有 Agent 数据缓存共享显式目录请求、合并同时发起的读取，30 秒有效期，无新增轮询。沿用 PR #947 的 gateway-model-catalog 与 ModelCapabilities，提供配置路线映射和能力/价格展示，Main 与网关共同使用。直接连接当前模型与同源网关路线合并显示，点当前选项不会重写配置；其余选模继续走原有角色绑定接口。模型源页移除重复使用列表及孤立样式。

未增加 Python 逻辑、数据库结构、账户价格规则或模型调度服务；未修改用户保存的源名称、调用 ID、模型选择与密钥。
