聚合优先与网关目录统一

专题首页 逐页设计 统一原型 专题归档

日期：2026-11-17。

Product Design

首页 Main/Worker 选择器与本机网关模型目录统一读取 Go 网关目录。选择器先列聚合，再列单模型；当前选择仍有勾选状态。搜索放在标题下，节点范围提示移到列表底部；普通行展示名称和输入输出能力，同名行额外显示调用 ID。手机继续使用全屏二级页。

网关默认展示全部已添加模型，聚合排在前面，保留聚合、已接入模型与上游目录筛选。上游模型仍需接入后才能调用。源声明的能力明确标注；未提供能力显示未知，聚合不把成员能力并集当作调用保证。

User Stories

  • 打开首页选择器，先找到聚合，再按名称或调用 ID 搜索模型，并看到输入、输出及工具等能力。
  • 从本机网关查看同一条路线的相同能力、上下文与最大输出；详情中仍能区分调用 ID 和上游模型 ID。
  • 能力源读取失败时保留已添加路线，允许重试，不改变已保存选择。

Technical Design

  • internal/modelgateway/model-directory.go：已有 /v1/model-gateway/models 补齐输入输出模态、上下文、最大输出和公布标价；排序为已配置优先、聚合优先。能力刷新截止时间为 12 秒，留在前端共享请求的 15 秒预算内。CLI JSON 自动获得相同字段。
  • gateway-model-catalog.ts：首页与网关复用节点范围缓存和在途请求；按目录修订隔离能力证据，五分钟内复用读取结果，无新增轮询。
  • ModelCapabilities.tsx：两处共用能力展示和中英文文案。
  • useAgentModels.ts：绑定网关的角色使用目录中的已配置 ID；直连服务商保留现有入口，并按源地址关联能力，防止同 ID 跨源误认。写入继续走现有角色配置接口。
  • GatewayModelDirectory.tsx：移除逐源发现和另一套列表拼装，统一使用网关行；保留搜索、来源/能力/类型筛选、分页、复制和详情返回。
