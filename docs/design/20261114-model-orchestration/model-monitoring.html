  • 先标出限流、鉴权、超时、流中断、连接失败和其他。点柱或类别时带入时间、来源、模型及失败条件。首版跳转使用审计现有的日期或小时范围，并标明实际查询范围。分钟级范围和细分错误类别等查询支持就绪后再启用。
  • 没流量显示「该时段暂无调用」，指标无法计算时显示「样本不足」。图例、计数和文字一起表达成功与失败。最后一个未结束的桶标为「进行中」。
  • 现有趋势可切到首字延迟 P95。采集齐全后再加入 P50/P99 和整体耗时切换。吞吐单独用 Token/s，进程 CPU、内存与在途请求放在诊断详情。
  • 保留可见时自动更新。查看某一时段后固定选中的时间范围，返回实时视图时再跟随最新数据。
