    技术设计

    聚合调度

    「成员」用于增删成员。「调度」首屏按当前生效顺序显示可调度成员的顺位，其后列出跳过的成员及原因。额度、重置时间和冷却在成员行内展示或展开。「调度规则」复用现有策略和成员顺序编辑器，应用后更新首屏顺位和当前优先候选。

    • AggregationEditor 只提供成员和调度页签，把 AggregationRuntime 的额度与时间信息放入成员详情，由 useRoutingStatus 在可见时共享一份响应。沿用按配置版本失效、隐藏暂停和失败退避。
    • routingView 已按实际策略返回 channels。界面以可用渠道在响应中首次出现的位置为准，按来源和上游模型去重生成成员顺位。首行与「当前优先」共用该结果，展开后保留各账号的渠道顺序。手动策略下顺位沿用已保存的成员顺序并跳过受限项。单次请求按实际需求继续筛选。
    • 最近调用按聚合路由 ID 从同一份监控记录提取，可打开真实记录。现有记录已有 RouteID，现有监控读接口需补路由筛选。只有存在关联证据时才展开重试与切换过程。缺少调用记录时显示「暂无调用」，来源首字 P95 保留来源口径。
    • 跳过的成员显示冷却、额度耗尽、能力不匹配或目录无法核验。无可调度成员时全部显示跳过。有可计算的恢复时间时，取各候选同时满足冷却与额度约束后的最早时间，使用「预计可尝试」。

    模型源与 API 协议

    创建、类型筛选和来源卡片共用三种来源类型。「OpenRouter 免费模型」「API 连接」「Magpie 插件」。API 协议在卡片和表单单列，可选 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages。API 连接可填云服务或本地服务地址。

    ModelHub 复用一个类型映射生成菜单、筛选和卡片标签。按 connector 和 pluginSourceId 判断，通用连接显示为 API 连接。已有 OpenRouter 通用连接通过「修改连接」显式切换。新建只显示上述三项。

    Magpie 插件

    • 新建 Magpie 插件直接填插件路径。支持兼容清单内的 GitHub 插件目录链接和仓库相对路径，例如 packages/workbuddy。输入框旁提供上游目录和说明入口，ZIP 或文件夹上传作为备用入口。Magpie 社区插件目录 · 插件说明
    • 识别时把路径解析为兼容清单里的项目和固定版本，检查当前节点并展示结果。确认发布者、版本和节点要求后，按清单下载固定包并复用现有包校验与隔离执行。
    • 上游 magpie://import 链接用于导入提供方连接。Roami 的插件链接接入独立使用插件包和版本确认流程。豆包工作按目标节点的实际系统和桌面应用状态展示。Magpie 导入链接说明

    已安装插件与更新

    「模型源 → 已安装插件」按插件包展示已安装版本、上游版本、兼容状态和最近检查时间。来源卡片的「查看插件」打开对应记录。同一包服务多个账号时，在一次更新确认里列出受影响的账号。

    2026 年 11 月 19 日核对到本机 WorkBuddy 0.2.26、豆包工作 0.1.5。分发索引分别列出 0.2.36 和 0.1.13，兼容状态待验证。原型的 0.2.27 只用于演示更新与回退。[上游分发索引]

    • 现有 plugins/packages 提供本地包名与版本。为可追溯的插件记录包名、发布源、已安装版本与校验摘要。服务端在用户查看时按有效缓存检查已绑定的 npm 发布信息或 Magpie 分发索引。手动上传且来源不明的包显示「来源未绑定」，用户可以随后绑定。Magpie 发布与校验规则
    • 上游版本更新后显示「有新版」。通过 Roami 兼容清单和目标节点检查后才给「更新」操作。超时显示最后一次结果和检查时间，并允许重试。保持可见的版本状态与可执行的更新条件一致。
    • 确认后下载固定版本、校验完整性并在隔离环境验证插件清单、可用模型和账号配置兼容性。待正在执行的请求结束后再切包。包 ID 变更与配置指向需一次性应用，失败时继续使用原包。保留上一版本及其对应配置用于回退；新旧格式不兼容时提示所需操作。

    验收

    打开聚合即可看出调度顺位、跳过原因和最近一次实际命中。手机在单一滚动区查看同样信息。应用规则后，顺位与当前优先同时更新。新建、筛选和保存后的卡片类型逐一对应。验证正常、无可用、规则草稿、链接识别失败、节点不兼容、版本更新和回退。
