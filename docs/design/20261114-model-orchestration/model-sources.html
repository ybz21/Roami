连接、模型与定价

来源详情默认显示连接摘要和已启用模型。「修改连接」处理连接字段，「管理模型」显示本次新增和移除。源默认价、模型级规则和当前生效价各自可查。

移除模型与删除来源

在「管理模型」取消勾选即可移除单个模型。应用前展示变更数量并确认。来源详情的「连接」首屏提供「删除来源」，确认显示来源名称，并提示将同时移除已启用模型。删除成功后回到来源列表。

有聚合、备用路由、草稿或模型绑定引用时，详情列出相关模型，用户解除引用后再删除。服务端保存时再次校验引用。Magpie 来源删除沿用账号解绑逻辑，插件安装和版本操作仍在插件详情。

导入 Magpie 社区插件

打开完整插件目录

进入「新建 → 导入模型插件」自动读取 Magpie 的公开 registry.json。沿用生产目录接口的范围，展示有供应商的社区插件，默认同时列出已安装和未安装项。GitHub 不可达时尝试 jsDelivr 镜像，仍无法连接时显示随包快照并提供重试。搜索接受名称、包名、供应商、路径和对应 GitHub 链接。

「检查更新」读取发布索引。初始化显示快照中的发行版本，点「检查更新」后核对线上版本。ZIP 和文件夹入口在「从文件导入」。

下载来源可选 GitHub 官方、国内加速（jsDelivr）或 gh-hk。加速节点失败时尝试备用地址。包的版本与 SHA-512 来自分发索引，索引优先直连 GitHub。包校验通过后沿用只读插件包和现有宿主检查，账号授权在创建来源后进行。

技术设计

数据来源与处理
插件账号保留现有包、供应商和账号引用。复用 Go 网关的 AccountQuota 与配额缓存，按账号开放受控签到动作，结果回到同一账号。安装版本与兼容性沿用插件管理。插件包和授权凭据各有独立生命周期。

账号入口

同一个插件可以管理多个已授权账号，入口定位到对应账号。读取积分和签到分别使用该账号自己的权限，沿用账号现有模型范围。
