现在能调什么，怎么接

只列已启用、可调用的模型，聚合排在前面。调用名单独可复制。密钥和目录在同一页，但密钥只在创建时完整显示一次。

行为

目录和发现是两套清单
这一页只出现已启用的模型。供应商那边发现了但没启用的，留在模型源，不进这里，也不进选模。
密钥只完整出现一次
新建或轮换时显示完整值，之后列表只留名称、用途和尾号。吊销立即生效，用这把密钥发出的历史请求仍可在审计里按时间和来源查到。
两种密钥不混用
这里发的是网关访问密钥，只能调模型。供应商凭据在模型源里管理，外部程序拿不到。
试调算一次真实请求
接入页可以发一次试调，结果直接链到请求记录。它会消耗额度，按钮旁写明这一点。
