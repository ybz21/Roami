这次用哪个模型

新建会话和委派共用一个选择器。三个选项：沿用角色默认、Auto、指定模型。费用策略只对这一次生效。候选和排除原因来自网关目录，不另维护一份清单。

行为

默认和本次选择互不影响
设置页改的是 Main 和 Worker 的默认模型。「沿用默认」显示当前用的是哪个角色的哪个模型。会话里的显式选择只存在于这一次。
指定模型时说清差在哪
选一个能力未验证的模型，保留选择并写明哪一项没确认，同时给出符合条件的替代。不直接禁掉。
Auto 事后说人话
创建时展示符合条件的候选和被排除的原因。跑起来之后，会话里显示这一轮实际命中的模型，点开能看到原因，并链到审计记录。
等额度时不丢进度
仅免费任务没有可用候选时，显示原因和下一次可试的时间，已完成的步骤保留。没有确切恢复时间就如实写「时间未知」，并允许改策略或取消。改用付费模型要先确认变更费用策略。
