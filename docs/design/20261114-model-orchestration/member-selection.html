Product Design

用户确认：“应该左边源，右边切到每个源的时候把它选出到池子里”。保留能力顶部与模型左侧导航、聚合成员 / 调度 / 运行标签，以及现有设计系统。此次只调整成员选择，不替换视觉系统。

聚合池位于选择区上方，直接展示跨源成员、来源和移除。下方左列列出模型源及“已选 / 可选”数量，右列随源切换显示已配置模型。默认展开第一个源，点击模型卡或复选框加入池中；切换源不自动选中，也不清除已选。

一个模型无需搜索和全选。超过八个模型出现搜索；多个模型允许全选此源或搜索结果，超过三十个分页。历史未在源中启用的成员保留在池中并标记，标题显示数量，由用户显式移除。手机已选成员横向滑动，避免挤占模型列表高度。

User Stories

  • 我先看到源列表，切换后只看到这个源里已配置的模型。
  • 我能跨源加入模型，随时核对池内成员，不用进入另一个“已选”视图。
  • 我能直接移除任意来源的成员，模型卡的勾选同步变化；不同源中的同名模型互不影响。
  • 我能全选当前源或搜索结果，返回列表后继续草稿，保存后读回相同顺序。
  • 我在手机上仍然从左侧选源、右侧选模型，整张模型卡可点，移除按钮始终显示。

Technical Design

AggregationMemberPicker.tsx 用源按钮列表替代源下拉框与 @selected 伪源；池成员始终展示。已选身份仍使用 candidateIdentity，保持插入顺序和按身份绑定的权重。移除只删除对应候选及其权重，首次加入成员沿用源 / 嵌套路由组协议。

原生模型范围继续复用 configuredSourceModelIds，不读取上游目录，不把聚合引用或备用候选当作源内模型。@group 嵌套组入口保留，排除当前组。最多 64 个成员，超限全选禁用，不静默截断。

model-routing.css 用现有 token 实现左右分栏、紧凑池成员条与模型卡。桌面与手机都保留左右关系；手机缩窄源列，名称换行。源和模型列表独立滚动，聚合池和底部保存栏保持可见；展开更多设置后恢复编辑器滚动，保证短屏字段可达。没有新增 API、定价或调度语义。

Acceptance

隔离实例使用合成源和模型，不触碰生产配置。验收覆盖单模型、跨源选择与移除、搜索与分页、遗留未启用成员、空源、嵌套组、草稿、保存回读、桌面四档及用户截图宽度、安卓真机触摸。实际结果与截图路径记录在 acceptance.json 的 memberSelectionRevision。

255 个前端测试文件 / 1,843 项测试与完整质量门禁通过。桌面五档宽度、浅色英文、侧栏开关和 Redmi Note 8 实机流程通过。独立复核以用户原截图为主要证据，针对本次成员选择范围给出 ship，没有材料级修正项。保留既有 DESIGN.md 及 token 绑定，此次未产生设计系统变更。
