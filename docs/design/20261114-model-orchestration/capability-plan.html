任务与验收目标

  1. 接入者从未安装插件或 API 连接启用指定模型；同一个调用名在网关、CLI 和 Agent 可辨认。
  2. 工作流负责人创建会话或委派时选择能力和费用策略；任务恢复时看得见等待原因与实际命中。
  3. 值班与计费看到聚合不稳时追到一次请求和上游尝试；从费用异常找到对应额度及记账依据。

网关分层与共用能力

网关接口详版
  1. 人机交互Web、手机、CLI 和 Agent 使用同一个目录及状态词。列表使用展示名，接入与选模区提供调用名。
  2. 对外调用GET /v1/models 保留协议兼容形状；聊天、Responses 与 Messages 使用网关密钥。模型目录能力由 Roami 私有控制面读取。
  3. 控制接口已登录节点代理 /api/agent/model-gateway 映射私有 Unix socket /v1/model-gateway。目录、插件、策略、用量与观测分别授权；配置写入带修订。
目录契约与身份

展示名用于搜索。调用名在启用后稳定可复制，重命名通过别名兼容。目录独立保留上游 ID、源、聚合标志、协议、启用状态、输入输出与工具证据。保密字段分为来源授权凭据和网关访问密钥。roami model list --all --refresh --json 可以诊断已配置和发现项，日常选择器默认使用可调用目录。

调度、降级与费用契约

会话指定模型允许 --model 与 -model。原生会话 --free-only 和委派 freeOnly 属于请求策略；聚合选择器的免费筛选只影响添加时看到的候选。Go 网关对能力、冷却、配额及费用做准入。策略预览显示候选、顺位和排除原因；流开始后发生断流时记录终态，保留已发内容。

发布、一致性与访问

配置修改先校验引用和修订号，再原子发布。读模型目录携带可追踪修订与检测时间，后台更新保留最后一次成功结果。界面区分无数据、未检测、过期、权限不足。审计详情按节点与权限隔离，默认隐藏内部关联号和密钥。

实施顺序与验收门槛

先把基础能力定义清楚再排页面。第 2、3 条在基础目录具备后可并行，第 4 条在统一调度和观测可用后验收。

  1. 基础目录与接入

    定稿目录口径、调用名和证据，做完来源连接、发现、启用与删除。统一网关、CLI 与选模数据。

    • 模型目录与能力证据
    • 连接、发现与删除
    • 名称、调用标识与密钥

    仅启用一个来源模型后，对外调用目录、网关页面、CLI 和 Agent 候选可解释地一致；未检测状态有来源。

  2. 可解释的调度与观测

    发布策略、记录准入及尝试、统一费用与限额事件，再接聚合、概况、监控、审计和工作台。

    • 策略发布与调度
    • 来源健康与主动抽检
    • 请求、尝试与降级事件
    • 用量、计费与限额

    复现零尝试 503、候选耗尽 503、429 后恢复、HTTP 200 后断流。四种结论和账本能够互相跳转。

  3. 插件账号闭环

    与调度观测并行。复用接入基础，完成目录合并、版本迁移、解绑和 WorkBuddy 账号功能。

    • 插件与账号生命周期
    • 连接、发现与删除

    从尚未安装的条目创建来源；验证升级失败保留原版本与账号；能看积分和手动签到结果。

  4. 会话与长时任务

    复用已验证目录与调度，统一会话、委派与默认选模。语音使用独立现有适配器，可并行做测试闭环。

    • Agent 选模与任务约束
    • 语音输入服务
    • 用量、计费与限额

    固定选择能解释失败，Auto 能报告实际命中；无免费候选按上游恢复时间等待，任务可从断点继续。

跨页验收用例
  • 启用 WorkBuddy 的一个模型，验证其他已发现模型仍不会出现在调用目录；移除模型时，引用该模型的聚合可见并有恢复路径。
  • 复现 wb-ds 类 503。普通请求与显式仅免费请求走相同证据链；免费筛选状态不产生请求准入拒绝，真正的拒绝显示费用、能力或来源原因。
  • 发一条图片和工具调用任务。候选显示能力及其证据，未检测与不支持各自可见，无兼容候选时返回原因。
  • 回退插件版本后账号仍可用；撤销密钥后立即拒绝，原审计账本仍能按时间和来源查找。
  • 监控点异常进入审计与来源，返回后恢复同一时间窗、条目与焦点；桌面四档和安卓真机都可操作。
