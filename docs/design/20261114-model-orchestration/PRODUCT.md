# 模型工作台的产品事实

## Users

管理多个模型源、插件账号和模型路由的个人或团队开发者。桌面需要快速配置与排查，手机通过局域网完成同样的管理任务。

## Tasks

连接模型源，发现和管理模型，按源设置定价；把多个模型和账号组成可调用聚合，选择策略、调整顺序和权重，核对真实渠道状态并保存。

## Constraints

本阶段只改模型源和聚合及其共用导航。模型请求协议、已有价格规则、账号 Key、ID 别名兼容、64 成员限制和 24 小时滚动监控保持既有语义。CSS token、国际化、触屏命中与浏览器内滚动遵守仓库规则。

## Success

一条紧凑导航；策略和预览共处顶部，下方全宽成员列表；手柄拖动和键盘排序可用，快捷置顶/移除可发现；真实状态、能力和源延迟与未知清晰区分；完整完成模型源和聚合的保存与回读。

方向已由用户明确指定为 Linear/Vercel 深色后台风格与上下布局，采用 Tailwind + shadcn/Radix 逐步迁移。没有营销区块、虚构质量指标或付费能力声明。
