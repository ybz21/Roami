Product Design

面向管理多个 API、插件账号和聚合路由的用户。目标是在桌面和手机上都能看清当前配置、完成一个明确操作、核对生效范围，并能返回继续未完成的编辑。模式为 Operate；沿用 Roami 的中性深浅主题、字号、间距、控件和触摸规则，不替换现有视觉系统。

打开统一原型。文件可以离线打开。所有模型能力、价格、账号、请求和监控均为合成示例；授权、保存、Key 生成与质量检查只修改当前页面的演示状态，不连接真实服务。界面支持中英文与深浅主题。

能力顶部 Tabs、模型左侧 Tabs 及七个目的地保持：模型源、聚合、概况、监控、审计、本机网关、语音输入。手机使用原有的顶部模型导航，内容详情用全屏返回页。

走查结论

现状 交互调整 判断依据
连接页同时修改连接、读取目录、取消已启用模型，保存含义不够明确 默认只读摘要和已启用模型，显式进入连接编辑或模型管理 不让查看变成编辑，不让目录读取自动改变启用范围
定价表与编辑表单混排，继承规则难以核对 默认展示生效价和来源，编辑收进一个明确范围的检查器 模型单独规则、源默认和全局默认要可区分；未知不能显示为零
聚合在不同视图之间核对成员 左源、右侧源内模型，上方持续展示聚合池 延续用户明确确认的选择流程和 PR #935 的模型范围修复
策略文字与调度效果脱节 策略摘要与八次请求预览放在顶部，下面直接排序/设权重 操作与结果相邻，完整细则按需展开
概况堆叠限额、筛选和明细，分组与时间选择割裂 限额收为一行，概况只放汇总、趋势与分组；下钻统一进入审计 满足按模型、源、智能体、小时查看的既有需求
监控质量未知与零值容易混淆 未检查显示“未检测”，质量检查是明确的主动操作 不把无样本当作通过；监控保留与审计留存分开解释
网关凭据、调用示例和整个模型目录堆在一页 内部分为接入与密钥、模型目录 不改模型主导航，让接入操作与能力查找各有清楚入口
语音配置一直展开全部字段 默认展示当前服务摘要，修改后仅显示所选服务所需字段 保留其他服务的设置，减少重复填写

User Stories 与主流程

模型源

  • 列表卡片等高，整体点击进入；显示名称、类型、已启用模型数、少量模型名称、默认计费方式及连接状态。列表只提供新建、搜索和类型筛选。
  • 新建先选择 API、插件账号或本地服务。API / 本地服务先填名称、地址和 Key，高级协议设置折叠；插件继续使用既有授权能力。读取目录成功后进入选择模型，再明确保存。
  • 现有源先显示连接摘要和已启用模型。修改连接不顺带改变模型；管理模型时展示新增、移除数量。未保存的上游目录模型不能进入聚合。
  • 模型上游 ID 与网关名称分开，网关名称编辑在聚焦检查器中，不在每个列表行内铺表单。
  • 同一插件可新增独立账号源，每个实例独立连接、选模型、定价和调度。演示有两个 WorkBuddy 实例，可继续新增；不把一个插件来源误当成单账号限制。

定价

  • 默认只读：源默认方式、模型生效价、价格来源、输入 / 缓存读取 / 输出单价、币种与计价单位。
  • 点某个模型只编辑该模型；点默认定价只编辑源默认。切换计费方式时，只有按 Token 计费才出现三个单价字段；明确免费必须主动确认。
  • 检查器显示未保存的价格预览，与表中的当前生效价区分。取消恢复原规则；保存只影响当前范围。
  • 倍率与分时选项继续在高级设置中承载。实际实现沿用已有价格解析与请求价格快照，不新增计价算法。

聚合

  • 保留左侧源、右侧该源已启用模型、上方跨源池成员。切源保留选择；移除同步取消勾选；同名模型仍按源身份区分。
  • 默认自动生成对外 ID，常用创建只填名称和选成员；ID 与请求恢复参数按需展开。
  • 调度顶部放策略、短摘要和演示预览，下面全宽展示成员。拖拽手柄有键盘上下 / Home / End 操作；手机非手柄区域仍正常滚动。置顶和移除在触屏常显。
  • 策略定义、64 成员限制、成员权重身份和现有路由算法均保留。HTML 预览仅演示 UI 效果，轮流与权重序列随输入变化，不替代真实运行时调度。

概况、审计与监控

  • 概况默认展示今天，时间与时区由浏览器自动探测。请求量、总 Token、费用三个指标直接切换；按模型 / 源 / 智能体分组，按小时或天查看。
  • 手机将次要筛选收进“筛选”，保留当前筛选条；提供可直接选择小时的“查看时段”，避免要求手指精确点击窄柱。点时段或分组再点“查看这些请求”，把日期、源、模型、智能体和时段带入审计。概况不出现逐条请求详情。
  • 审计列表有状态和搜索，详情放回执、价格快照及失败原因。桌面用右侧检查器；手机用全屏详情。返回仍保留筛选。
  • 监控独立保存自己的源、模型和时间范围，避免与用量的历史时段互相污染。请求成功率、首字时间和质量分别解释，未检测与失败明确区分。
  • 监控仍为 24 小时滚动保留、64 MiB 上限，不保存对话正文。主动检查展示可能计费的提示；设计稿明确标为模拟，不发送模型请求。

网关和语音

  • 网关“接入与密钥”首先显示地址与复制，密钥列表默认只看名称、末尾标识和状态；新增才填名称，完整 Key 只显示一次。停用、轮换和删除均说明影响后确认。
  • “模型目录”标记聚合、已接入原生模型和仅上游目录模型，支持源、能力与名称筛选。未启用模型有明确的源配置入口；不把目录模型画成已可调用。
  • 语音输入先看服务摘要，修改时按服务显示字段，切换服务保留各自参数。

Technical Design

生产实现继续使用现有 React、antd 与本地 Radix / shadcn 控件，不在此阶段整体替换 UI 框架。交互统一先于跨页样式替换。没有提出新后端接口，也不修改限额、定价优先级或 24 小时清理边界。

原型实现

  • gateway-prototype.html 是统一原型。源文件在 gateway-prototype/，用 node gateway-prototype/build.mjs 重新构建。
  • 构建脚本从 frontend/src/index.css 和 theme.tsx 提取现有 token，从 icons.tsx 序列化 SVG；使用同一 useLayout() 更新尺寸、触摸、键盘和减少动态效果状态。没有另建断点或颜色系统。
  • 静态 HTML 内置中英文小字典，符合静态页面的国际化规则；正式实现的新增文案仍进入 frontend/src/i18n/。
  • 交互状态仅在当前页面内存中，刷新或“重置演示”回到合成初始数据；语言选择在浏览器本地保存。没有业务请求或真实账号凭据。

Acceptance

各页面的桌面与手机验收条件见 逐页设计。正式实现的检查记录见 页面实现与验收。

桌面四档、Android 实机及离线异时区检查通过；原型无业务网络请求。独立初审指出手机密钥列表拥挤、模型定价来源标签错误两项问题，修复并经真机保存 / 触摸操作验证后，两项定向复核获 ship；该结论仅覆盖这两项修复及直接回归。完整前端现有测试 1,843 项通过，它们是生产代码回归检查，原型交互验收另行记录。
