实现与验收

首屏
类型、展示名、调用名、独立的输入与输出、工具和费用
来源
Web 与 CLI 读取同一份目录。API 按调用方授权和协议返回可调用模型。
验收
目录默认聚合优先，未发布模型留在模型源。验证别名搜索、输入输出独立筛选、回到同一目录位置、旧密钥撤销后返回认证失败。
