查看流程与状态

为当前节点选择语音转写服务，保存后用一段试录验证。

先看服务的保存与验证状态
桌面同屏查看配置和试录结果。手机从配置页打开试录子页，录音时只保留结束与取消动作。
按服务商保留草稿
切换服务商时保留各自字段。试录使用已保存配置，旧结果标明服务商和时间。
转写服务独立配置
语音输入将录音转成文本。会话所选模型的音频理解能力在本机网关模型目录查看。

流程与状态

切换服务商、编辑与保存
  • OpenAI 兼容填写 API 地址、凭据、转写模型和可选语言。局域网的兼容服务用自己的节点地址。
  • 火山引擎主表单只显示 API Key。保留旧配置用于兼容，避免要求用户重新填写。
  • 未配置展示「设置识别服务」，完成保存后可用试录验证。
有未保存的修改

保存后可测试新配置。切换服务商或保存失败时保留草稿。选择「取消编辑」后恢复已保存配置。

录音、停止与转写结果
  1. 开始
    请求麦克风权限由「开始试录」触发浏览器授权。授权后显示计时和录音状态。
  2. 录音
    停止并转写，或取消录音停止时释放麦克风后提交录音，取消时释放麦克风并丢弃本次录音。返回时如仍在录音，确认是否丢弃。
  3. 结果
    显示转写文本提交后显示正在识别与取消等待。结果标明时长、服务商和完成时间，可重新试录或复制文本。
正在识别 8 秒录音

取消等待后只保留此前结果，随后到达的回执不会覆盖当前显示。

按原因恢复录音与识别
  • 浏览器麦克风权限被拒绝允许此站点使用麦克风后点「重新试录」。不安全的连接提示改用 HTTPS 或本机地址，未找到麦克风时提示检查输入设备。
    录音前
  • 连接超时或网络断开检查网络以及节点到 API 地址的连接，再点「重新试录」。已保存的配置继续可见。
    提交后
  • 服务鉴权失败、达到额度或未识别到语音鉴权失败进入编辑并更换密钥。达到额度时按提供方提示稍后再试。未检测到语音时重新录一段。
    识别中

实现与验收

形态
桌面左侧配置、右侧验证。手机版以全屏子页完成试录，返回后可继续编辑此前草稿。
配置与转写
复用节点语音服务配置及识别回执。试录只展示当前操作和可读的脱敏错误，表单保存结果与识别结果独立判断。
验收
分别尝试麦克风允许、拒绝后恢复、录音中取消、识别超时和错误凭据。切换服务商后可找回字段，试录提交时使用已保存配置。
