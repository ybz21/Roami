接入与发布

启用需要的模型，配置策略，再交给调用方。

  • 模型源连接供应商，只启用需要的模型。
  • 插件与账号发现、安装和更新社区插件，再管理各供应商的账号。
  • 聚合编排成员与顺位，核对生效策略和实际调度。
  • 本机网关查可调用模型，发放密钥和复制接入示例。

运行与排查

从近况发现异常，追到请求与费用。

  • 调度与排查确定哪个聚合需要处理，点开异常就能找到原因。
  • 监控看异常影响范围，区分请求终态与供应商异常。
  • 审计还原一次请求是如何结束以及如何记账的。
  • 概况查看消耗、限额与重置时间，按来源核对费用。

会话与输入

为任务能力匹配模型，并独立验证语音转写。

  • 会话与委派选模在创建和委派时选择固定模型或 Auto，并跟踪实际命中。
  • 语音输入选择转写服务，用试录结果验证配置。
