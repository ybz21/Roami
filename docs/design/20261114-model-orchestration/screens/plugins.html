查看流程与状态

从 Magpie 目录选插件，确认版本后接入供应商账号。

目录默认显示所有条目
按名称、包名、供应商或仓库链接搜索。保留已安装、可更新和未安装三种状态，返回时恢复筛选和当前条目。
版本变更保留账号
下载、校验与应用各自回显。应用前显示影响的账号，回退入口保留上次生效版本。
手机逐层进入
从目录进插件详情，再进入指定账号。授权且支持签到的账号显示积分、重置日和最近一次签到结果。

流程与状态

同步目录与文件导入

目录优先读取 GitHub，失败后尝试 jsDelivr。两者均不可用时显示缓存、上次同步时间及重试。已安装状态仍由节点提供。

正在显示离线目录

上次成功同步 14:28。恢复联网后重试。

选中未安装的 Gumloop 后，显示安装、说明和发行版本。从文件导入时，先填写当前节点可访问的插件文件或目录路径，再检查包名和版本。读取或校验失败时保留路径。

检查更新、应用与回退

打开「检查更新」后读取发布索引并显示检查时间。下载时可选官方或支持的加速来源。校验成功后版本才进入待应用状态，应用确认显示受影响账号。

更新没有生效

仍在使用 0.2.26，已关联的账号可继续使用。你可以重试应用。

应用成功后，可在版本区回退到 0.2.26。回退确认显示目标版本及受影响账号。

创建账号、授权与签到

选择供应商和地区后创建来源账号，完成授权就能到模型源启用模型。同一供应商支持多个独立账号。账号已被来源使用时，解绑前列出关联来源。

今日已签到

到账后显示最新积分和签到时间。再次打开账号时保留今日结果。

授权过期时显示「重新授权」。完成后回到刚才的账号，再继续查看积分或签到。
