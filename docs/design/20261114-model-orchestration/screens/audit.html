四种容易混淆的请求结果

按事件顺序还原准入、响应、换路与终态。遇到 503 时记录有无上游尝试，遇到 200 时保留流的最终状态。

  • 准入被拒 · HTTP 503候选被费用策略或目录条件排除，网关未联系上游。
    0 次尝试
  • 候选用尽 · HTTP 503首选返回 429，备选返回 402。
    2 次尝试
  • 切换后恢复 · HTTP 200首选限流，备选开始响应并完成流。
    2 次尝试
  • 输出中断 · HTTP 200已向客户端发送部分内容，随后中断。
    终态失败
