流程与状态

创建或重连来源
API 连接
填写地址、协议和凭据，连接验证成功后可发现模型。连接失败时保留填写内容，显示地址、认证或网络错误。
OpenRouter 免费
固定服务地址。填写凭据后自动加载当前免费候选，用户选择要启用的模型。
Magpie 插件
从插件目录选择已安装或未安装的插件，完成供应商账号授权后发现模型。查看插件与账号
连接管理
同一账号可重连和编辑。授权失效仍显示已启用模型与上次检测结果。删除来源
发现、检测、定价与生效
发现与探测
发现结果显示更新时间。模型能力详情给出来源、探测时间及结果；超时与未验证沿用上一份有效证据，并可重试对应模型。
价格范围
定价页区分来源默认规则、模型覆盖和最终生效价。价格未知单独显示，免费状态来自当前生效规则或有证据的供应商报价。
账号顺位
多账号来源按生效顺位展示可用与冷却状态。编辑账号顺位时保留已启用模型，保存后显示当前顺位。
确认变更
先列新增、移除与受影响的调用名。保存成功后，在 本机网关核对可调用范围。保存冲突时保留选择并重新核对。
