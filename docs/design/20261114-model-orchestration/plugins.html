先装插件，再给供应商建账号

从模型源的「新建来源 → 插件」进入。左边是社区目录，右边是选中插件的版本和账号。账号授权完成后回到模型源启用模型。

行为

目录读不到时用缓存
顶部标明目录的读取时间。读取失败时继续展示上次的目录，并给出重试，不把列表清空。
更新先下载校验再替换
应用前列出受影响的账号。校验失败或应用失败都保留正在使用的版本，账号不需要重新授权。
授权和启用是两页的事
授权完成后可查看这个账号的插件能力。模型仍在模型源里启用。
页面按插件实际能力渲染
已授权账号声明 usage 时展示额度，声明 checkin 时提供签到按钮。签到成功后刷新余额。由插件返回已签、活动未开放或需到服务商应用验证等状态。
WorkBuddy 国内版和国际版各自显示
国内版插件提供签到，国际版展示其支持的额度信息。其他平台也根据各自声明显示。可在账号原型试用演示结果，或查看插件说明。
解绑前检查引用
账号被某个来源使用时不能直接删除，先列出使用它的来源。
