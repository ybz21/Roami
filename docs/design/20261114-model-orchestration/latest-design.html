以一个聚合池为范围，同时展示下一次请求的可调度顺位、所选时段的结果分布和一条已完成请求的真实尝试。选择失败或恢复可联动请求列表，打开完整审计后返回到原来的筛选与请求。

例如，选中「输出中断」后，同时显示 HTTP 200 和「输出中断」终态。遇到选路被拒时，显示发出前的过滤原因，并跳到这组聚合的配置。遇到限流时，可直达发生限流的来源。

设计接口以聚合 ID 关联生效配置和滚动请求记录。当前原型使用合成记录演示页面联动，聚合设置保存后会回读并更新首选顺位。
