创建任务

沿用现有「开任务」弹窗。「互审」位于上排工具条，默认收起。点击后下方展开审查 Agent Logo 和交审方式，再点收起时保留已选设置。

审查 Agent
推荐由另一种 Agent 审查。可点 Logo 改选，明确选择后保留该选择。
主动交审
作者在有可审版本时发送首轮请求，适合明确知道何时收敛的任务。
空闲交审
作者空闲且有新变更时自动开始首轮，之后由作者提交修复版本。

会话与复审

点击「开干」时同时准备独立的 review 子会话。桌面从项目树或会话标签进入，手机从项目列表或作者会话的对端入口进入。审查者启动后先显示「等待交审」。

  1. 作者提交可审版本，审查者在自己的终端里核对任务范围和改动。
  2. 审查者发出结论。作者在原会话直接收到完整意见，可继续修复和验证。
  3. 作者提交新版本，原 review 会话继续下一轮。每轮可通过或发回修改。
  4. 通过即停。最多 3 轮，无需在开工时设置。达到上限时保留末轮意见和历史。

开工指令由宿主下发。发送命令可以从实际执行记录展开查看。

用户故事

  • 创建任务时，我用两个 Logo 区分作者和审查者，选好何时交审即可开工。
  • 开工后，我从作者下方打开 review，看到所选 Agent 正在等待或审查。
  • 审查者发回意见后，我在作者会话查看涉及的文件、问题和依据，能在两边来回核对同一轮版本。
  • 准备失败时，我能用原配置重试，或收起互审后继续任务。

交互原型

点上排「互审」，选择审查 Agent，再点「开干」。进入 review 后可演示交审、发回意见、提交修复和通过，再切回作者查看收到的意见。
