# 互审原型验收

验收日期：2026-11-20

| 范围 | 实际检查 |
| --- | --- |
| 桌面 Chrome | 在 1280、1920、2560、3440 CSS px 检查开任务和审查详情。分别展开、收起两处 Prompt，开工操作可达，工作区贴到右边缘，页面无横向溢出 |
| Android 真机 | Redmi Note 8，Chrome，392 CSS px。真实触控通过开工、查看 Prompt、内部滚动、返回项目、从项目树打开子会话，以及作者和审查者双向切换。软键盘弹起后开工按钮仍在视口内 |
| 模拟互审 | 主动交审完成提交、反馈、修复、通过四步。空闲交审选择一轮时保留意见并进入轮次上限。自动配对跟随作者，显式选择保留。关闭互审后没有子会话或残留审查消息 |
| Prompt | 两种语言可加载。创建前分别展示双方 ID 占位符；创建后按会话展示已绑定的演示 ID。英文浅色可完成配置和空闲交审 |
| 独立文件 | Chrome 直接打开本地 HTML，使用同目录 CSS 与 JS。Roami 文件路径测试 `TestFilePathLinks` 通过 |
| Roami CLI | 在独立测试实例用 `new`、`fork`、`children` 核对父子关系，在两个测试 shell 间用稳定 ID 验证 `send` 双向送达，再按同一入口关闭隔离实例 |
| 仓库检查 | 前端类型检查、i18n、hover、Vitest 和生产构建通过。原型 JS 语法检查与设计扫描通过 |

PR 附桌面创建、Prompt 预览、互审对话和 Android 真机截图。桌面和手机的互审过程均使用演示数据。CLI 核对覆盖普通会话的命令能力，真实 Agent 启动、工作区授权、版本确认和宿主消息接收属于后续实现。
