# 互审原型验收

验收日期：2026-11-20

| 范围 | 实际检查 |
| --- | --- |
| 桌面 Chrome | 1280、1920、2560、3440 CSS px。点上排「互审」后下方展开，项目树和桌面标签都能打开互审子会话，工作区贴到右边缘，页面无横向溢出 |
| Android 真机 | Redmi Note 8，Chrome，392 CSS px。触控选择 Pi 审查、开干、返回项目、从项目树打开 review、切换对端、完成三轮审查。软键盘弹起时，滚动表单后开干按钮仍可点击 |
| Agent 选项 | 作者与审查者均可选 Claude Code、Codex、OpenCode、Pi。桌面验证 OpenCode 与 Pi 互换角色，并收到对端意见。当前节点注册表覆盖未安装 Agent 的回归测试通过 |
| 双向消息 | 在审查者侧展开第一轮发送记录，包含作者的稳定 ID 与版本。切换到作者会话后，直接看到同一条完整意见和作者的修复回复 |
| 多轮审查 | 三个版本依次提交，两次发回修改后第三轮通过。另跑全三轮均有修改意见的路径，到上限后停止并保留最后意见。英文浅色验证空闲首轮、提前通过、显式审查者选择和关闭互审 |
| HTML 设计页 | 桌面 Chrome 从本地 index.html 打开 product.html 和 tech.html，验证用户故事、命令示例和原型入口。Android 实际触控总览导航、章节锚点、返回和打开原型。相对文件和页内锚点均可解析 |
| Roami 文件和 CLI | 文件路径测试 `TestFilePathLinks` 通过。在独立实例用 `new`、`fork`、`children` 核对父子关系，用稳定 ID 验证两个普通测试 shell 的双向 `send`，随后按同一入口关闭实例 |
| 仓库检查 | 前端类型检查、i18n、hover、Vitest 和生产构建通过。原型 JS 语法与 Git 空白检查通过 |

PR 附互审收起与展开、审查方发出、作者收到、三轮通过、Android 真机和HTML 设计文档截图。原型里的会话、版本及意见都是演示数据。CLI 核对覆盖普通会话的命令能力，真实 Agent 启动、工作区授权、版本确认和宿主消息接收属于后续实现。
