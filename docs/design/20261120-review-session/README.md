## 产品设计

保留原来的「开任务」布局。「互审」默认收在原工具条里。点击后，下方展开审查 Agent Logo 和交审方式。推荐用 Codex 审 Claude Code 的任务，反向亦可。用户可改选审查者，关闭后保留已经选过的设置。

开工时在同一个任务工作区创建持久的 `review` 子会话，启动选中的审查 Agent。双方在自己的终端中用 `roami session send` 双向交审与回传实际意见。作者在原会话内修复并提交下一版本。

主动交审由作者发送首个可审版本。空闲交审由宿主在作者空闲且有新变更时提交首轮。两种方式默认最多 3 轮，通过即停，达到上限保留最后意见。Prompt 开工时由宿主注入，设计及示例见 [技术设计](README.html#prompts)。

## 用户故事

- 创建任务时，我用 Logo 指定谁审，并选择主动或空闲交审。
- 开工后，我能在作者下方立即打开 `review` 子会话，看到审查 Agent 在等待。
- 作者直接收到完整意见，修完提交下一版。审查者能从同一个会话复审并给出结论。
- 如果审查准备失败，我能按原配置重试，也能关闭互审后继续开工。

原型使用示例任务、会话和消息。语音、附件与其他 Agent 图标用于还原现有工具条，互审演示可选择 Claude Code 或 Codex。
