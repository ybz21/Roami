场景与验收

用户能从标签和项目列表看到哪些会话在运行、哪些在等确认。进入会话后，仍可及时看到输出、回答 TUI 提示、浏览旧消息及恢复 Codex 会话。

用户操作与预期

打开多个标签，回到项目或文件
标签按现有样式显示 Agent 与待输入状态，工作台可继续切回原会话。收起终端坞或文件覆盖会话后，暂停该会话的交互抓屏与转录读取。
切到一个正在运行的会话
先显示当前会话已缓存的内容，同时校验会话身份并立即追读。桌面保留用户选的显示模式。手机按既有规则打开对话，用户手动切回终端后保持该选择。
出现权限确认或选项菜单
可见会话及时显示实际问题。选择后立即复核屏幕，同一道题是否仍在决定要不要补发 Enter。后台待输入状态继续由共享概览更新。
Codex 连接恢复
在可见会话检测恢复入口。操作时重新读取屏幕和关联对话，保留草稿备份、单次中断与回到 shell 后继续的顺序。
离开浏览器或遇到断网
暂停会话读取，保留最近内容；恢复时从现有游标追上。在加载较早消息时维持滚动位置，断线重连和切换节点时按各自的会话身份恢复。

实施后要验证的行为

  • 可见交互提示的常规抓屏预算沿用 1.2 秒；活跃对话的增量轮询沿用 1.5 秒。用实际 TUI 测量确认出现到可点击、消息写入到可读的 P95 延迟，与同环境现状对照。
  • 打开终端坞、回到浏览器以及发送消息时立即追读。保留草稿、用户选择和阅读位置。切到另一个节点、同名会话重建或切换执行器时，旧数据不得写进新会话。
  • 覆盖 Claude、Codex、OpenCode、Pi、普通 shell 与原生会话。原生 Main 的回合状态和转录最终消息继续按现有口径显示。
  • 交互回归包含同一会话的工作台与项目 Main 双入口、独立会话页、桌面文件标签、慢请求、断网和回前台。桌面覆盖 1280、1920、2560、3440 CSS px，手机在 Android 真机上点按并切换前后台。
