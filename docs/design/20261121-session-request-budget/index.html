会话请求频率优化

桌面上，每过 5 秒，工作台就给每个打开的命令行会话发三条请求，分别查 Claude、Codex、OpenCode 在不在跑。

开了 8 个会话，一轮就是 24 条请求，收起终端区也照问。截图里成批的 codex 和 opencode 多半就来自这里。

你正在看的对话还会每隔约 1.5 秒问有没有新消息。同一个对话如果在两个地方打开，两边会各问一次。

准备怎么改

先让标签和项目列表共用一次状态查询。打开会话后，权限确认和恢复功能共用一份终端画面。同一个对话也只发一份新消息请求。收起终端区或切走后，工作台就停止读这些详情。
