# 局域网模型源接入回归

## 问题与行为

HTTP 模型地址原来只允许 localhost，私网地址导致目录拉取和保存按钮同时禁用，运行时节点路由也拒绝同类地址。现在目录、保存和节点路由一致允许私网 IP 的 HTTP 地址；公网 HTTP 仍保持原约束。

用户可拉取目录，也可手动填写模型直接保存；已有模型源可修改名称、协议与密钥，不要求再次拉取目录。已配置模型的编辑入口由“聚合策略”改为“编辑”，与实际可修改内容一致。
