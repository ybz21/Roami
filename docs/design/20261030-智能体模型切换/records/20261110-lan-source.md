# 局域网模型源接入回归

## 问题与行为

HTTP 模型地址原来只允许 localhost，私网地址导致目录拉取和保存按钮同时禁用，运行时节点路由也拒绝同类地址。现在目录、保存和节点路由一致允许私网 IP 的 HTTP 地址；公网 HTTP 仍保持原约束。

用户可拉取目录，也可手动填写模型直接保存；已有模型源可修改名称、协议与密钥，不要求再次拉取目录。已配置模型的编辑入口由“聚合策略”改为“编辑”，与实际可修改内容一致。

## 已有源模型列表与网关入口修正

源卡片增加“更新模型列表”，使用已保存的连接和密钥重新拉取目录。保存的模型不再锁定勾选，可与新增模型一起调整；未出现在新目录的旧模型仍可见并标注，避免静默丢失，用户取消勾选后确认移除。保存保留其他源、未修改模型的 ID、密钥与聚合策略。目录无变化时直接显示没有变更。新增交互回归覆盖卡片入口、重新拉取、增删保存及其他源保留。

网关地址和协议说明移入“本机网关”同级标签；移除“配置智能体”重复入口。桌面源配置在卡片内，手机仍走全屏二级页。真实部署页检查发现 antd 为双字中文按钮插入空格，浏览器验收选择器改为兼容“返 回”等可访问名称，而不是按隔离页的纯文本误判。
