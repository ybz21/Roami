# 模型源 HTTP 与 HTTPS 证书配置

## 产品设计与用户故事

用户可在「能力 → 大模型 → 模型源」填写公网或局域网 HTTP 地址，拉取目录或手动添加并保存模型。HTTP 地址下方提示请求和密钥明文传输。HTTPS 默认验证证书。用户连接可信的自签名服务时，可在「连接选项」中勾选「忽略 HTTPS 证书验证」。更换地址后需为新地址重新选择证书策略。

## 技术设计

证书策略随模型源配置保存。目录拉取、目录缓存、模型调用与模型验证指纹使用该源的策略。网关为验证和忽略验证分别维护连接池。目录返回重定向时，表单提示填写跳转后的 Base URL。用户凭据仍随明确配置的地址发送。

## 验收

- Go 用例验证公网 HTTP 目录与实际转发、默认拒绝不受信任的证书、开启选项后目录与转发成功、重读保存的策略后调用成功，以及目录重定向不会转发请求。
- 桌面 Chrome 在 1280、1920、2560 和 3440 CSS px 检查表单边界，使用测试目录验证中英文界面、HTTP 拉取、HTTPS 证书提示、勾选后拉取和保存。
- Redmi Note 8 真机通过 ADB 点按验证地址输入、HTTP 拉取、展开连接选项、勾选证书选项、HTTPS 拉取和返回列表。
- 用户给的服务在 HTTP 返回 308，直接通过 IP 访问 HTTPS 时在证书校验前失败。通过带显式 IP SNI 且验证证书的 TLS 请求读取到 71 个模型，其中包含指定模型。接入此服务仍需上游提供可直接访问的 HTTPS 地址或为无 SNI 的握手提供默认证书。
