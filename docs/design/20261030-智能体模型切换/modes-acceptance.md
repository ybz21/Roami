# 原厂与自定义模式验收

2026-10-31。交付范围：能力 / 智能体中的安装、启动和模型模式；自定义配置为“模型源、模型”两步。

## 自动化覆盖

- 原厂不是“恢复旧配置”：从第三方预设切换后不保留其端点和凭据，恢复旧配置仍能回到原来的第三方连接。
- Claude Code、Codex、OpenCode、Pi 均验证切换、持久化读回和恢复。登录文件、hooks、权限、MCP 等非模型设置保留；Codex 内置 OpenAI 的旧转发覆盖被移除。
- 原厂 API 校验配置修订，过期提交返回冲突，不覆盖新的设置。
- 自定义应用同时验证来源和模型；来源与模型不匹配时不改本机配置。
- 原厂状态不会显示仍在使用自定义模型；未启用的旧连接预设继续保留引用保护，覆盖 Claude 根入口和 Codex `/v1` 入口。
- 前端验证先选源再选模，换源后不能沿用旧模型；只改变表单不写配置；确认后才应用；目录不可用不妨碍原厂模式；未安装先安装。
- 原有定价、用量与限额回归保留，主流程外的旧预设仍可在高级区域操作。
- 来源模型目录为只读服务端请求，不下发凭据；来源仅配置连接时也可选模，确认应用才加入共享列表；目录失败可直接输入模型 ID。新增源目录读取、手填回退和重复应用复用路由测试。
- 原生 CLI 内直接更换模型后，当前使用和删除保护按实际端点与模型计算，不依赖旧预设仍被标为应用。
- 前端 150 文件、1128 测试通过；typecheck、i18n、hover、生产构建通过。Go 适配器、网关及 API 测试通过；两核心包 race 检查及 quick 质量门通过。

## 桌面真实界面

独立实例 `/tmp/roami-model-modes-run`，全部 CLI 配置位于其专属目录，未修改用户真实 CC 的已配置模型。

1. 初始显示 CC 已安装、版本 2.1.314、原厂模式（Default）、已应用；提供升级和打开终端。
2. 自定义选择“团队模型源”，模型下拉仅出现“日常编程 / 深入推理”。选择日常编程后换到“个人模型源”，模型清空、应用禁用。
3. 另增“新配置的模型源”，不预登记任何模型。下拉直接读取 source-live-model / source-reasoning-model；选择 source-live-model 并确认，模型进入统一列表，当前使用更新。真实模型配置经过 Go 适配器写入，API 回读模式为 custom。
4. 选择原厂只是编辑，当前使用仍显示 source-live-model；确认应用后才变为原厂，API 回读 official。
5. 原厂页面不展示自定义来源和模型字段，不把恢复旧配置当成原厂。

## Android 真机

Redmi Note 8，1080×2340、DPR 2.75、392 CSS px。ADB 实际点按自定义、新配置的模型源、source-reasoning-model、应用和确认；当前使用更新为 source-reasoning-model，共享目录新增该模型，正在使用标为 Claude Code。再实际点按原厂、应用和确认，回到原厂。

模型搜索弹出真实软键盘，列表在字段上方展开，两个选项均可触达；用 ADB 直接点选第二项并完成应用。来源、模型选项、模式按钮及确认动作实测 44px；无横向溢出，文档 scrollTop=0。CC 二级页保持一条返回栏和底部四个导航入口，高级预设默认收起。手机 Chrome 缺少 CLI 要求的 browser ID，ADB 负责真实操作，CDP 只用于读取和定位本任务页面。
