## 产品设计

顶部保留现有**智能体 Logo 与会话名**，仅在该组有已打开文件时显示独立的下拉箭头。点击 Logo / 会话名始终进入对话；点击箭头打开该组的对话与文件列表。左栏不列组内文件，也不将文件常驻铺在顶部。

```text
Roami / ai-app-factory

[ Claude 官方 Logo  海空双模式  下拉箭头 ]   [ Codex 官方 Logo  登录流程 ]
                              下拉菜单
                              对话
                              已打开文件
                              交互方案.md（当前项）
                              验收清单.md
```

这里的“组”是会话及其工作区资源的导航呈现，不是新建的文件夹。入口不换成文件夹图标；智能体标志使用真实类型和官方品牌色，文件保留文件图标。菜单关闭后顶部仍是同一个智能体入口，当前文件名称显示在内容标题栏。

### 点击规则

| 入口 | 结果 |
| --- | --- |
| 智能体 Logo / 会话名 | 直接回指定会话的对话；shell 会话进入终端 |
| 会话旁下拉箭头 | 打开或关闭菜单，不改变当前资源 |
| 菜单“对话” | 回该会话的对话 |
| 菜单文件项 | 打开该文件并收起菜单 |
| 文件标题前返回箭头 | 回来源会话，文件继续保留 |
| 菜单外点按、Escape | 关闭菜单，不关闭文件、不切资源 |
| 其他会话的 Logo / 名称 | 直接进入那个会话，不恢复它上次看的文件 |

核心修正是把“回到会话”和“选择文件”分成两个明确点击区。Logo 和名称从不承担恢复文件的职责，避免重现最初的问题。没有新设一个图标不同、功能相同的“对话”常驻标签。

### 菜单与当前状态

- 菜单第一项固定为“对话”，使用对应智能体 Logo；其后“已打开文件”分区只列打开的文件，不递归展示目录。
- 当前具体资源同时使用中性选中底色、字重和勾选图标；文件正在显示时，“对话”不能被标成当前资源。
- 顶部会话组可以高亮表示归属，但只有正在查看对话时，Logo / 名称按钮才带 `aria-current`。菜单内使用 `menuitemradio` 与 `aria-checked`。
- 同名文件显示完整路径以便区分；长名省略，正文标题与详情保留完整路径。
- 文件多时菜单自身滚动；弹层逃逸导航的 overflow，不撑大文档，不被导航裁切。弹层靠近右边界时向左避让。
- **没有已打开文件时，只显示智能体 Logo 与会话名，不渲染箭头、空菜单或占位间隙。** 打开第一个文件后箭头出现；关闭最后一个文件后箭头消失，点击名称仍回对话。
- 箭头显隐依据该组已打开文件，不依据磁盘上有没有文件，也不依据当前显示对话还是文件。回到对话但仍有文件开着时，箭头保留。
- 若最后一个文件在菜单打开时关闭，产品实现须同时关闭菜单，并将仍在菜单内的焦点还给该会话名称；不得让焦点落到已移除的箭头。单击箭头不触发新建或关闭。
- 打开另一组菜单不切换当前内容；选定具体资源后才切换。切组和看文件保留演示草稿，实际产品继续保护未保存文件。
- 会话名、Logo 始终保持会话身份。文件失效时显示文件错误与恢复动作，不自动替换为成功打开的对话。

原有全局标签仍用一份存储，只将组内资源收进菜单。`FileTab.task` 继续拥有工作区归属；同一 worktree 的多个会话可以看到同一批文件，文件只保留一个标签 / 编辑器实例。已存在的会话派生关系不被此菜单替代。

## 用户故事

1. 在文件中点击上方智能体 Logo / 会话名，一次回到原对话，无需先关闭文件。
2. 想继续文件时点击会话旁箭头，在同一菜单中选择已打开文件。
3. 点箭头只查看列表，然后点空白或 Escape，文件和输入内容均不变。
4. 看到官方智能体 Logo 就能识别会话类型，不必把会话理解成新的文件夹实体。
5. 用键盘或手机触控也能明确地区分“回对话”和“选文件”。

## 桌面与手机

桌面仍保留共享项目身份栏，下方各会话以“智能体 Logo + 名称 + 独立箭头”横向排列。工作内容占满剩余空间，右侧属性面板默认关闭，开启后关闭会归还全部宽度。文件标题前保留层级返回 Chevron。

手机将当前智能体入口放进顶栏：左侧一个返回按钮，中间为 Logo / 会话名，有已打开文件时右侧才显示资源下拉。无文件时名称区收回箭头位置。文件名显示在正文前的文件标题，不重复另一套返回栏。下拉只是短列表选择，使用锚定菜单；长文件列表在菜单内滚动，不弹出嵌套对话框。

文件页顶栏返回回来源对话；对话页返回收起会话工作区；独立的会话切换按钮打开全屏选择页。选择页只有一个返回栏和滚动容器，选择具体会话回到对话。会话 / 文件全屏工作内容不叠底部主导航，现有产品一级页的首页 / 项目 / 工具 / 设置底栏不变。

触控箭头视觉仍为小图标，命中区由伪元素补至 44；与名称按钮相邻处增加间距，避免两个点击意图重叠。名称本身高度至少 44，不靠 Tooltip 说明用途。

## 技术设计

### 现有依据与模块职责

| 现有模块 / 拟新增组件 | 要求 |
| --- | --- |
| `ProjectTree.tsx`、`useProjectActions.tsx` | 保持会话真实身份，具体会话入口直接激活会话，不能继续转换为 `returnToTask` 恢复文件 |
| 现有顶部标签导航、`SessionResourceMenu.tsx` | 保留 `AgentLogo` 和会话名，使用现有 antd Dropdown / Menu 模式，提供独立箭头点击区 |
| `useTaskWorkspace.ts` | 校验文件归属，原子更新活动会话 / 文件，捕获来源会话，保持文件草稿 |
| `term-tabs-store.ts` | 继续使用全局标签数据与 `FileTab.task`；菜单不拥有另一份文件列表 |
| `view-state.tsx` 作用域 Hooks | 保存可恢复位置与草稿，不新增模块 Map 或 localStorage 快照 |
| 文件标题、`BackButton` / `BackLink` | 来源返回在标题前；失效来源回同组有效会话，无会话时由用户明确打开 |
| `frontend/src/i18n/` | 产品实现补中英文案、状态与可访问名称 |

组身份继续复用 `TaskKey`，会话用稳定 ID，文件用现有规范化路径。菜单是现有数据的派生视图，不新建组业务实体、接口或轮询。同一工作区共享文件时，具体点击的会话是本次导航意图，不能从遗留后台 `active` 值猜测。

服务器 `/workspace` 继续拥有打开标签和活动资源；菜单开合与焦点是组件临时状态，卸载时清理。实际文件编辑器的 `draft`、滚动位置和恢复仍通过统一工作区仓库，不把 DOM、菜单节点或连接存入仓库。旧 `task-last-tab.ts` 的恢复能力如保留，应只用于明确的“继续工作”入口；本次 Logo / 名称入口不再调用它。

原型使用 React portal 展示菜单，避免导航裁切；产品实施复用现有 antd 浮层与移动命中约定。菜单边界、滚动、节点、事件监听均归组件清理。尺寸档位只取自 `useLayout()`；DOM rect 只用于弹层定位，不用于另立断点。

### 键盘与状态

- Logo / 名称和下拉箭头是两个相邻的原生按钮，Tab 分别到达。
- 箭头使用 `aria-haspopup="menu"`、`aria-expanded`、`aria-controls`，标签包含具体会话名。
- 打开菜单时聚焦当前项；尚未查看该组时聚焦“对话”。上下键循环，Home / End 到首尾，Enter / Space 选择。
- Escape 关闭并将焦点还给箭头；Tab 关闭并继续页面焦点顺序。外点关闭不抢回焦点。
- 选择文件后关闭菜单，保留可恢复焦点；调整窗口或滚动外部容器时关闭失去锚点的菜单，菜单自身滚动不关闭。
- 加载、错误、来源失效和未保存关闭保护仍由产品对应资源控制，菜单不能伪装成操作成功。

## 原型与后续验收

独立原型使用演示数据，不读取真实会话、不连接终端、不保存或发送业务内容。支持 Logo / 名称回对话、箭头菜单、具体资源选择、外点 / Escape 关闭、方向键、草稿隔离、手机会话选择、浏览器返回、深浅主题和可选属性面板。

产品实现与实际验证见 [implementation.md](implementation.md)。原型保留演示数据与中文资料，不作为产品测试；产品文案已接入现有中英 i18n。
