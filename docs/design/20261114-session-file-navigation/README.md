[交互原型](prototype.html) · [原型源码](proposal.tsx) · [验收记录](acceptance.md)

## 产品设计

推荐用**工作区**把对话与打开的文件组织在一起。组标题可以“继续上次”，具体会话入口必须直达该会话，文件入口必须直达该文件。不要让带 Agent 标识的会话行暗中承担恢复整个工作区的职责。

截图中的“海空双模式”目前是一条会话行，但其点击链路调用 `returnToTask`，恢复了任务上次打开的文件。这并非文件丢失或会话消失，而是两个不同意图共用了一个入口。

```text
ai-app-factory
  海空双模式                         工作区（文件夹图标）
    对话                             真实会话（Agent 标识）
    交互方案.md                      打开的文件
    验收清单.md                      打开的文件
  登录流程                           另一个工作区
    对话
```

“工作区”是当前任务 / worktree 的导航呈现，不要求新建业务实体。一个工作区可有多个会话，文件和会话是同级资源，不把文件强行归为某个会话的附件。

### 点击规则

| 入口 | 落点 | 保留什么 |
| --- | --- | --- |
| 工作区名称（文件夹图标） | 该工作区上次资源；首次打开主会话 | 上次文件、对话、滚动位置和草稿 |
| 工作区左侧展开箭头 | 只展开 / 收起子项 | 不改变正在查看的内容 |
| 组内“对话” / 某个会话名 | 指定会话的对话；shell 则进入终端 | 文件仍然开着，未保存内容保留 |
| 某个文件名 | 指定文件 | 其他标签和会话保留 |
| 文件标题左侧返回箭头 | 返回来源会话；来源失效时回主会话 | 不关闭文件，不丢编辑内容 |
| 对话标签 | 当前工作区最后使用的会话 | 不关闭文件 |
| 其他工作区 | 该工作区上次资源 | 每个工作区独立记忆 |

文件打开时，工作区组标识归属，文件子行标识当前位置；不再把会话行高亮成“正在看对话”。折叠的组显示“上次：交互方案.md”或“上次：对话”，明确名称点击会恢复什么。展开后隐藏重复摘要。当前组的标题使用字重，只有具体资源带 `aria-current` 和选中线。

### 为何选这个方案

| 方案 | 好处 | 代价 / 判断 |
| --- | --- | --- |
| 只把会话点击改成直达对话 | 改动最小、一步回对话 | 文件仍只有横向标签入口，难看出归属；可作为较小范围的备选 |
| **工作区组 + 对话 / 文件直达** | 同时支持继续工作、回对话、回文件 | 每个工作区多一行；推荐 |
| 会话行右边加“回对话”小图标 | 不增加层级 | 两个相邻落点难区分，手机易误触；不选 |

保留现有全局平铺标签栏，不借此改成按组隔离的标签系统。侧栏分组回答“它属于哪里”，标签栏回答“我开着什么”。

### 密度与边界

- 当前工作区初次进入默认展开；之后尊重用户折叠。其他组保留折叠状态，不因轮询跳动。
- 单会话时子项显示“对话”，可访问名称包含实际会话名；多会话时显示各自名称，保留 Agent 标识和真实状态。
- 已有会话派生关系仍在会话子树内表达。派生关系跨工作区时只显示关联入口，资源归属不随派生关系改变；文件不是派生会话。
- 文件区只列已打开文件，不递归铺目录。超过 3 个时显示“全部 N 个文件”，打开工作区资源页；不新造文件系统树。原型展示两个文件。
- 同名文件加最短可区分的父路径。长名省略，打开后标题与路径可完整阅读。
- 没有文件时不显示“暂无文件”。无会话但有文件时组仍可进入；返回对话动作改为“打开会话”，由用户明确发起，不自动新建。
- 文件失效时保留文件身份和错误，提供关闭入口与返回对话；不把对话误报成文件成功打开。
- 关闭文件后仅在当前组内选择相邻文件，再退回该组会话，不跳进其他组。涉及未保存内容时沿用现有保存 / 放弃流程。
- 组标题菜单称“工作区操作”，会话菜单称“会话操作”；收起组不结束会话，不触发 worktree 清理。

## 用户故事

1. 看文件时点“对话”，一次点击回到原会话；文件标签继续保留。
2. 切去另一组再点“海空双模式”，恢复刚才看的文件；想找对话则点组内“对话”。
3. 在文件标题左侧点返回箭头，回到打开此文件的会话；不需要先关闭文件。
4. 多个会话共享一个 worktree 时，能准确进入某个会话；文件只列一次，不伪造归属。
5. 手机上从项目进入工作区资源页，在“对话”和文件之间明确选择；文件页一按返回可回来源对话。

## 手机与桌面

桌面沿用现有项目导航、全局标签、内容区、可收起检查器。分组不改变主内容宽度策略，检查器关闭后空间归还内容。文件标题返回箭头始终在标题前。相邻区域同底色，以单条分隔线分开。

手机沿用首页 / 项目 / 工具 / 设置底栏。项目里的工作区资源页使用一层等高返回栏与一个滚动容器；进入会话或文件后全屏显示，不叠底栏。不把桌面树塞进抽屉。文件标题前的返回回来源对话；对话顶栏返回回资源页，再返回项目。系统返回与浏览器返回遵循访问历史，**显式返回对话**是稳定落点，二者不混用。URL 已管理页面时不再叠加 overlay history。

原型手机入口为该工作区的资源二级页；顶栏返回展示最小项目选择页。原型控制条中的“切换工作区”用于演示“切走再回来”，不属于产品常驻工具栏。

## 技术设计

### 现有证据

- `frontend/src/components/shell/ProjectTree.tsx`：会话行使用 Agent 标识，`onSession(task, name)` 承接点击。
- `frontend/src/app/useProjectActions.tsx`：组合侧栏动作及任务返回。
- `frontend/src/app/useTaskWorkspace.ts`：`returnToTask` 恢复文件；`activateSession` / `openTerm` 清空活动文件，可作为具体会话落点。
- `frontend/src/components/shell/task-last-tab.ts`：现有“任务上次标签”记录。
- `frontend/src/components/terminal/term-tabs-store.ts`：`FileTab.task` 表达工作区归属，没有文件所属会话字段；现有注释明确标签全局平铺。

### 模块与状态

| 模块 | 拟承担的变更 |
| --- | --- |
| `ProjectTree.tsx` / `task-tree.ts` | 从现有 task 读模型呈现组、会话和已打开文件，分别暴露组恢复与资源激活回调；保留会话层级 |
| `useProjectActions.tsx` | 将工作区恢复、会话直达拆为独立意图，不让 `onSession` 继续转成“恢复任务” |
| `useTaskWorkspace.ts` | 校验目标归属，原子提交活动会话 / 文件；捕获文件来源会话；关闭文件只选组内资源 |
| `view-state.tsx` 作用域 Hooks | 保存组折叠、每组上次资源、来源会话和手机导航位置；作用域按节点 / 页面 / taskKey |
| `BackButton` / `BackLink`、文件标题组件 | 增加返回来源对话入口；失效会话明确回退 |
| `frontend/src/i18n/` | 产品实现时补中英文字段、状态和可访问名称 |

工作区身份复用 `TaskKey`，会话身份用稳定 ID，文件身份复用现有规范化路径；同一路径打开于多个工作区时沿用现有唯一标签及其 `FileTab.task`，本提案不改变文件去重策略。独立工作区名称复用 task 名称；会话改名不重置工作区身份，也不强制同步组名称。

`lastResource = { kind: 'session', sessionId } | { kind: 'file', path, sourceSessionId? }` 是导航意图的普通数据，不存 DOM、编辑器或连接。来源会话在打开文件时捕获，再次激活文件不会用一个无关的后台 `active` 值覆盖它。`draft` 继续由文件资源作用域保护。

不要增加新的全局 Map 或 localStorage 快照。实施时将 `task-last-tab.ts` 的旧状态迁入统一仓库；新状态先读取旧记录，成功迁移后不再双写。现有服务器 `/workspace` 继续负责打开标签和活动资源；与组级上次资源之间明确职责，避免两套状态互相覆盖。组折叠属于可见偏好，首帧本地镜像、服务端偏好加载后校准，遵守 `preferencesLoaded()`。

不新增轮询。目录、会话和文件标签变化通过现有订阅更新。单击具体会话、单击具体文件、恢复组分别校验资源是否存在、是否属于当前节点和组。组内无资源时显示一句“工作区内没有打开的内容”，由用户选择打开文件或新建会话。

### 后续产品验收条件

- 从文件状态点会话行，一步回指定会话，未保存草稿不变。
- 切组再返回恢复原资源，两个组的滚动位置、草稿、来源会话互不串用。
- 只有具体资源为当前项；折叠 / 展开不切资源。
- 覆盖多会话、派生会话、已关闭会话、失效文件、重名、跨节点、重新命名和空工作区。
- 产品实现需通过仓库完整前端检查、运行时 full gate、桌面四宽度与 Android 真机验收。

## 原型范围与复现

原型内容是演示数据，不读取真实会话，不连接终端，不写产品偏好。支持工作区恢复、会话 / 文件直达、折叠、文件返回对话、手机二级页、浏览器历史、检查器开合和深浅主题。原型编辑区可输入演示草稿，切换资源保留；没有实际保存动作。

仅开发者设计文档与原型使用中文，不加入产品 i18n；产品落地时所有可见文字必须进入现有中英语言包。图标与断点直接复用 `frontend/src/icons.tsx` 和 `useLayout()`，没有另写断点读取。
