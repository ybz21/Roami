# 会话与文件：顶部标签组

状态：第二版设计提案，尚未修改产品行为。更新：2026-11-15。

[交互原型](prototype.html) · [原型源码](proposal.tsx) · [验收记录](acceptance.md) · [第一版快照](revisions/v1/prototype.html)

## 产品设计

将会话与其工作区的文件放进**顶部同一个标签组**，类似浏览器的标签组。左侧不新增资源列表；当前原型不渲染左侧栏。用户在看文件时，直接点击同组第一枚“对话”标签，就回到会话。

```text
Roami / ai-app-factory

[ 海空双模式  展开按钮 | 对话 | 交互方案.md | 验收清单.md ]   [ 登录流程  展开按钮 ]
─────────────────────── 当前组 ─────────────────────────

当前文件或对话，全宽内容区
```

上方名称是组，组内各项是具体落点。不要把组名、对话名和当前文件混为同一枚标签。单会话组的会话标签显示“对话”，多会话组显示各自名称和 Agent 标识。

“工作区”复用现有任务 / worktree 身份，不新建业务实体。文件与会话同组；同一 worktree 中的多个会话共享文件，不伪造文件专属于某个会话。

### 顶部结构

- 一条横向导航展示所有已打开的组，不另加“选组一行、文件再一行”的桌面工具栏。
- 每组按“组名、展开箭头、对话、文件”排序；对话在组内第一位，文件跟在其后。
- 组名使用文件夹图标，具体会话保留真实 Agent 标识。组和组之间有间距，组底部用细线表示归属。
- 当前组的组名和归属线使用 `--accent`，当前具体标签用中性 `--sel-bg` 与字重。选中的是具体资源，组只是当前归属。
- 默认展开当前组，其他组可收起为组名。收起后显示上次资源名，明确点击组名会恢复什么。
- 原型右侧检查器默认收起，仅显示文件 / 会话属性；不再复制一份资源导航。

### 点击规则

| 入口 | 结果 |
| --- | --- |
| 组内“对话” / 指定会话标签 | 直接进入该会话，不恢复文件 |
| 文件标签 | 直接打开指定文件 |
| 组名 | 恢复该组上次资源，并展开该组 |
| 组的展开箭头 | 仅展开 / 收起标签，不切资源、不关闭文件 |
| 文件标题前的返回箭头 | 返回来源会话，文件仍然保留 |
| 其他组的具体资源 | 直接打开该资源，不经过“继续上次” |
| 浏览器 / 系统返回 | 按实际访问历史返回，不与“回来源对话”混用 |

切换会话、文件和组，保留草稿及可恢复位置。折叠与关闭是不同动作，不能共用一个图标或菜单名称。关闭文件继续沿用保存 / 放弃流程；关闭会话与结束整个工作区也保持现有区别。

### 密度与边界

- 顶部空间不足时，标签导航自身横向滚动，主内容和文档不横向滚动；切换资源时将当前标签滚入可见区域。
- 多文件仍在同组内排列，不把第 4 个文件突然移到左栏或新资源页。长文件名省略，完整路径在文件标题与详情可读。
- 同名文件加最短可区分父路径；组标题、会话改名不改变资源稳定身份。
- 文件通过 `FileTab.task` 唯一分组。文件来自同一 worktree 的多个会话时只出现一次；返回来源在打开文件时捕获，不被后台活动会话覆盖。
- 只有会话、没有文件时，仍是一组“组名 + 对话”，不显示空文件计数或“暂无文件”。
- 会话关闭但文件仍打开时保留组；来源会话失效则回同组有效会话，没有有效会话时提供明确的打开会话动作，不自动新建。
- 文件失效时保留文件身份、错误与关闭入口；不把错误文件自动换成对话并伪装成打开成功。
- 会话派生关系继续属于会话导航；顶部组表示资源工作区，不将派生会话当作文件标签，也不重写现有会话树。

原有全局平铺标签的存储仍是一份。此次改变的是**顶部呈现分组**，不把状态、标签或草稿改成“只载入当前组”；其他组仍可从同一条导航直接到达。产品现有全局项目侧栏不在本提案的整体重构范围，不向其中增加组内文件树；如果保留真实会话入口，点击必须直达会话。

## 用户故事

1. 看文件时，点击顶部同组“对话”，一次返回会话，无需先关闭文件。
2. 会话与文件在同一个视觉组里，切换时不会误认为已经换了任务。
3. 在顶部切到“登录流程”再回“海空双模式”，恢复上次文件；想回对话则直接点“对话”。
4. 其他组暂时不用时收起，文件继续打开，顶部只保留组名和上次资源。
5. 手机上通过顶部工作区选择器切组，组内“对话”和文件标签仍能直接点击。

## 手机与桌面

桌面保留共享项目身份栏，其下是一条 Group 导航。组内标签单行排列，工作内容占满剩余宽高。文件标题左侧保留返回来源对话的 Chevron。右侧属性面板按需打开，关闭后宽度全部归还内容。

手机顶部为“返回、工作区名、切组按钮”，下面保留当前组的资源标签，第一枚始终是“对话”；文件区可横向滑动，切换后让当前项可见。顶部两层共同表示当前组，组名不会随文件改变。切组按钮打开全屏工作区选择页，选择后恢复该组上次内容；不使用窄抽屉或模态对话框铺长列表。

会话和文件仍作为全屏工作内容，不叠底部主导航。文件页顶栏返回回来源对话；对话页返回打开工作区选择页。选择页只有一个返回栏与滚动容器。现有产品主页面继续使用首页 / 项目 / 工具 / 设置底栏，本提案不改主导航。

## 技术设计

### 现有证据

- `ProjectTree.tsx` 当前会话行调用 `onSession(task, name)`，带 Agent 标识，但后续落点可能使用工作区恢复。
- `useTaskWorkspace.ts` 的 `returnToTask` 恢复文件；`activateSession` / `openTerm` 可激活具体会话并清空活动文件。
- `term-tabs-store.ts` 的 `FileTab.task` 表达文件工作区归属；当前标签存储为全局平铺列表。
- `task-last-tab.ts` 已有任务上次资源记录；新功能不再复制一份导航快照。

### 模块与职责

| 现有模块 / 拟新增组件 | 设计要求 |
| --- | --- |
| `frontend/src/components/terminal/` 现有标签导航、拟新增 `WorkspaceTabGroup.tsx` | 将现有全局标签按 `TaskKey` 派生为可展开组，保留组内资源直达与全局可达性 |
| `useProjectActions.tsx` | 分离组恢复与会话直达意图；侧栏真实会话入口不得继续转成“恢复任务” |
| `useTaskWorkspace.ts` | 原子提交活动会话 / 文件、校验归属、捕获来源会话，关闭文件只选同组有效资源 |
| `view-state.tsx` 的作用域 Hooks | 按节点 / 页面 / taskKey 保存折叠、上次资源和可恢复位置，不增加全局 Map |
| 现有文件标题与 `BackButton` / `BackLink` | 保留标题前的来源会话返回入口 |
| `frontend/src/i18n/` | 产品实施时补齐中英标签、状态及可访问名称 |

工作区身份复用 `TaskKey`，会话使用稳定 ID，文件使用现有规范化路径。原有文件去重与 `FileTab.task` 归属不变，同一文件不复制为多个编辑器实例。

组列表由现有打开标签与会话目录派生，不增加 API 或轮询。`lastResource = { kind: 'session', sessionId } | { kind: 'file', path, sourceSessionId? }` 只存普通数据；草稿继续使用文件资源作用域的 `draft` 策略。

实施时将旧 `task-last-tab.ts` 的状态迁入统一工作区仓库，成功后不再双写；服务器 `/workspace` 继续拥有打开标签和活动资源，组级恢复只表达导航意图。折叠作为可见偏好首帧读取本地镜像，再等 `preferencesLoaded()` 校准服务端值。React ref 仅承接 DOM，滚动快照按统一状态协议存普通数值。

键盘可依次 Tab 到组名、展开按钮与具体资源；Enter 激活，`aria-expanded` 标注展开状态，`aria-current` 只给具体当前资源。横向滚动不得吞掉页面中的键盘操作或移动手机输入焦点。触控命中至少 44，hover 只在精细指针生效。

### 后续产品验收条件

- 从文件点顶部同组会话，一次回到指定会话；未保存内容和位置保留。
- 折叠不切换、恢复组会展开；其他组始终可从顶部到达，侧栏不重复组内资源。
- 大量文件、长名、重名、多个会话、派生会话、已关闭来源、跨节点和刷新均不串组。
- 标签滚动、键盘焦点、拖拽排序和关闭行为遵守现有能力，不误结束会话或 worktree。
- 产品实现通过完整前端检查、运行时 full gate、四宽度与 Android 真机验收。

## 原型范围与复现

演示内容不读取真实会话，不连接终端，不写产品偏好。可操作：顶部组切换与折叠、会话 / 文件直达、文件回对话、浏览器返回、手机选择工作区、演示草稿保留、属性面板与深浅主题。没有保存、发送、关闭、拖拽或实际终端操作。产品级滚动恢复仍待实现验证。

仅开发者设计原型使用中文，不接产品 i18n；产品实现时必须进入现有中英语言包。图标与档位直接复用项目 `icons.tsx` 和 `useLayout()`。

