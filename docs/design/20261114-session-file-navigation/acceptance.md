# 顶部标签组原型验收

2026-11-15，第二版。仅验收设计文档与独立原型，产品导航尚未实现。

## 设计范围

- 当前原型没有左侧资源栏；会话与文件仅在顶部按组导航，右侧默认收起。
- 桌面所有组处于同一条横向导航；手机显示当前组与组内资源，从顶栏选择其他工作区。
- 第一版侧栏设计冻结在 [revisions/v1/](revisions/v1/prototype.html)，不作为当前推荐稿。
- 已核对现有 `FileTab.task`、会话稳定 ID、工作区恢复链路和现有设计 token。文件按工作区归组，不声称是某个会话的私有附件。

## 浏览器交互

真实 Chrome 实际点按通过：

- 组内“对话”直达会话，文件名直达文件。
- 收起组后具体标签隐藏，当前内容保持；点击组名恢复上次资源并展开。
- 从其他组返回恢复原文件；两个组的对话草稿互相隔离，文件草稿保留。
- 文件标题返回来源对话，浏览器返回恢复实际访问位置。
- 右侧属性栏开合正常，默认收起，未再复制资源列表。
- 深浅主题均已截图，页面脚本错误为 0。
