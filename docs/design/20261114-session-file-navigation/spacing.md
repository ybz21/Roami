# 页签与资源菜单间距修正

2026-11-16。沿用本目录的产品设计、用户故事和模块划分。

## 产品与用户故事

会话名称、资源下拉和关闭会话是相邻的不同动作。两枚尾部按钮使用相同的视觉尺寸和固定间隔；文件菜单的图标、名称和关闭按钮按列对齐。用户可以扫描普通文件名，也能选择超长名称、同名路径及未保存文件；名称省略时关闭动作仍保持可见。

菜单宽度受视口约束；靠近屏幕边缘时水平避让。长列表在弹层内部滚动，不改变工作区与文档大小。

## 技术设计

- `session-resources.css`：会话页签规则提高到具体组合选择器，避免后载入的通用 `.tt-tab` 覆盖；下拉与关闭视觉尺寸为 `--sp-5`，间隔为 `--sp-1`。
- 菜单复用 antd Dropdown / Menu；按其现有选择器层级覆盖组列表缩进与行内边距。图标统一占 `--sp-5` 的列，行内留 `--sp-2`；名称可收缩，状态和关闭按钮不收缩。
- 菜单整体宽度限制为 `min(40ch, 视口减两侧 --sp-4)`，标题内容允许收缩。`SessionResourceMenu.tsx` 启用现有弹层的水平移动与边界避让，避免右侧触发器翻转后菜单左缘越界。
- 不改变文件归属、草稿、关闭确认、键盘焦点或导航状态所有者；无新增接口、轮询及产品文案。
