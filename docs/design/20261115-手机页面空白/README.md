# 手机恢复会话后页面空白

## 产品设计

手机恢复共享工作区的会话标签后，首页、项目、工具和设置仍显示当前页面。只有实际打开手机会话覆盖层时才隐藏底页，返回后恢复原页面与会话标签。

## 用户故事

- 在电脑打开会话，再从手机进入项目或首页，能直接看到内容。
- 手机打开会话并返回后，可以继续切换底部导航，不必关闭已有标签。

## 技术设计

`useTaskWorkspace` 统一提供 `pageVisible`，由 `AppShell` 传给 `AppRoutes`。手机只依据覆盖层 `overlay` 判断页面可见性；桌面继续依据任务视图和工作区聚焦模式判断。共享标签、偏好和页面状态存储方式保持现状。

此前共享标签恢复后，手机的 `useWorkspaceLayout` 也可能产生 `focus` 模式，但手机没有打开会话覆盖层。`AppShell` 将桌面的聚焦模式用于手机，导致 `ViewBoundary` 隐藏整个页面。
