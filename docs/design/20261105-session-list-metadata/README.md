# 会话列表精简

## 产品设计

左侧项目会话树只展示会话名、Agent 标记、运行状态与时间。分支名和 worktree 路径不再占用每行的第二、第三行；父子会话的缩进、选中和菜单保持原有行为。

当前会话的分支集中在桌面顶部标签栏右侧。点击后展示完整分支名和目录；没有分支时使用目录作为入口。长名称截断，完整值在点击浮层中换行。页面标签和文件标签激活时隐藏会话信息，避免显示错误上下文。

## 用户故事

- 浏览多个会话时，直接按短标题找到任务，不受重复目录信息干扰。
- 进入会话后，在顶部确认分支，点击查看完整目录。
- 派生会话仍打开自己的实际工作区，跨目录派生关系不受显示精简影响。

## 技术设计

- `ProjectTree.tsx` 移除位置展示和相关参数，保留树与导航的数据关联。
- `SessionContext.tsx` 复用 Ant Design Popover 与既有 SVG 图标；点击、键盘聚焦和粗指针命中区可用。
- `TerminalPane.tsx` 通过现有 `useSessionProject()` 和 `taskDir` 提供顶部上下文，不添加请求或轮询。
- `index.css` 清除会话树的多行样式，为顶部入口和可换行详情提供 token 样式。
- 新增入口名称同时提供中文、英文翻译。
