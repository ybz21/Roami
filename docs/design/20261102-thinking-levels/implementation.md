# 思考强度产品实现

2026-11-04。对应已合入的方案 PR #607；本记录说明实际产品代码与验收。

## 产品与用户故事

首页输入栏、思考强度菜单及 Main / Worker 普通设置统一使用“默认、低、中、高”。
普通入口最多四项，按模型能力取子集；标题、选项及状态说明的文字从同一位置开始。
菜单移除与选档无关的执行器说明，每项提供一句用途说明，选中标记占独立右列。

已有 none / minimal / xhigh / max 等参数显示“自定义”，普通菜单不勾选其他档位。
打开、关闭菜单和取消操作保留配置与草稿；主动选择默认才清除显式参数。
模型设置的高级配置保留原始参数选择，可查看精确值，避免把 max 转成 high。
模型能力未知时说明当前限制，普通菜单只提供恢复默认，不使用通用七值回退凑齐四档。

## 技术设计

- `providers/reasoning_effort.py` 分开展示能力与原始协议兼容性。能力来源是仓库原有模型家族表；本次没有新增模型家族或宣称进行了上游探测。未命中表的模型返回 unknown 与空展示能力列表，原始参数兼容性保留。
- `server/model_settings.py` 的设置和模型目录回执增加 `reasoningSupport`，`reasoningEfforts` 仅用于已知展示能力。可区分 supported / unsupported / unknown；旧服务没有状态字段时，前端按未知能力处理。
- `agent-reasoning.ts` 集中管理能力子集、展示名称、自定义状态及高级原始值，首页和设置共用。存储与保存接口不迁移；默认依旧写 null，实际请求不携带 default。
- `AgentModelPicker.tsx` 复用桌面浮层与手机底部 sheet；保留原子保存、失败重试与节点切换时丢弃过期响应的流程。打开菜单聚焦当前项，方向键切换焦点，Enter 选择，Escape / 手机返回关闭。
- 中英文文案走现有 i18n。高级配置中的 low / xhigh 等原始值是协议参数，保留原文。
