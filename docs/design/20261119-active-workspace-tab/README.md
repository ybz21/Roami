# 顶部工作区标签选中态

## 产品设计

截图中的标签队列很长，当前项仅有顶端 2px 蓝线、中性底色和粗体，难以快速定位。
改为内容区一侧的 4px 蓝色底线（`--sp-1`）、`--text-bright` 标题和既有 `--sel-bg` 中性底色。
标题在深色主题保持白色、浅色主题使用深色；选中状态用底线、底色和字重表达，不增加文字或徽标。

项目前缀与关闭按钮使用 `--text-dim`，让会话主题成为主要视觉锚点。
Agent 品牌色、运行状态点、待确认文字继续使用各自语义色。

## 用户故事

- 打开多个会话时，一眼定位当前会话，切换后标记立即跟随。
- 切到页面、文件或固定标签时，看到同一套选中规则。
- 深浅主题均可识别；鼠标悬停不覆盖当前项，键盘焦点可见。
- 手机保留现有会话顶栏及主导航，点按、返回和安全区正常。

## 技术设计

仅修改 `frontend/src/index.css` 的公共 `.tt-tab.on` 样式。
用绝对定位的 `::after` 绘制底线，`pointer-events: none`，不改变标签尺寸或按钮命中。
`.dropL::before` 与 `.dropPeer` 保持各自拖拽语义；选中线不依赖阴影。
`TerminalPane.tsx` 继续负责选中状态和滚动定位，不引入新的状态、请求或依赖。
