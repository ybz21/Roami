# 会话创建与关闭反馈

## Product Design

异步创建会话时展示居中的 Ant Design Spin、当前状态、真实准备步骤和任务短名。取消入口直接可用；补充草稿默认折叠，展开后沿用持久化草稿。路径、时间、执行记录不占据等待画面。失败和结束状态沿用详情与恢复动作，不用动画掩盖错误。

关闭请求被后端受理后，前端立即从目录与会话列表隐藏，普通后台关闭进度不再进入收尾列表或占据会话页面；后端继续调度。失败仍保留收尾恢复入口。原生会话的 closing 状态同样隐藏。

## User Stories

- 提交任务后可立即确认正在准备，并看到实际步骤更新。
- 等待时可以取消，或主动展开输入补充；切换与刷新后草稿保留。
- 准备完成后可发送保存的补充；失败后看到原因并恢复。

## Technical Design

`LifecycleOperationView` 对未结束且无需人工处理的 create 操作呈现等待分支；其余操作保留既有详情。复用 lifecycle 状态、取消接口、`useLifecycleDraft` 与现有轮询，不添加定时器或请求。等待容器在 guard 中占满剩余空间；内部内容限宽，复用设计令牌。Spin 支持减少动态效果偏好，状态通过 polite live region 公布。

`useSessionOverview` 统一提供已受理关闭的名称集合，目录和会话列表据此排除仍存在于旧列表响应中的会话。`useNativeSessionList` 默认排除 closing；收尾入口只保留创建和需要恢复的关闭。
