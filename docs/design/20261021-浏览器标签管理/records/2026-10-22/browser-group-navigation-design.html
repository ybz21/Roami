产品设计

应用工作区标签和浏览器网页标签保持两层。网页标签栏右侧（用户截图红框位置）常驻“人工 数量 / 智能体 数量”，中间仅展示当前组，旁边固定“全部页面”入口。切组恢复该组上次查看的页面；空组在标签区显示“暂无页面”，保留当前网页直到用户选择其他页面。计数显示实际页面数，容量与超时配置仍放浏览器设置，不常驻占据浏览区域。

“全部页面”在桌面打开右侧目录，无需离开当前网页；默认分两段展示人工和智能体，提供标题 / 网址搜索、来源筛选。查看或筛选目录不切换当前网页，选择具体页面才激活并按需唤醒。每行只显示标题、域名、已知固定 / 休眠状态；创建来源与完整地址收进详情或菜单。原型为便于评审直接展示移组动作，产品沿用统一菜单，桌面和触控均有可见“更多”入口。

从界面新建始终归人工，工具栏写“新建人工页”，不随当前筛选变成智能体来源。可将智能体结果移到人工组，也可反向移动；移动不改写创建来源，不取消任务占用和未知操作保护，失败保留原组与当前页面。当前页面被移组时来源指示随之更新；移动其他页面不打断正在查看的页面。后台新增页面只更新数量，不抢组、不切页。被关闭或删除的组内最近页面回退到仍存在的页，不跨组猜选。

手机主浏览器保留标签入口；来源筛选置于“全部页面”中，使用 MobileSubPage 全屏二级页，一层返回栏，固定搜索 / 来源筛选，只有列表滚动。点页面返回浏览器，返回键仅关闭目录；桌面收窄沿用手机方案。空组显示“暂无页面”，搜索为空显示“未找到页面”，不追加零结果计数。只展示有可信元数据的状态，不虚构任务名和执行中标记。

用户故事

  • 我能直接查看人工页面和智能体找到的页面，来回切换时恢复各组上次阅读的位置。
  • 我能打开全部页面按标题或网站找结果，搜索和筛选时不打断当前网页。
  • 我能把有用结果移入人工组继续使用，原始创建来源保留，任务与输入保护继续生效。
  • 智能体在后台查资料时，我正在看的组和页面保持稳定；手机上同样能查找、选择和移组。

技术设计与交付范围

BrowserView                          唯一页面目录快照、激活页面及用户当前来源
browser-tabs.tsx / TabStrip           常驻来源切换、组内最近页面、标签条和目录入口
browser-tabs.tsx / TabSheet           桌面目录 / 手机 MobileSubPage，共用搜索与分组列表
TabInfo                              复用 origin / createdBy / pinned / sleeping
GET /browser/tabs + PATCH /tabs/:id   复用现有读取与移组，不新增后台轮询

每组最近页面在当前面板内记忆，恢复前核对目标仍存在；目录筛选是独立临时状态。后台快照合并只维护数据，不改写用户选择。原型演示基本两组；若增加“Agent 按任务 / 会话分组、人工自定义分类”，必须独立设计 subgroupId 与可靠创建归属，不能用网页 URL、模型品牌或当前任务租约推断历史创建者。设计已按用户指定位置进入实现；发布状态以本次验收记录为准。
