# 统一简洁返回按钮

## 产品设计

全站层级返回使用单个左向 Chevron SVG 图标，默认无描边、无文字尾缀，保留对应的无障碍名称。详情页可在箭头旁展示当前页面标题，标题独立于按钮；PC 技能详情采用与手机相同的「箭头 + 技能详情」单行标题栏，桌面字号沿用区块标题令牌。技能详情、模型配置、项目、OKR、记忆、后台任务、引导页及文件预览使用同一控件；已使用相同箭头的文件 / 浏览器历史工具栏维持原行为。方向键、翻页和手机硬件控制保留各自语义。

桌面按钮沿用控件尺寸，手机命中区至少 44px；鼠标悬停、键盘焦点和禁用状态保持可辨。真实链接仍使用 href，交互返回使用 type=button，不触发表单提交。返回路径、草稿和历史管理保持原有语义。

## 用户故事

- 在详情页使用同一种简洁返回按钮，返回原列表或上一级页面。
- 手机上直接点按箭头返回，辅助技术仍能读出目标名称。
- 编辑模型等表单时，返回不误提交；项目返回继续保留原查询条件。

## 技术设计

- `BackButton.tsx`：原生按钮与 `BackLink`，复用 `icons.tsx` 的 ChevronLeft；调用方可传上下文名称与原有回调 / href，统一不渲染文字。
- `index.css`：`.tt-back` 定义透明、无边框的图标按钮；字号、尺寸、圆角、颜色使用既有令牌，hover 仅限精细指针。
- `MobileSubPage` / `MobileNavigation`：二级页与手机顶栏复用同一按钮，返回历史与手势逻辑不变。
- 各业务模块将文字返回替换为共享控件，保留表单、来源切换和路由行为；引导页页脚同时适配新控件，保持返回在左、继续在右。

## 验收

前端全量 228 个文件、1,642 项 Vitest 通过，涵盖项目、模型、Agent、记忆和手机导航既有行为。桌面与 Android 真机验收记录在完成后补充。

最终验收：typecheck、i18n / hover、全量 Vitest 与 full 门禁通过。full 以已验证提交 5ff9eed2 对比，仅涉及前端和文档，按约定跳过 Python / Go。独立 Chromium 验证技能详情四种桌面宽度及侧栏开关，无文档溢出；返回按钮无文字，回车可返回并保留搜索草稿。项目缺失页的原生链接可键盘导航，引导页返回首页、模型编辑页返回列表均成功，表单返回按钮 type=button。

Android 真机通过 ADB 点按详情返回，再点手机顶栏返回：依次回到原市场和工具页。两层返回均为 44×44px，名称为本地化「返回」，图标按钮命中正确，无可见文字。详情返回保留官方 URL 草稿。
