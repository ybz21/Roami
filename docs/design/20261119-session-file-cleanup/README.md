# 关闭会话时收起关联文件

## 产品设计

关闭会话标签或从会话管理入口关闭会话时，一起收起该会话打开的文件标签。
只改变工作区打开状态，不删除文件，也不清除文件编辑器的受保护草稿。
其他会话打开的文件、独立打开的文件保持原状。

## 用户故事

- 在会话里连续打开多个文件，关闭会话后不再留下离散文件标签。
- 同一个 worktree 有多个会话时，只收起关闭会话打开的文件。
- 刷新页面、改会话展示名或从另一设备关闭会话，清理规则保持一致。
- 手机上关闭最后一个会话及其文件后，退出会话覆盖层，返回原页面。

## 技术设计

- `FileTab.session` / `WorkspaceFile.Session` 保存打开文件的稳定会话 ID。
  文件在另一个同工作区会话内重新打开时，归属更新到该会话。
- `useTaskWorkspace` 用持久归属恢复文件返回入口；关闭会话时同时更新文件列表与选中状态。
  文件仍使用原有 `task` 决定工作区，不改变文件分组、布局或文案。
- `workspace-state.ts` 与 Go `WorkspaceStore` 在应用会话移除操作时清理归属文件，
  合并最新状态中另一设备刚打开的文件，避免旧客户端遗漏文件。
- 现有会话目录确认会话消失后，沿用原有标签清理与工作区同步流程；不增加轮询。
  原生会话目录尚未加载完成时，保留待确认会话及其文件。
- 兼容旧数据：工作区只有一个打开会话时补全文件归属；多个会话共用的旧文件，
  在最后一个关联会话关闭时收起。没有可确认归属的历史文件不猜测归属。
- 编辑内容继续由 `FileView` 的资源作用域保护，关闭标签不删除草稿。
