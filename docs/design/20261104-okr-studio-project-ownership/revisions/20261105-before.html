活动场景与项目归属

产品问题

旧团队恢复为只读记录时没有工作室，具体活动里看不到 Three.js。宣传成员又因启动时被看到源码目录，出现在 Roami 源码项目下。

用户故事

打开宣传目标的具体活动，可以看回原团队场景，切到同一组历史任务和群聊；明确知道它是历史。切页、停动画、返回后保持选择。数据与复盘成员归宣传项目，开发 OKR 功能的 backend/frontend 继续归源码项目。

技术设计

LegacySwarmHistory 复用 SwarmStudio 与 studio-scene，旧记录映射为 idle；历史动画只转头，不敲键盘、不发送任务粒子。组件 active 控制 WebGL 生命周期。减少动态效果与后台仍停止渲染。

worktree.sessionHomes 以已登记普通项目和 session 台账的同一 stable ID/tmux ID 修复运行时缓存；Git 仓库的 worktree 绑定不覆盖。session-project 补全普通目录的最长前缀归属，task-tree 优先当前 placement，两个项目视图复用 swarmProjectMatches 保证 projectId 优先。

边界与集成

本分支只修这两个回归。项目文件包、看板定义、connector、团队记忆及执行机制由恢复的主会话继续；旧群不会自动变成新受管团队，不重新派发历史任务。
