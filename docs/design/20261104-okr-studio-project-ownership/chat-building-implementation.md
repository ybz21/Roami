## 本版边界

这是基于现有保存协议的聊天编辑工作台，不是独立草稿版本系统。服务端保存的定义直接作为预览来源；它不提供隔离文件草稿、历史版本切换、先确认再原子应用。用户聊天仍由既有 Main 工具权限处理，页面说明不能代替宿主范围约束。多执行器 Main/切换必须另行接入持久身份与协调协议，不能用当前任务委派选项冒充。当前左侧全局入口及手机项目页既有入口保留兼容，本批仅变更桌面项目详情入口。
