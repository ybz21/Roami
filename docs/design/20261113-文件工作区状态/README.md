# 页面工作区状态保留

## 产品设计

所有主导航页面在访问后保留实例。文件、浏览器、手机、设置、项目、能力等页面之间切换，或临时进入会话，再返回时恢复各自的选中项、输入、展开状态和滚动。文件页恢复目录、标签顺序、当前标签和分栏。保留隐藏文件、排序、搜索、路径输入，以及未保存的编辑和源码 / 预览选择。手机沿用同一份目录记忆，文件详情仍使用全屏二级页。

页面实例仅属于当前节点；切换节点会释放旧节点实例，避免全局节点地址变化后旧页面误读另一节点的数据。文件页另外按节点保存当前浏览器内的快照。刷新页面、退出登录后清空。文件栏宽度、分栏比例和预览滚动继续使用现有记忆机制。此变更不增加界面控件、文案或新的磁盘持久化。

## 用户故事

- 打开日志与两个 HTML 文件，切到浏览器再返回，文件标签和选中项仍在。
- 浏览器选中某个标签并切到手动模式，去文件页，再回来保持标签、模式和未提交的地址。
- 设置页或项目页输入尚未提交的内容，切到其他入口再返回继续填写。
- 编辑文件但尚未保存，去设置页查看配置，返回后继续编辑。
- 浏览子目录后切到其他页面，回来仍停在该目录，并能后退、前进。
- 切换节点时各自恢复自己的文件目录和标签；关闭的标签不再恢复。

## 技术设计

### 页面保留与活动范围

`AppRoutes` 为每个已访问的主导航页保存最近的路由，并在独立的 `RetainedPage` 中常驻渲染；每页保留自己的滚动容器和 Suspense 边界。切到会话时保持页面树，桌面关闭页面标签时释放对应实例。未访问的页面不挂载。页面组件接收最新业务数据和动作，但保留自己的路由与手机搜索请求。

`PageActivityProvider` 将页面是否在前台与文档可见性组合。页面的轮询、连接和全局输入监听使用 `usePageEffect`：隐藏时清理，恢复时重新建立，不清空 React state。应用壳层与终端等无页面范围的调用保持原有行为。共享会话订阅暂停观察时保留上一份快照。设置草稿的刷新离开警告继续覆盖隐藏页面。

每个页面的 Ant Design 弹层在独立的 body 容器中渲染，隐藏页面时一起隐藏，避免遮住其他页面。手机二级页与检查器同样遵循活动范围。首页隐藏时暂停自动选会话、标已读和向手机顶栏插入操作。浏览器 / 手机镜像暂停连接后恢复原选项；浏览器地址草稿不会被恢复轮询覆盖。文件页隐藏时释放 Monaco / 预览实例，沿用已有滚动记忆。

页面保留增加了已访问页面的状态与 DOM 占用；不宣称 CPU 或内存下降。通过隐藏时停止周期任务和镜像连接控制后台开销。

### 文件页快照

`AppShell` 的 `useFilePageMemory` 持有每个节点的独立内存快照，经 `AppRoutes` 传给 `FilesPage`。只有独立文件页的 `FilePageMemoryProvider` 启用记忆；会话文件面板和其他复用组件继续遵循原有生命周期。

`useFilePageState` 在提交后记录工作区和目录状态。`FileWorkspace` 保存标签、当前选中项、分组、焦点和左右排列；显式关闭文件时释放对应文件缓存。`FileBrowser` 保存目录、列表快照、历史、路径输入、排序和搜索，首次挂载不再重置目录。路径栏只通过 `Input.Search.onSearch` 提交，避免 Enter 同时被两个处理器提交而破坏历史索引。

`FileView` 保留读取基线、草稿和预览模式，重挂载后沿用基线判断未保存修改。文件页隐藏时清理文件轮询；恢复后继续通过原有 mtime 检查磁盘变化。源码编辑器及 HTML / Markdown 的滚动记忆复用现有实现。
