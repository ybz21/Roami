## 架构与行为

- 一份 `WorkspaceStateStore` 实现存取、字段订阅、草稿保护和缓存预算；已删除原 `page-view-state.tsx`、`file-page-memory.tsx`。原文件位置和表单草稿模块不再持有独立 Map。
- `ViewBoundary` 不含文件 / 浏览器 / 手机卸载名单。新页面通过 `definePage` 默认卸载；新增的未知页面名回归证明无需修改白名单就能重建并恢复。
- 专项回归覆盖同一字段多消费者一致、同批连续更新、无关字段不重渲染、显式 null、资源和节点隔离、缓存字节 / 项数预算、LRU、活动读取、草稿保护、关闭清理、拒绝资源实例、卸载后的刷新警告及订阅释放。
- 本地节点与名为 `local` 的远端节点分别存储，切换时重建控制器；浏览器普通视图和任务绑定视图分别恢复，返回原节点时恢复该节点状态。
- 现有复杂表单 / 对话控制器显式保留；它们共用统一边界，活动任务暂停和重型子视图释放保持有效。没有声称自动序列化任意局部 React state。

## 生产版与真机

使用 `scripts/dev/isolated-roami.sh` 启动两个独立后端 / tmux，分别服务基线和本次生产包；镜像 Chrome（29482）和验收 Chrome（29483）使用不同 profile。每轮新建浏览器上下文，1920 × 1080，打开相同的 30 个 480 KiB 日志文件，再重复“文件 → 浏览器 → 设置”20 轮。每次采样等待 1.5 秒并执行两次 GC，读取 CDP 的 V8 堆和 DOM 计数。

| 时点 | 887898a0 JS 堆 | 统一内核 JS 堆 |
| --- | ---: | ---: |
| 一个文件预热 | 30.98 MiB | 31.10 MiB |
| 30 个文件，文件页在前台 | 35.82 MiB | 36.93 MiB |
| 文件与浏览器均隐藏 | 27.23 MiB | 27.86 MiB |
| 往返 20 轮后 | 29.11 MiB | 29.23 MiB |

20 轮后差异约 +0.12 MiB，两端 DOM 均为 826，隐藏文件页的内容节点均为 0。本次版本第 1–20 轮的监听器均为 953，较基线多的 1 个用于统一的草稿刷新保护。此重构主要统一所有权和未来接入规则，不宣称额外降低内存；也不把 V8 堆等同于 Chrome RSS、GPU 或后端内存。有限样本不证明无限次切换零增长。

缓存默认预算是 200 项、估算数据载荷 2 MiB；活动读取暂不淘汰，未保存内容不参与预算淘汰。这是缓存预算，不是整个应用内存的硬上限。
