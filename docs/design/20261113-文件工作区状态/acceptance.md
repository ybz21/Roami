# 页面状态保留验收（初版）

本记录对应 `148694f9` 的初版常驻实现；后续按需卸载与内存对照见 [memory-acceptance.md](memory-acceptance.md)，其中替换了列表节点常驻的实现。

日期：2026-11-13。基线：`8c886c6419d1b4ea613a2173ef090a4cb03882a3`。

## 环境与方法

使用 `scripts/dev/isolated-roami.sh` 启动私有后端与 tmux；镜像另用私有 Chrome（CDP 19482、独立 profile），与桌面验收浏览器分开。测试文件均为本次生成的日志、Markdown、HTML 和长目录列表。手机为通过 LAN 访问自签 HTTPS 的 Redmi Note 8，实际运行 Android Chrome；每次构建后硬刷新。触摸通过 CDP touchStart / touchEnd 和合成触摸滚动执行，并检查实际命中点。

原始边界与状态断言记录在 [acceptance.json](acceptance.json)。截图附在本变更 PR，通过 `pr-shots` 孤儿分支存放。

## 行为对照

| 场景 | 原版 | 修复后 |
| --- | --- | --- |
| 三个文件标签，切浏览器再返回 | 标签全部消失，目录回到默认位置 | 标签顺序、选中项和目录保留 |
| 日志输入未保存内容，切设置再返回 | 页面卸载会丢失编辑 | 未保存文本与脏标记保留 |
| 文件拖到第二编辑组，切设置再返回 | 分栏丢失 | 编辑组、当前标签和分栏保留 |
| 浏览器选标签并输入未提交地址，切文件再返回 | 地址被真实 URL 覆盖 | 保持选中的 State First 与地址草稿 |
| 设置搜索“模型”，切项目或能力页再返回 | 搜索清空 | 搜索输入和对应 DOM 实例保留 |
| 手机在文件目录中切设置、工具后返回 | 回到默认目录 | 仍在原测试目录 |
| 手机浏览器输入地址后切设置再返回 | 草稿丢失 | 地址草稿保留 |
| 手机长文件列表触摸滚动后切页返回 | 页面重建 | 滚动 400px，返回后仍为 400px，列表节点保持连接 |

浏览器隐藏超过其 3 秒刷新周期时，标签与健康接口新增请求为 0；文件页隐藏时没有继续发文件 stat 轮询。恢复页面后镜像重新连接并显示所选测试标签。上述指标只证明后台活动暂停，不代表 CPU 或内存下降。

- 桌面覆盖 1280、1920、2560、3440 CSS px，文件栏展开 / 收起共 8 组边界检查；均无文档横向溢出，内容使用页头以下的实际可用高度。
- 真实鼠标完成标签切换、分栏拖放、文件栏开合、编辑和跨页面导航。

## 范围

此变更保存当前浏览器应用实例内的工作状态。刷新、退出登录会重建页面；节点切换释放旧节点页面以隔离全局 API 地址，文件页另有节点内快照。页面保留增加已访问页面的状态与 DOM 占用，隐藏页面会停止周期任务并释放镜像连接、重型文件预览。
