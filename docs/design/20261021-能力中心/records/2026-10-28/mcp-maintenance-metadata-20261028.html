MCP 保活与中文名称 · 2026-10-28

Product Design

MCP 显式连接后保存开启状态，在运行时重启后自动连接。空闲连接通过协议心跳检测，失效后退避重连并重新发现工具；连接成功只在初始化和目录校验通过后显示。已经发出的工具调用不自动重放，未知结果仍需用户或任务自行确认。新建和编辑支持中文名称及描述，列表、详情、搜索和 Agent 工具目录都使用这些信息。

User Stories

  • 开启 MCP 后，无需保持能力页打开，Agent 可继续发现和调用工具；进程退出或远程会话失效后自动恢复。
  • 修改中文名称和描述后，连接、工具引用和已保存的工具开关保留；保存失败时保留表单输入。
  • 服务不可用时显示正在重连，不假报已连接；删除服务和关闭运行时后停止重连及子进程。

Technical Design

tools/mcp.py 由每连接监护任务维护已有 SDK actor，空闲 30 秒发送 ping 并刷新工具目录，健康检查限时 10 秒、初始化限时 25 秒，失败按 1 至 30 秒退避。用户调用与心跳由同一 actor 串行，重连只恢复会话和目录，不重放调用。运行时启动恢复 enabled 项，卸载同时取消监护和 actor。capability_imports.json 沿用原子私有文件，新增 enabled、displayName 与 description；缺字段的旧登记仍兼容原名称与首次显式连接方式。

稳定 ASCII name 保留为工具引用，新中文名称由 displayName 承载；新建只填中文名时自动分配引用名。元信息编辑不重建连接，注册表的描述立即更新，别名摘要保持只取远程工具协议与权限。CapabilityEditor、CapabilityCatalog 复用现有控件、i18n 和 MobileSubPage，不增加页面轮询。

验收记录

验收：full 质量门禁通过（Go 全量、Python 全量 1683 项、静态与格式检查、前端 typecheck／i18n／hover／生产构建及秘密扫描）；最终 MCP／Agent／目录定向 67 项和前端 142 文件／1038 项通过；实际生产包 83 项检查覆盖七档宽度、中英文、深浅主题、编辑保存、刷新恢复与命中，无文档横向溢出。stdio 进程退出、心跳超时、Streamable HTTP 会话过期、运行时重启、未知调用不重放、工具权限保留及原子保存回归通过。隔离 HTTPS 服务实际杀掉夹具进程后约 31.2 秒恢复，运行时重启后自动恢复开启项；中文描述通过真实 CLI 查询返回 7 个目录项。目录回退规则保留同分类的直接文字匹配，避免中文元信息被其他分类的别名命中隐藏。证据入口 /tmp/mcp-keepalive-20261028/index.html。粗指针为桌面模拟；Redmi Note 8 仍处于安全锁屏，真机触控、软键盘和安全区验收未完成。未调用付费模型，未部署现用服务。
