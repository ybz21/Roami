复用 Go LLM Gateway · 2026-10-28

Product Design

直接复用 ~/codes/llm-gateway 的 Go 网关及现有模型连接。Agent 只处理对话和任务，主、后台、记忆及评测的 HTTP 模型连接直接请求网关，由 Go 网关统一定价、计费及额度拦截。模型设置只保留连接和模型选项，并提供网关入口；原本地价格、限额和统计入口撤下。外部专业 CLI 保持各自现有连接和登录配置。

User Stories

  • 旧的本地未知费用不会阻止新对话；真实额度不足由 Go 网关返回，界面显示恢复方向。
  • 价格、消费和额度在同一 Go 网关管理，无需在 Agent 中重复配置。
  • 失败事件立即显示，历史刷新失败也不会让回复状态消失。

Technical Design

app.py 与 providers/factory.py 移除 ModelProxy 及其传输包装，工作流移除本地费用预检查和计费上下文。现有连接地址、密钥与模型路由继续由 ModelSettings 管理；旧 proxy 字段原样保留作历史材料，不参与配置验证和模型准入，新的设置写入不再接受该字段。原 model-usage 接口只读旧账并标为 archived，模型执行不再读写该账表。

费用与额度复用 llm-gateway/internal/observe/pricing.go 与 internal/billing/middleware.go 的实现，无单价按网关既有零默认值处理，402 作为普通模型 HTTP 错误传回。前端复用现有错误活动组件，turn.failed／turn.interrupted 在 SSE 投影时立即显示；首条回复创建前的失败同样保留终态；晚到的 POST 回执只补入对应用户消息，保留 SSE 已确认的轮次状态，不能重新排队。保留用户输入和局部输出，所有新文案进入中英文语言包，不新增配置或监听端口。
