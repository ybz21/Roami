# 精简 Main 选模列表

在首页输入 `/model` 或点当前模型，都会打开同一个选择器。标题下直接显示搜索框，列表保留模型名称、原生或聚合类型、输入输出、能力及价格状态。切换生效说明在列表下方。调用 ID 从列表行移除，仍可用完整 ID 搜索同名模型，网关继续提供调用 ID 和复制入口。

沿用现有 `AgentModelPicker`、`/model` 命令与网关目录，选模请求仍使用稳定 ID。桌面弹窗标题减少垂直留白，手机沿用全屏选择页和触摸返回。

回归覆盖隐藏 ID 后按完整 ID 搜索同名模型并切换到正确路线，以及桌面和手机在 Main 工作中用 `/model` 打开选择器。
