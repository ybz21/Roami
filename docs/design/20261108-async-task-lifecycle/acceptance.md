# v1 原型验证

日期：2026-11-08。验证对象是 HTML 交互方案，不是服务端异步功能。

## 桌面

使用 Roami Chrome 所连接的真实浏览器，通过临时 Playwright/CDP 验证脚本操作本方案专用标签页。

8 组交互场景通过，无页面 JavaScript 异常：

1. 创建后同一条目立即处于准备中；就绪前发送禁用；草稿保留；重复提交不增加资源。
2. 准备失败在原资源身份和操作记录上重试。
3. 取消先进入取消中，模拟补偿完成后才标记已取消。
4. 关闭受理时不轮转；模拟停止确认后轮转，清理尚未完成时下一排队任务已运行；任务未被标成验收成功。
5. 合并成功、清理失败后，从清理步骤恢复，不重复合并。
6. 合并冲突保留资源，明确处理后继续。
7. 模拟服务重启和页面刷新恢复同一操作，保留已确认步骤。
8. 模拟客户端断线期间后台继续推进，重连读取最新状态，不再创建资源。

1280、1920、2560、3440 CSS px，各验证控制栏打开／收起与详情打开／收起，合计 16 种组合。
文档无横向和纵向溢出，列表与详情使用剩余高度；收起后空间返回工作区。产品决策与技术方案页可独立滚动，浅色切换正常。

## Android 真机

Redmi Note 8（序列号 216d6a43），Android Chrome，经 LAN 打开静态方案。使用方案独立标签和本任务创建的 18732 调试转发，不操作真实任务。

- 实际为 compact／coarse，约 393 CSS px；横向无溢出，文档没有额外滚动条。
- 新建确认框可触控提交，提交后退出确认框并出现准备中条目。
- 准备中可输入草稿，发送按钮禁用；刷新／切换后草稿仍在。
- 等待准备完成后，原草稿保留，发送入口启用。
- 键盘弹出时底部导航隐藏；确认框在可见高度内滚动，输入区按键盘高度和令牌间距避让。
- 使用 ADB 实际点按详情返回，回到列表；草稿不丢。
- 使用 ADB 实际点按发送，草稿清空，补充内容进入当前会话的模拟输入队列。
- 使用 ADB 滑动技术方案内容，内部 scrollTop 从 0 增至约 349，文档本身不滚动。
- 顶栏、底栏、详情返回栏可达；详情只有一个内容滚动容器。
