# 主会话上下文与检索恢复

关联 #352、#407；基线 main 20c6b14。

## 目标

首页先回答当前问题，避免每次读取所有旧工具记录。默认回报简短、使用当前用户的语言；完整结果和调试请求保留原文。检索不再因默认三标签预算而中断，也不在失败页面上无证据地重复观察。

## 方案

- Main 首轮保留所有用户消息、已存在的有效压缩摘要、最近一条普通答复及当前完整工具轮。明确的详细结果/调试答复也按需恢复，避免把它们下一轮又当成指令。历史助手调用与工具结果按需读取，Worker 视图保持完整。
- `conversation_history` 只恢复当前会话当前轮的正常历史投影；沿用所有者、分支、遗忘和上下文准入检查。明确 `task_status includeResult=true` 同样恢复完整历史。后续轮不会因进度查询再次隐藏已经请求的详情。
- 视图使用独立 requestBasis，重新估算实际可见上下文，不能把小视图的用量校准用于完整历史。Debug 保留 historyView 与隐藏记录数；不删改持久化消息。
- 当前请求前注入简短交付契约，区分日常状态和明确原始字段请求。Main 通过 `reply` 提交最终答复、通过必填 taskId 的 `task_reply` 回报一个任务，通过独立的 `task_queue_reply` 回报总队列，避免单任务问题落到无关旧任务的汇总；常规路径一次模型请求结束。仅发现客套话、中文回报英文请求、直出内部字段等错误时拒绝交付并让同轮修正，不截断、不替换内容、不增加固定改写请求。明确的详细/调试输出提供用户原文 scopeQuote 后保留完整内容。中英文对话正文属于 i18n 标准允许的 Agent 对话例外。
- 旧 task_steer 会把助手续作计划存成 user 消息，曾导致来源清单、条数和步数限制被误当用户要求。新记录保存 sourceUserMessageId；旧记录用成功工具回执关联 operationId 找回真正用户消息。Main 首轮隐藏这些执行计划，完整视图把它们标为历史执行数据。手动任务干预仍是用户约束；遗忘的来源不会复活。历史摘要指纹包含角色与来源语义，旧摘要不能继续复用原来的错误归属。
- 完成回调把执行器证据放入系统数据，最后单独呈现原始用户问题，避免证据语言覆盖用户语言。已配置的正预算仍有效；本机旧配置 max_tabs=3 的无限设置已在隔离运行时验证；生产配置应与支持 0 的新运行时一起更新，避免旧版本启动时拒绝新值。
- 浏览器观察保留协议已经捕获的文字、链接和 URL，去掉额外的 3KB / 12 控件 / URL 截断。下游不能把未看到的内容当成网页缺失。
- 浏览器 `max_tabs=0` 为默认无限，正整数表示显式预算，取消固定上限；已有正整数配置继续生效。资源所有权、输入停止证据和用户接管检查保持强制。
- 研究任务观察失败后记录 task/run/resource/scene 的事件。同轮同资源同场景再次观察直接返回不可读，避免重复驱动调用；新场景、新尝试和其他来源不受这条记录阻挡。无场景变化再次重复同一阻塞，或更换网址重试同一已满容量时，关闭后续工具输入，允许仅基于本轮证据回报已核实结果和未确认项；没有可核实内容则如实失败，不依赖次数/时长预算。停止导航后的未知结果仍保留未知；不会据此放行未知写入。取消或不可重试完成回调禁止写操作；不能靠重新派发任务绕开失败。

## 自查

保留所有用户约束可避免因省上下文丢失偏好；最近答复支持连续追问。更早的助手决定依靠显式历史读取，必须测试准确引用而非猜测。保留的用户消息或最近答复仍可能较长，因此不承诺固定输入上限。视图减少输入量不等于 CPU、内存或整体延时都同比降低。

失败栅栏只能说明该场景未读到，不能证明页面永久失效。允许可信新场景/新尝试恢复；不能为了重试主动放宽所有权或绕过暂停。页面自主恢复但没有新场景证据时，本次研究应换公开来源或说明限制。

## 验收

完整质量门禁覆盖 Go、Python 与前端检查，数量和结果记录在 PR 中。原十题三轮真实主模型回报通过；数字题曾暴露缺省语言参数导致无法交付，现改为由原请求推导、默认简短。真实 Chrome 天气原题成功、未调用文件写入工具。主会话进度不再复述额度清单或追加客套追问。长检索也暴露了助手补充示例被当成验收清单的问题：自包含检索原话下发，已有可用核实答案即可附限制交付；不穷尽助手补充的服务。完整结果和负例保留在 PR #410 的验收记录。

自动测试覆盖无限预算、显式预算、失败栅栏跨驱动重建、场景变化恢复、所有者隔离和暂停；上下文测试覆盖完整用户约束、历史精确恢复、遗忘排除、用量基准隔离。真实 Chrome 保留原失败历史，重复原题并测试中英状态、完整结果、原始字段、自然天气问题。原十题三轮使用真实配置主模型和受控成果证据，单独标明与真实浏览器检索的区别。报告保留题目、完整回复、耗时、来源和负例。
