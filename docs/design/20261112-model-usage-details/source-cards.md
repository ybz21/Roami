# 模型源卡片简化

## 产品设计

模型源列表只展示身份、协议与认证、模型摘要和默认定价状态。整卡点击进入连接详情，移除卡片里的改名、配置、定价、账号调度、更新和删除快捷按钮。列表左上角默认单价入口移除；默认单价仍可从模型源定价页进入。

新建入口位于列表顶部右侧，使用“+ 新建”按钮；菜单保留添加模型源、导入插件源和本机模型源入口。按最新确认移除虚线占位卡片，无模型源时仍保留顶部新建按钮。

## 用户故事

- 不同模型数量、长名称和备用源提示不会改变卡片尺寸。
- 点击任意一张源卡片后，按“连接、模型与定价、账号调度”完成编辑。
- 在连接页修改名称、读取模型列表、添加插件账号或删除；仍保留删除确认和备用源保护。
- 手机可用整卡点击进入，使用顶部新建按钮创建，详情为完整二级页。

## 技术设计

`ModelHub` 保留详情路由和已有草稿状态。列表区域使用原生按钮覆盖卡片，提供本地化可访问名称与键盘焦点；未嵌套交互控件。顶部新建按钮复用现有 Dropdown 菜单。

`model-hub.css` 使用等分网格行与拉伸对齐，摘要适度截断；默认定价区域底对齐。`ModelSourceEditor` 将名称放在连接字段中，添加账号位于插件登录区，删除管理操作在内容滚动区。原有定价、调度、发现、保存与删除 API 不变。
