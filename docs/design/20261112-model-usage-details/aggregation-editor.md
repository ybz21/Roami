# 聚合编辑与网关模型目录

## Product Design

- 聚合的名称与对外模型 ID 均可编辑。改名保留旧 ID 的兼容入口，新的模型目录仅公布新 ID；已保存的嵌套引用统一为新 ID。
- 添加成员先选源，再多选模型，可全选该源、按源公布的免费输入/输出价格筛选。已添加成员不重复选择。一次添加完整选择，不静默截断。
- 聚合支持最多 64 个成员；展开嵌套后仍最多 64 个模型，路由展开仍最多 256 个账号/Key，嵌套深度与并发额度查询限制保持不变。普通故障转移仍最多 8 个候选。
- 桌面编辑器旁显示草稿的调度预览；手机在编辑页中显示。顺序、用完再换、轮流与权重展示新调度周期的前 12 轮示意，支持模拟跳过一个不可用成员。智能、额度、到期、速度、价格展示判断顺序，不伪造实时指标或排名。保存后的渠道列表仍来自真实路由状态。
- 网关页增加模型目录：按源、能力、名称/ID 搜索；区分已添加的网关模型和源中尚未添加的模型。展示上下文、最大输出、输入/输出类型、工具调用、推理和输入/输出美元标价。没有公布的数据显示“未提供”，不从模型名字推断能力。
- 目录标价是源公布的美元每百万 token 输入/输出价格，实际路由与计费仍遵守用户在源内的定价规则。

## User Stories

1. 我可以把 hy4 改成 free，旧的调用配置继续有效，父聚合不会失去这个成员。
2. 我可以先选 OpenRouter，再筛选免费模型并全选，一次加入聚合；超过限制时先调整选择。
3. 我可以对比权重 3:1 与轮流分配的示意，并查看一个成员不可用时的分配变化。
4. 我可以在网关页查看每个源的完整模型列表，筛选支持图片或工具的模型，并分辨能力未知和明确支持。

## Technical Design

- `agentproviders.ReadSourceModelDetails` 复用既有源鉴权、禁止重定向、超时、Anthropic 分页、去重与 ID 过滤；只投影经过约束的能力字段。新详情读取上限 8 MiB，原有仅 ID 调用保留 1 MiB 限制；模型数仍有 1000 的边界。
- `catalog/discover` 与 `catalog/source-models` 保持旧 `models: string[]` 响应兼容，附带 `details`。插件能力使用其已校验的模型数据。读取目录不保存配置、不发模型推理请求。
- 聚合保留至多 32 个历史 ID。别名只能来自同一个已有聚合，禁止与其他模型/别名/默认入口碰撞，禁止凭空注入别名或吞并其他模型。网关请求、原生绑定和默认模型识别均支持兼容 ID；绑定使用记录归并到现 ID，删除保护覆盖历史 ID。
- `source-model-directory.ts` 的组件内结果按源与配置 revision 区分，离开时取消请求，不轮询、不写数据库。`GatewayModelDirectory` 每源每页 30 个模型，避免手机一次渲染所有条目。
- `routing-preview.ts` 只执行草稿示意的平滑权重/轮流计算，不调用运行中的调度器、不改变游标。动态策略使用优先级步骤和成员图，不把示意称为真实分配结果。
- 不新增监控采集、持久化或保留期；原有 24 小时滚动监控限制保持原样。

## 成员排序交互

### Product Design

路由策略决定实际优先级；配置顺序决定固定顺序策略的先后、轮流的轮转顺序，以及自动策略条件相同时的顺序。预览列表展示当前策略与对应的顺序说明。编辑状态直接在预览成员行里提供拖动手柄、上下移和权重；不再在两处重复列出编辑器。

“整理顺序”支持按模型源分组（源内相对顺序不变）、按模型名称排序，操作直接调整待保存的候选顺序；它们是一次整理动作，不是持续覆盖手动顺序的路由策略。手动拖动后保留该顺序，点击保存后提交。

### User Stories

- 我可以直接拖动预览中的模型，把希望优先调用的放前面，马上看到前 12 轮分配更新。
- 我可以先按模型源分组，再手动调整同源成员；权重始终跟着原来的成员。
- 在手机上可以抓住手柄拖动；列表其他位置正常滚动，也可点上下移。键盘用户聚焦手柄后用上下键，Home/End 移到首尾，Escape 取消拖动。
- 智能、速度、价格等自动策略解释手动顺序只在条件相同或相近时生效，不把手动顺序误当作实时排名。

### Technical Design

`AggregationMemberOrder` 统一成员顺序、快捷整理和权重编辑。`useAggregationMemberDrag` 使用 Pointer Events 与指针捕获同时处理鼠标/触屏，仅手柄禁用原生触摸滚动；超过移动阈值后显示原行和插入位置，松开才修改草稿。拖到滚动区域边缘时使用 requestAnimationFrame 滚动所在面板，不滚动文档；取消、离开落点、丢失捕获、保存、切换编辑器或卸载时不提交意外排序并清理动画。

候选以 source/model 身份移动，不按数组位置搬动权重。保存使用原有 candidates 数组；不增加数据库字段、后台排序任务或轮询。不同协议的源可以重新排列而不重定义聚合入口协议，调用时原有协议过滤继续执行。

### Acceptance

单元回归覆盖键盘首尾/上下移动、鼠标拖动在松开前不修改、取消及越界落点不修改、保存顺序与预览更新、权重随成员保留、源内稳定分组、保存时禁用，以及不同协议候选重新排序后的入口协议保持。


排序交互验收见 [evidence](aggregation-order-evidence.json)：桌面四种宽度与面板开关均无溢出，鼠标从首项拖到第三项、Escape 取消、源内稳定分组、键盘首尾移动、权重保持与保存回读通过。Redmi Note 8 真机验证 17 个成员的触摸拖动、取消、边缘持续滚动、源分组、上下移、正常滑动不排序、保存回读及页面无溢出。

完整前端 253 文件、1,815 测试通过，新增排序与保存回归共 9 项；typecheck、i18n、hover、生产构建、Go 网关回归及完整 quick 门禁通过。验收中另修正服务端省略 false 时“仅用免费来源”被误显示为选中的问题，新增回归断言后 5 项聚合工作区测试通过；新建聚合仍默认仅用免费来源。
