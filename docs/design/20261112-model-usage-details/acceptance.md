# 概况与审计原型验收 · 第二版

验收日期：2026-11-12。状态：待用户确认，未开始产品前后端实现。

## 信息结构

- 「概况」和「审计」是大模型下两个同级 Tab，默认打开概况。
- 概况统一展示用量、每日限额、汇总、趋势和分组统计；今日额度不受统计筛选影响。
- 审计直接呈现逐条请求，不显示概况的额度、汇总和趋势模块，也没有内部「概览 / 请求」Tab。
- 点击概况分组或趋势进入审计，保留对应筛选条件；调用详情返回审计。
