# 模型源定价与免费聚合 · 原型增补

本文件记录原型评审阶段。后续正式实现见 [产品接入](product-integration.md)。

本轮只增补静态原型。用户要求暂停接口规范整理，未新增或迁移真实接口，也未改变已实现的概况 / 审计代码或当前真实计价、路由行为。

## 产品设计

在大模型下新增同级「聚合」页，提供多个对外模型入口，例如 `free-default` 和 `free-code`。每个聚合独立配置候选列表与策略，智能体选入口，调度选择实际模型源。

添加候选先选模型源，再从该源下选择模型，点击「添加候选」。未选源时模型选择不可用；切换源会清空待添加的模型，已经添加的候选保留，可跨源排序和移除。已添加及不符合免费条件的模型不能重复加入，选项直接标明原因。

定价放入模型源编辑器：源默认策略支持继承全局、按 Token、明确免费、套餐额度和未知；源内模型可覆盖默认策略。全局定价页保留兜底策略、币种与各源策略概览，并可直接进入对应源配置。普通输入、缓存读取、输出分别定价；额度与货币不是同一单位。源定价的单位跟随已保存的记账币种，未保存的全局编辑不覆盖源草稿。

免费 API 是默认候选范围；套餐额度通过每个聚合里的开关单独纳入，不与无限免费混为一类。原型中的 `Free API A / B` 和 `demo-free-*` 是显式示例，不表示任何真实供应商当前免费。

填写三项 0 元不会自动成为免费候选。源必须有明确的免费策略和条件确认；模型覆盖为付费或未知时，覆盖结果优先。套餐额度只有已知且足够时可用，未知不计为 0，不切换到付费扣费模式。

最新修订：路由策略已扩展为默认 smart 等九种，详见 [路由策略与监控](routing-monitoring.md)。下表的优先级 / 轮询对应当前 order / rotate。

## 每个聚合可配置的策略

| 设置 | 行为 |
| --- | --- |
| 优先级 / 轮询 | 按候选顺序选首个可用模型，或在可用候选之间轮询 |
| 候选顺序 | 独立选择模型并上移 / 下移，最多 8 个，与现有候选规模契约一致 |
| 限流冷却 | 可选 30 / 60 / 120 / 300 秒；冷却期间跳过该源，到期后重新参与 |
| 限流时切换 | 开启则尝试下一候选，关闭则按当前策略停止 |
| 额度耗尽时切换 | 开启则尝试下一候选，关闭则停止；从不回退付费模型 |
| 套餐额度 | 每个聚合独立选择是否纳入，余额按来源自身单位记录 |
| 能力要求 | 是否需要工具调用、最低上下文长度；不满足要求的候选跳过 |
| 启用 / 停用 | 停用后不会调度；没有可用免费候选时停止并展示原因 |

开始输出后中断始终停止切换，不把已经开始执行的请求自动重放到另一模型。这个行为不作为可随意关闭的重试选项。

## 用户故事与交互

1. 我创建一个免费通用入口，先选择源，再选择该源模型并添加；从另一个源再添加候选，设优先级；第一个限流时，另一个接手。
2. 我创建编码入口，要求工具调用和足够上下文，设轮询；不符合能力的模型不会被选中。
3. 我只想用免费 API，保持套餐开关关闭；需要利用 WorkBuddy 等套餐时，显式纳入并按积分记录。
4. 我希望限流后直接停下，在该聚合内关闭切换；其他聚合的策略不受影响。
5. 我把源策略改为按量计价，或把某个模型改为未知价，它立即退出免费池的可用候选；不会因为价格字段是 0 而误入。
6. 我切到概况或模型源配置后回来，聚合草稿、候选和策略仍保留。

「调度演示」可模拟正常调用、首选限流、额度耗尽和开始输出后中断。可推进示例时间或恢复示例状态，所有结果都来自本页示例数据，不访问真实模型。

## 技术设计与接入边界

- `assets/source-pricing.tsx`：源策略、模型覆盖、免费确认及原型内价格解析；源编辑保存仅提交当前源的变更，保留其他源和全局设置。
- `assets/model-aggregation.tsx`：聚合配置、资格判断、优先级 / 轮询、源级冷却、套餐余额和演示执行记录。草稿与运行状态分开，未保存策略不会改变演示中的已保存聚合。
- `assets/model-management.tsx`：模型源、全局定价和聚合之间的交互联动。
- `assets/prototype.tsx`：加入同级聚合入口，其余导航结构不变。

真实接入仍应在 Go 网关完成资格判断、调度、状态并发保护和审计；Python 不增加 Token、请求数或支出准入上限。HTTP 限流的真实冷却不能早于上游明确的重试时间。候选能力、免费条件和套餐快照要有来源与有效期，未知或失效时不可自动认定可用。

已核对当前代码：`PricingConfig.LookupExit` 优先对外模型价，随后源 / 原生模型价、模型通用价、全局默认；尚无源默认策略。Magpie host 会输出 `free` / `rate` 等信息，但 `modelplugins.Model` 尚未完整保留这些字段，Go 侧也未统一接入套餐额度。现有 `failover` 只对明确未发送的拨号失败切换，不能把原型中的限流 / 额度调度当成已上线能力。

本轮不改动现有出口定价优先级，也不整理 `/llm-gateway/...` 接口规范。
