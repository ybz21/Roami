# 用量与定价交互重做

状态：交互稿已确认并接入正式页面，见 [实现与验收](interaction-implementation.md)。入口：[interaction-review.html](interaction-review.html)。沿用本主题目录，保留已上线版本和原有八页原型。

## 产品设计

### 用量分析

截图中的问题不是缺少底部模型分组按钮，而是概况趋势退化成单一总量、模型请求量不再直接可见，小时数据也没有接回新工作区。新的主路径为「选择周期与范围 → 分组 / 指标 / 时间粒度 → 查看模型对比 → 选择时段概况 → 进入审计查看请求明细」。

- 默认直接展示按模型拆分的请求量；今天默认按小时，近七天默认按天。分组支持模型、源、智能体和总量；指标支持请求量、总 Token、输入、输出、缓存读取和费用。
- 颜色图例直接显示各组数值。点击图例聚焦单组，再点恢复；点击柱形只更新时段概况，不在概况页展示明细表。请求量是整数，请求总数包含费用待核对的请求。
- 多天周期仍可选择其中某一天按小时分析。小时明细遵守现有 48 小时保留期；已归档日期展示明确状态并可切回按天，不生成不存在的历史请求。
- 概况仅保留额度、汇总、趋势和分布；逐条请求与分组统计表都归入审计。点击「进入审计」时携带当前范围；返回保留原有分组、指标、时段和筛选。零结果不显示零计数或分页。
- 今日额度是独立的全局区，不受分析筛选影响。未知费用不算作 0，余额保持待核对。模拟时钟固定为 2026-11-13 18:00、Asia/Shanghai，后续小时为空。

### 模型源定价

定价统一归属于「模型源」，侧栏不再保留独立定价入口。模型源页提供全局默认价入口，卡片内进入该源与模型的定价。源内查看全局默认价后返回原源并保留草稿；从卡片列表进入默认价后返回卡片列表。旧原型的相关导航转向此版入口。

卡片显示未保存修改标记，进入详情继续编辑时保留各源和各模型的草稿。卡片上的价格概况展示已保存、当前生效的规则。

原界面把账号路由、源默认策略、折叠的模型覆盖和手动添加模型混排，无法直接判断某模型实际使用哪个价格。模型源首先以独立卡片展示，卡片包含身份、服务地址、模型、默认定价概况及操作；点击卡片内「定价」才进入该源的定价页，返回回到卡片列表。定价详情内保留「模型与定价 / 连接 / 账号调度」三个上下文。手机定价详情是全屏二级页，只显示一个返回栏。

- 模型与定价页同时展示源默认规则和源内模型的当前生效单价。表格明确标注继承全局、继承源默认或单独定价，统一说明币种和每百万 Token 的单位。
- 源默认价是独立保存范围：保存源默认规则、倍率和时段，不连带保存未提交的模型覆盖。
- 单个模型通过右侧编辑器修改，手机为全屏二级页。保存只影响当前模型；恢复「使用源默认价」立即展示继承结果。返回或切页保留草稿，未保存的模型显示标记。
- 基础单价和当前最终单价分开显示；最终价计算源倍率与当前时段倍率。表中显示已保存、当前生效的结果，不把未保存草稿冒充已生效价格。
- 明确免费必须确认条件；普通 0 元单价不代表免费资格。套餐额度与货币费用分开呈现，未知价格不显示为零。无效单价显示行内提示并禁用保存。
- 添加模型通过独立选择器打开，目录选择为默认，手动 ID 输入为次级方式；保留已有模型与单价。账号路由单独保存，不再混在定价表单里。
- 全局默认价归入模型源，只展示兜底规则；返回恢复模型源上下文。全局未定价、模型无匹配、归档、确认免费、无效价格、未保存和保存成功均有实际交互状态。

## 用户故事

1. 我直接比较不同模型今天的请求量，点击 10:00 后查看各模型在该小时的数值，再进入对应审计查看分组统计与逐条记录并返回。
2. 我切为按源看 Token，再从近七天切换到其中一天的小时分布；更早日期明确提示归档。
3. 我修改源默认输入价但暂不保存，再编辑并保存另一个模型的专属价；模型保存不会偷偷提交源默认草稿。
4. 我看见模型继承全局价，可以查看全局规则，或改为单独定价；倍率改变后能看到当前实际乘算结果。
5. 我在手机选择免费策略，必须确认条件才能保存；输入数字时保存栏保持可达，返回只保留草稿，不误提交。

## 技术设计

- `assets/interaction-review.tsx`：独立的示例数据、分析状态、审计下钻、源默认与模型草稿、价格继承和保存边界。无产品配置写入，也不调用模型。
- `assets/interaction-copy.ts`：中文与英文文案，沿用项目 I18nProvider；固定样例品牌、模型 ID、日期和币种是示例内容。
- `assets/interaction-review.css`：项目设计令牌、鼠标限定 Hover、内部滚动、手机 44px 触控目标、小时横向滚动、全屏编辑与键盘避让。仅打开的编辑器占据侧栏宽度。
- `assets/build.mjs interaction-review`：生成可独立打开的单文件 HTML；不带参数仍构建原八页原型。旧原型支持 `?tab=`，便于跳转聚合、监控等已设计页面。

正式接入时复用 `ModelUsageWorkspace` 和既有图表渲染器，恢复分组序列；`WorkspaceUsage` 补齐按所选日期、配置时区和全部筛选条件计算的小时数据，保留归档判定。当前工作区响应中的小时数组未填充，不能只修改图形。

源定价接入 `SourcePricingSettings` 时，保存模型覆盖应从已保存的源规则合并当前模型，避免提交另一份未保存的源默认草稿。实际生效价格必须由后端返回命中规则和倍率。已有对外模型显式价格覆盖优先规则需要兼容并显示来源；此稿示例没有额外的对外模型覆盖，不在前端猜测真实账单。历史价格快照和多币种统计保持原口径。

证据：[桌面](evidence/interaction-review-desktop.json)、[手机](evidence/interaction-review-phone.json)。截图放在 `/tmp/roami-interaction-*.png`，不提交主线。

最新结构复验：概况无明细表，审计包含可折叠分组统计与请求列表；模型源为卡片入口，进入定价与返回卡片在桌面和真机均通过。

默认定价归属复验：桌面与真机确认侧栏无独立定价入口，模型源内默认价可进入和返回；桌面另验证从源继承区查看默认价后返回原源并保留草稿。
