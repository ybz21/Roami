# 概况分析与模型源定价交互接入

## 产品设计

按 [已确认的交互稿](interaction-review.md) 接入正式页面。大模型导航依次为模型源、聚合、概况、监控、审计、本机网关、语音输入，定价全部归入模型源。

模型源卡片内进入该源定价；详情全宽显示连接、模型与定价、账号调度。默认单价从模型源页进入，源内查看默认价后返回原源并保留草稿。旧定价地址继续进入模型源下的默认价页面。已有模型和对外名称覆盖价保留，通过显式展开查看，真实价格来源由网关返回。

概况仅展示全局今日额度、周期摘要、分组趋势和分布，不展示明细表。默认按模型、请求量、小时展示；可按源、智能体、总量以及 Token、各币种费用分析。图例聚焦组，柱形和时段选择器选择区间；进入审计携带区间与归属，返回保留概况选择。分组统计表和逐条记录在审计。

## 用户故事

1. 比较今天各模型请求量，选择某个小时并查看对应审计，返回后仍停在原来的分析位置。
2. 将统计切为按源看 Token，浏览最近一周中的某天；归档日期明确提示切回每日汇总。
3. 在源默认价里输入未保存修改，再保存一个模型的价格；模型保存不提交源默认草稿，反之也如此。
4. 从模型源卡片进入定价，查看继承和倍率后的真实生效价，单独保存账号调度；手机输入时仍能点击保存和返回。

## 技术设计

- `ModelHub`：七个导航项、全宽源详情、卡片定价入口和嵌套默认价入口，保留旧地址与连接创建、目录选择、导入和语音功能。
- `ModelUsageWorkspace`：概况和审计各自保留筛选状态，恢复分组图表序列，使用既有 ECharts 渲染器；手机小时图独立横向滚动，时段选择器提供键盘可用的等价入口。
- `model-usage-workspace-state`：传递所选小时日期和审计小时，复用可见性轮询与取消机制。
- `usage-workspace.go`：按账本配置时区和全部归属筛选生成小时组；审计的小时、状态和搜索条件同时作用于记录与分组统计。夏令时重复小时包含两次实际时段。每日归档不伪造成完整小时数据，今日额度维持全局口径。
- `SourcePricingSettings`：源默认规则、单模型规则、账号策略分开保存，后端事务只合并指定范围。未提交的其他草稿保留；免费需确认，无效单价禁用提交。手机编辑为全屏二级页，保存栏随软键盘避让。
- `source_pricing.go`：返回基础规则、命中来源、源与分时倍率、最终单价，以及既有对外名称覆盖价，沿用网关实际定价函数和价格快照语义。
- `useGatewaySettings`：默认价与限额分开保存和撤销，并保留另一上下文草稿。服务端原子合并，避免旧全局配置覆盖新保存的源策略。

不增加存储表、小时历史或监控保留量；用量明细沿用 48 小时归档，监控继续沿用滚动 24 小时与既有容量上限。

## 验收

桌面与 Redmi Note 8 使用隔离开发实例、真实 Go API 和已有合成账本，没有调用用户真实模型源。截图保留在 `/tmp/roami-redesign-*.png`，不提交主线。

- 前端全量：240 个文件，1,765 项测试通过。
- Go 网关回归覆盖时区与归属过滤、归档、夏令时重复小时、独立保存、价格来源与倍率；定向 race 检查通过。
- 全量质量门通过；首次出现未修改模块 `TestClaudeRejectionSettlesAndReusesOriginalProvider/cancelled` 的生命周期暂态失败，定向连续三次通过，随后完整质量门通过。
- 桌面四档宽度与真机证据见 [桌面](evidence/interaction-product-desktop.json)、[手机](evidence/interaction-product-phone.json)。

英文浅色版在四档桌面与 392 CSS px 下复验通过，手机导航采用短名称和自然宽度，超出部分由既有 Tabs 菜单承接，避免文字相互覆盖；中文真机完整操作复验通过。[语言与主题证据](evidence/interaction-product-locales.json)。

## 插件多账号与详情顺序

模型源详情顺序统一为「连接 → 模型与定价 → 账号调度」。插件源卡片提供「添加账号」，复用已安装的插件包创建新的独立实例，自动区分名称并进入新实例的连接页。普通 API 源不显示该操作。

新实例使用新的源 ID、进程和私有工作目录，不复制原实例的登录凭证、选项、模型选择或定价。已有包与提供方的导入入口同样可以重复创建。源内模型选择与聚合仍以源 ID 区分账号。

插件进程容量从 8 调整至 64，与现有模型源容量一致；沙箱、单进程资源限制与删除实例时的清理继续生效。登录区移入连接配置的内容滚动区，修正手机宽度越界，并避免登录输入框的 Enter 误提交外层连接表单。

验收：同一合成 WorkBuddy 插件包创建 10 个实例，分别登录，验证各实例选项、凭证与调用隔离；10 路并发、管理器重启恢复，以及退出一个账号不影响另一个均通过 race 集成测试。桌面四档宽度和 Redmi Note 8 实际触摸添加账号、独立登录、切换定价及返回通过，前端全量为 240 个文件 / 1,765 项测试。没有使用真实 WorkBuddy 账号或外部模型调用。

证据：[桌面多账号](evidence/plugin-accounts-desktop.json)、[手机多账号](evidence/plugin-accounts-phone.json)。
