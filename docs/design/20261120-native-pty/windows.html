Windows 整包移植

首发验 Windows 11 24H2+ x64：不只要接 ConPTY，还得先填平 7 个 Unix 系统调用编译卡点。

ConPTY：crosspty 与直接调系统 API 并行探针

  • crosspty v1.2.0 首选但有 3 个风险：Close() 直接杀进程；Job 句柄藏在内部；Wait() == -1 分不清“未退出”和“查退出码失败”（此时保留待确认和围栏）。
  • 直接调 ConPTY 并行对照：用现有 x/sys/windows 跑同套用例（暂停启动 → 绑 Job → 恢复运行），crosspty 过不了就直接切换。go-pty（需 Go 1.25）仅作参考。
  • 两个必踩坑：① ConPTY 内置虚拟终端，会发 ESC[6n 光标查询，服务端 VT 必须秒回，否则 PowerShell/PSReadLine 卡死；② 24H2 上 ClosePseudoConsole 立即返回，必须等管道 EOF + 进程退出码都齐了才算结束。只走公开 API（含 ReleasePseudoConsole）。

整包适配清单

卡点Windows 做法
文件锁（存储/围栏/注册/标签）Flock → LockFileEx（验共享/独占、非阻塞、崩后释放、大小写路径）。
磁盘与内存Statfs → GetDiskFreeSpaceExW；内存与进程树用 Job Object；压缩/暂停按不支持。
进程、目录与环境/proc → GetProcessTimes；目录用初始 cwd + OSC 7；环境走 CreateProcessW 不敲 export。
监控与手机模拟器Setsid/Setpgid/Kill 隔进 Unix 文件，Windows 禁用但不拦启动。
托管与 IPC支持按需拉起（DETACHED_PROCESS）或登录计划任务；go-winio 命名管道拒远端（或走 127.0.0.1:0 + 私有 Token）。
打包与升级试点发带校验和 ZIP，正式看签名 MSI；测空格路径、中文用户名、最小权限与回滚。

7 个包编译报错回执

PowerShell 与 Agent 启动

Shell：默认探测 PowerShell 7（pwsh.exe），5.1 验过后可选；缺失给安装提示不改用户配置。

Agent：原生 .exe 走 CreateProcessW；npm 装的 .cmd 批处理优先找原生/Node 入口，确需走 .cmd 时验证受信任路径并经转义过的 cmd.exe 启动。

放行条件

  1. PTY：真机 x64 跑通启动失败、输出阻塞、ESC[6n、Ctrl+C、收尾排空、Job 清理和双会话隔离（arm64 另验）。
  2. 交互：PowerShell 7/5.1（PSReadLine/中文/粘贴/缩放）与 Codex/Claude Code 全屏交互和清理正常。
  3. 整包：干净机器上安装、重连、重启 Web、升级宿主、回滚全通，异常不误放围栏。
