产品设计

一套 Roami 入口，在 macOS、Linux、Windows 上随时断开并接回正在跑的原生终端。

第一阶段范围

先上：单窗格常规会话（新建、列表、连接、断开、重连、抓屏、打字、关闭），沿用稳定会话 ID；Windows 默认开 PowerShell 7。

后补：多窗口、上下/左右分屏、受管任务。切换默认前，老 tmux 会话照常工作。

电脑和手机谁控制

  • 谁动手谁接管：点终端或敲首个键即接管并切到本机宽度；光打开看、切后台、翻历史不抢控制权。
  • 只看时不挤坏排版：同时仅一端控制。电脑控制时，手机只看保持正常字号、按电脑列宽渲染并左右滑（不撞边缘返回和选词）；点进去打字才切回手机宽度。
  • 断开释放，不设空闲踢出：控制方掉线后释放控制，尺寸保留到下次接管；迟到输入/缩放按代次丢弃，合并手机弹键盘和转屏抖动。

关键场景

Windows 开 PowerShell

按登录用户在项目目录启 PowerShell 7；缺 7 时给安装提示，装完原地重试。

手机接回电脑终端

关掉电脑网页程序不停；手机打开先收快照再接实时流，点按即按手机宽度重排；若离线期间已退出，显示退出结果和尾部输出。

重启 Web / 升级宿主

Web 重启不掉会话。宿主升级时新会话走新版、老会话留旧版，最多留 2 代旧宿主善后；超上限先暂停升级，由用户等结束或确认关掉/重开。连不上时标“待确认”，绝不盲目重开。
