Roami 终端架构

业务只认 SessionBackend，系统差异全压在底层 PTY 和本机通信。

代码分层（5 个包）
包职责
internal/application、session、revive上层统一走 SessionBackend；台账按宿主各自对账，休眠按重启批次汇总；session_homes 改用通用运行 ID 替代 tmux $N。
internal/sessionbackend第一层接口：创建（带 Env）、查询（活着/已退/待确认）、连上、抓屏、输入、停止；按 Session → Window → Pane 寻址，预留 LayoutBackend。
internal/tmuxruntime兼容实现，保留 tmux 精确目标和粘贴回车规则。
internal/sessionipc / sessionhost基于 yamux 多路复用；宿主管布局树、窗格、VT、日志和控制权；切换与防重用独立小库 session-host.db，不碰主库 meta.db。
internal/terminal第二层接口：必选核心（启动/读写/缩放/终止/等待/释放）+ 可选能力（进程查证/内存限额/暂停）。句柄与系统调用留在 pty_unix.go / pty_windows.go。

逐项迁移清单

多窗口和上下/左右分屏预留

三层模型 + LayoutBackend

模型固定为 Session → Window[] → LayoutNode（二叉树：叶子是 Pane，分叉记 horizontal/vertical 与 ratio）。首轮单窗格即“1 窗口 + 1 叶子”，以后加分屏底层 PTY 与流不动。

  • 预留接口：NewWindow / ListWindows / SelectWindow / CloseWindow，SplitPane(paneID, dir, ratio, spec)、ResizeSplit、FocusPane、ClosePane，配 layout_changed 事件。
  • 渲染分工：Web 端直接按布局树用 CSS 排多个 xterm.js；CLI 端先按窗口/窗格切换附着。

现有窗口命令

宿主托管、不停会话升级与防重创建

独立宿主 + session-host.db

roami-sessiond 支持三平台按需脱离父进程自动拉起（Setsid / DETACHED_PROCESS），systemd / LaunchAgent / 计划任务作为常驻增强；Web 重启不动它。

宿主登记、路由指针 (current_host, generation) 与创建回执存于独立冻结 schema 的 session-host.db，不与主库 meta.db 互相阻塞或冲突。切换与回滚均用单事务 CAS 并递增代次。

并发重试最多建一次

创建带 operation_id 和 expected_generation，与切换串行落受理记录后再开 PTY；过期请求回 STALE_GENERATION，调用方重查路由确认未受理才重试，结果不明时保留围栏先查证。

老宿主善后

最多留 2 代旧宿主，满了暂停升级；无活窗格和未结请求后标退役、退出、删端点，最多留 1 个旧版二进制备回滚。

三平台底层、本机通信与 CI 门禁

平台边界

  • Unix：creack/pty；Linux 用 cgroup//proc，macOS 用无 cgo 系统接口验进程与目录。
  • Windows：crosspty v1.2.0 并行对照 x/sys/windows 原生 ConPTY，详见Windows 移植。
  • IPC：单连接跑 hashicorp/yamux。Unix socket 放短路径私有目录（全路径 ≤ 90 字节，避 macOS 104 字节上限）验 UID；Windows 用 go-winio 命名管道验权限拒远端（或三端统一 127.0.0.1:0 + 私有 256-bit Token）。
  • CI 防腐烂：除薄平台文件外业务层零系统调用，CI 跑三平台交叉编译。
断线接回、VT 状态与连接协议

画面同步

宿主持续读 PTY 按序号写入有界缓冲：短断线续传，长断线发完整快照（含滚动历史和终端模式）。服务端 VT 先验 charmbracelet/x/vt v0.1.0（需 Go 1.24.2+），对照 xterm headless 测回放和 30 会话内存。服务端 VT 是 DA/DSR/OSC 查询的唯一回答方（尤其保证 Windows ConPTY 的 ESC[6n 即时应答），客户端屏蔽自动回传。

协议消息

消息作用
hello / attach校验版本与身份，决定续传或快照。
snapshot下发截止序号、列行尺寸、含历史屏幕快照与权威模式（备用屏/鼠标/SGR/DECCKM/光标）。
output / mode / resized / layout_changed / exited按序号渲染；二进制帧前 8 字节大端序号 + VT 数据；区分进程退出与输出读完；漏号重同步。
claim / input / move-cursor / resize日常低延迟交互（携控制代次，不逐键落回执）；move-cursor 按暗/灰样式避误吞建议。
submit受管任务专用：带 request_id、括号粘贴 + 独立回车并落回执，超时不重发。
resync / detach重拉快照或取消订阅，不杀进程。
迁移与回滚

三步走

  1. tmux 接进统一接口，改好分宿主对账与归属，过老回归。
  2. 隔离实例跑单窗格原生试点（快照、move-cursor、手机水平看屏、双版本升级）。
  3. 切默认和回滚只动新建，老会话照常连；确认进程真退才允许从台账重开。
