原生终端选型

用什么

Roami 用自己的 Go 宿主管会话。macOS/Linux 用 creack/pty v1.1.24。Windows 首选 crosspty v1.2.0，通过 ConPTY 启动 PowerShell 7。

Windows 真机若过不了输出收尾、退出确认或进程树清理，改用 x/sys/windows 直接接 ConPTY。

第一步怎么做

  1. 先给现有 tmux 接上统一会话接口。
  2. 做 Linux 单窗格，跑通断线重连和 Web 重启，再验 macOS。Windows 并行验证 PowerShell 7。
  3. 先切新会话，已运行的会话继续走原后端。

Windows 为什么要单独适配

Windows 适配放在哪一层

creack/pty 的 Unix 接口交给调用方一个双向 *os.File，子进程由 exec.Cmd 启动和等待。Windows 版本的 StartWithSize 目前返回 ErrUnsupported。ConPTY 需要分别管理输入管道、输出管道、控制台句柄及进程句柄，启动时还要将控制台作为属性传给 CreateProcessW。

在 Roami 内定义终端契约，让适配层包装系统 API 或通过验证的库。分离附着连接、进程停止与 PTY 资源释放，终端协议与会话宿主跨平台复用。直接扩展 creack/pty 原签名仍需解决双管道封装和 exec.Cmd 的等待兼容。
