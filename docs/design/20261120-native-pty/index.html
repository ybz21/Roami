原生终端选型

选什么

会话交给 Roami 自有独立 Go 宿主 roami-sessiond。macOS / Linux 用现有 creack/pty v1.1.24；Windows 首选 crosspty v1.2.0（ConPTY + PowerShell 7），真机探针并行用现有 x/sys/windows 直接调 ConPTY 对照，不达标直接切原生。

看架构图 · 看方案对比

先干什么

  1. 抽出 SessionBackend 接上现有 tmux，收口台账、归属和直调旁路。
  2. Linux 跑通单窗格（重连 + Web 重启），再验 macOS；Windows 并行验 PowerShell 7。
  3. 新会话切默认，老 tmux 会话照常连。

三平台支持范围与为什么不改 creack/pty

平台范围

为什么不扩展 creack/pty

Unix PTY 只有一个 *os.File；Windows ConPTY 是双管道 + 控制台句柄 + 进程句柄，creack/pty 在 Windows 直接报错不支持。在 Roami 内部定 TerminalBackend 接口各自实现更干净。
