# 实施与验收

首页桌面和手机的三点菜单增加「执行调试」。手机使用 URL 二级页面，一根返回栏、一个滚动区；链路列表与详情独立返回。三个页签是链路、队列、上下文，「怎么看」默认折叠。无常驻刷新按钮。

## 已实施

- 请求列表按 15 分钟 / 1 小时 / 24 小时分页；活动轮次和后台任务独立分页，不受历史范围影响。activeTotal 独立于当前队列页，旧活动项不因翻页丢失轮询。
- 新增 owner/conversation/branch 范围的只读 debug / debug/trace 接口，复用原始因果链与 Chrome Trace 导出。Go 转发接口沿用登录鉴权，不暴露本地回调。
- manifest 保存当次上下文容量、输入估算、epoch 与执行限制；历史缺失数据保持未知，当前上下文另列。字段白名单不包含 prompt、工具参数或凭据。
- 浏览器待发队列用只读元数据订阅，不重挂发送器，不包含草稿正文或附件名称；真实发送中状态来自现有发送器，旧存储中的 sending 保持未确认。
- 首屏最多挂载 200 个跨度，按需继续加载，节点详情展开才创建 DOM。可见活动页面按需轮询，关闭后停止；共享缓存中已经发出的只读请求允许完成。
- 查询跨度超限会说明调试查询受限，不影响任务运行；专业执行器内部与未采集的时间保持未知。并行阶段耗时不可直接相加。

## 验收证据与边界

- 全量质量门禁通过：Go、Python 677 项、Ruff、前端类型/i18n/hover/构建及提交策略。前端全量 113 文件 / 797 项通过。
- 新增服务端用例验证只读、跨 owner / conversation / branch 拒绝、遗忘文本不返回、旧队列不受时间窗限制、跨页活动计数及历史 manifest 缺失保持未知；读取中切换模型时，容量和模型名来自同一次配置。
- 前端验证服务不可用时的反馈、单发送器、发送途中离开页面、迟到回执作用域、存储中未确认发送、URL 返回及大链路初始 DOM 上界。
- 桌面 Chrome 与真实 Redmi Note 8 触控验证菜单入口、请求、链路、当前/当次上下文、队列、两级返回及关闭后零轮询。补查桌面长链路时发现底栏高度变量缺省使容器高达2323px（视口900px），补0回退后内容容器839px且可实际滚动到底；document 无滚动、无横向溢出；手机 compact/coarse，桌面 large/fine。
- 浏览器验收使用实际组件与隔离 Runtime 生成的真实结构数据，经 HTTPS 夹具提供；不冒充生产 Go/Python/浏览器整链路或真实专业执行器内部验收。Go 转发鉴权与 Python 归属校验另由自动测试覆盖。
- 桌面实际下载并解析 29 个 Chrome Trace 事件，检查原始请求正文未导出；不声称手机系统下载落盘已验证。
