# 右栏工具栏、拖拽与场景点击

关联 #721。用户要直接切换协作与任务、拖动右栏宽度，并点击里面的成员和任务；顶部重复的主智能体按钮移除。

## 产品设计与用户故事

右栏打开时，协作 / 任务在右栏左侧，更多与收起在右侧。聊天头不再重复放工作区与更多。
关闭后仅在聊天头显示工作区展开入口，完整释放原宽度，保留当前聊天、草稿与任务筛选。
已有团队的项目直接使用团队页 Main；尚未绑定团队的初始化讨论仍保留必要入口。

分隔条沿用全局细线样式，可拖拽及键盘调整。拖动时只显示引导线，松开再提交宽度，
避免原生终端/对话在每次 pointermove 时反复重排。宽度按节点与团队保存为比例，首帧读取
本地选择；窗口改变时重新约束两边可用宽度，收起时不留空列。

协作场景的成员名与机器人进入同一原成员聊天；任务行打开详情。场景尚未完成定位时
暂不展示叠在原点的标签；鼠标经过可点机器人显示指针，取消或拖动不误触选择。

## 技术设计

- `ManagedSwarm` 将右栏页签及动作收拢到 `swarm-workbench-head`，折叠入口按开合状态呈现。
- `SwarmWorkspaceDivider` 复用 `usePointerResize` 和输入遮罩，松开提交一次；宽度 hook 使用
  `ResizeObserver` 读取实际容器/目录/分隔条，保存比例且不增加轮询。
- `SwarmStudio` 等待 renderer 更新并定位后才开放标签；scene 的命中路径清除取消指针并核对
  同一 pointer。标签、机器人继续调用原 `selectMember`，不新建会话或替换执行器聊天。
- `ProjectOkr` 对已绑定团队隐藏顶部重复 Main 按钮，原消息引用和初始化讨论保持原能力。

不更改 Main / 成员 / task / provider 身份、任务状态或数据来源。所有文案复用已有 i18n，
组件复用全局令牌；手机工作区仍是二级页，不把桌面拖拽栏放入手机。
