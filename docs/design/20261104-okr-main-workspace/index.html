一个 OKR，一个固定负责人

目标讨论、任务分工、群聊和记忆围绕同一个持久实例继续，不因收起页面而换人。

用户如何继续

  1. 进入 OKR 的主智能体对话，自动恢复已有负责人和历史；两个窗口同时打开仍使用同一个身份。
  2. 负责人使用已关联团队创建任务、分派成员、处理依赖并核验产物；目标讨论与团队群聊共用 Main。
  3. 收起页面保留实例和草稿；停止当前执行使用明确的停止动作。
  4. 文件入口按目标配置、团队、记忆、数据连接、日期产物与历史分类。历史素材集中归档，旧 artifacts 链接保持可用。

身份与实现

范围唯一身份与约束
项目 OKR当前一个已注册项目对应一个 OKR；本轮不引入同项目多个目标目录。
主智能体project_okr_mains 以 owner/project 唯一绑定 conversation；并发创建在同一写事务中归并。
已有团队复用专用 Main，不迁改原 task/revision/run 和回执；首页 Main、跨项目共享实例或错误归属拒绝绑定。
前端OkrMainChat 恢复持久实例，OkrProjectFiles 提供真实目录入口；旧运行时仅可复用核验后的已有专用团队 Main。
历史项目 archive/legacy-20261104/ 保存原文件，manifest 记录原路径、现路径、字节、SHA256、权限与修改时间。

验证边界

会话关闭不代表任务验收；发布成功不代替宿主验证。新持久索引需要正式升级运行时，生产旧 busy、模型路由与账目不能绕过。桌面、真实手机与完整门禁的结果以 README 中最终记录为准。
