# 任务结果文件提示

## Product Design

文件暂不可用时只显示一条简短提示和“查看详情”。用户主动展开后查看完整原路径；保留可访问名称、键盘操作与粗指针命中区，不让长历史路径占据整个任务面板。

## User Stories

- 用户先看到任务结果和状态，需要定位旧文件时再打开路径详情。
- 切换任务后恢复收起状态，不把上一任务的选择带到下一任务。
- 渲染对话与原生会话使用相同提示，空列表不显示警告。

## Technical Design

`TaskOutputWarning` 统一 `AgentTasks` 与 `NativeSessionArtifacts` 的不可用文件提示；按 task.id 挂载，内部保存展开状态，useId 连接 aria-controls 与列表。路径仍完整保留，使用 code/overflow-wrap 在详情内换行；按钮使用现有 SVG 图标、i18n、尺寸与触控令牌。

## 验收范围

隔离组件通过真实 roami chrome 点击展开、Enter 收起、换任务重置、空列表、中英切换与粗指针外围命中核验，使用合成路径，不访问生产 API。1280×800 与 390×844 截图已目视核对；390 档只是桌面视口模拟，不是真机。源码候选 typecheck/i18n/hover、216 套 1579 项 Vitest 与生产 build 通过。
