# 跨布局保留当前对话

关联 #770。沿用现有[Main 优先入口设计](main-first-conversations.md)及运行态原型，不新增按钮或设置。

## 产品与用户故事

群聊、Main 和原成员的选择在窗口缩放、横竖布局重建后保持。用户明确点 Main 或打开 Main 消息引用时，再切到该项目原 Main。成员暂时不可用时显示原阻塞，不自动替换收件人。每个对话沿用自己的草稿，缩放不会产生消息、任务或新实例。

## 技术设计

`ManagedSwarm` 的 recipient 当前只存组件状态；响应式壳重建会重新默认 Main。以现有节点路由前缀和 Swarm ID 为键，在本地同步保存选择，初次渲染直接读取。相同节点的其他 Swarm、其他节点的同名团队不共享选择。沿用当前成员的身份和发送前准入。

显式 Main 入口使用唯一请求标识代替每次挂载重新从零计数的数字；当前页面记住已处理标识，组件重建时不会重复覆盖之后的群聊/成员选择。真正的新 Main 请求仍在首帧生效。用户切到群聊或成员时清除旧 Main 消息引用，防止页面重建再次夺回焦点。持久化只保存界面选择，不保存消息正文或授予执行权限。

## 验收

覆盖 Main/群聊/成员的重挂载、不同 Main 请求、节点与 Swarm 隔离、损坏或不可写的本地存储、各自草稿保留及显式 Main 引用。真实自有桌面页验证 medium/large 往返与四档宽屏；禁止触手机的边界保持，紧凑模拟单独记录，不计真机触控通过。发送仍以原服务的 fresh task/revision/run 校验为准。
