# 右侧任务列表

## Product Design

团队页保留左侧 Main、群聊和成员，中间始终显示当前对话。移除顶部“对话与协作 / 任务”两个页面入口，将“协作 / 任务”置于同一个右侧工作区。协作保留真实成员场景，任务以平面单列显示主题、成员、真实状态，不使用五列看板。关闭工作区立即把宽度还给对话。

点击任务在右栏查看产物、状态、验收与原任务入口，不切换正在聊的人，不重建聊天，不发送消息。当前职责任务默认可见，历史任务通过现有“更多”筛选。实现细节和完整指令收在详情中。

手机从相同工作区按钮打开全屏二级页，顶部切换协作与任务；点击任务打开单独详情，返回列表再返回原聊天。每页只有一个返回栏，列表或详情独占滚动。

## User Stories

- 我和 Main 聊天时，切换右栏任务查看交付，草稿与会话保持。
- 我和某个成员单聊时，查看另一人的任务不改变当前收件人。
- 我在群聊里点具体任务，右栏直达该任务详情；回复成员仍需显式选中成员。
- 手机查看任务后返回，继续原对话；Enter 保留换行，不误发。

## Technical Design

- `ManagedSwarm` 继续使用同一 `useSwarmSnapshot` 订阅，不增加逐任务轮询。
- 原 `tab` 仅决定右栏协作/任务，主对话节点始终渲染；沿用原任务身份、原生会话入口与最新 revision/run 复核。
- 原本的打开/关闭偏好沿用，原 board 偏好迁移为右栏任务；桌面关闭释放 grid 列。
- `SwarmStudio` 在右栏隐藏重复标题，仅显示动画控制；离开协作时卸载场景并释放场景状态读取。
- 列表只读复用宿主 work 状态和当前职责映射，产物及外部验收继续沿用既有详情；不生成假完成状态。
- 手机用 `MobileSubPage`，不引入新路由；目录、工作区与详情保持明确返回关系。
