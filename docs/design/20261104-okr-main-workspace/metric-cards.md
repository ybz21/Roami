# 每个指标一张趋势卡片

关联 #656，补充 2026-11-05 用户截图反馈。

## 产品设计

数据看板同时展示所有已配置指标，每个指标独立成卡，取消共用下拉切换。卡片以指标名称为标题，显示自己的数值、单位、日期、趋势与可展开的逐日数据。只有一个指标时占满可用宽度；宽屏按可用空间并排，手机纵向排列。没有观测的数据仍显示缺测提示，不绘成零值；空的关键结果分组不占位。

## 用户故事

- 同时看到 star、fork 等指标，不用记住上一次下拉切换前的曲线。
- 收起 Main 对话后，图表立即使用释放的空间，不保留空列。
- 在手机上顺序滚动每张卡片，名称、单位和数据不会混到另一指标。

## 技术设计

`OkrDashboard` 继续读取既有 widget 配置及 `metricIds`，将每个 metricTrend widget 拆成独立指标的 `OkrTrend`。单指标的配置标题继续有效；多指标使用各自名称。缺失指标不生成虚构卡片。`OkrTrend` 只接收一个指标，删除选择器及其本地选择状态，继续复用真实来源筛选、逐日聚合、ECharts 和图表释放逻辑。

趋势卡片使用独立的 `.okr-trend-grid`，避免关键结果的跨列元素使 auto-fit 保留空列。列宽由可用画布和既有 spacing token 计算，单卡和 Main 面板开关自然重新分配宽度。没有新增数据接口、写入、录入表单、配置页或轮询。
