# 会话标签行尾间距

## 产品设计

截图中的文件下拉和关闭按钮分散，标题与动作之间叠加了内边距和标签 gap。
沿用现有矩形标签和中性选中态，把鼠标端的行尾动作收紧为一组，保留标题阅读空间。

## 用户故事

- 桌面用户能在长会话名旁快速找到文件菜单和关闭按钮。
- 键盘用户仍可打开文件菜单，并按 Escape 返回触发按钮。
- 手机用户保留现有布局和触控热区。

## 技术设计

仅修改 `frontend/src/components/terminal/session-resources.css`：
用 `html[data-pointer="fine"]` 限定鼠标端；标签 gap 归零，尾部及标题右侧内边距
使用 `--sp-1`，两枚动作按钮使用 `--sp-4 + --sp-1`（20px），箭头与关闭图标统一为
`--sp-3`（12px）。不改变 React 结构、资源菜单状态或触屏规则。

## 验收

  标题按钮宽度从 155px 增至 175px，同时右侧留白减少 4px，净增加 24px 文字空间。
