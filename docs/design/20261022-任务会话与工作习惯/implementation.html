原任务可以继续，会话由用户结束。

本页描述实际实现；原交互稿仍使用示例数据。功能尚未部署，需通过实现 PR 合入上线。

三个入口与工作环境

  • 首页右侧任务栏和任务详情都有“进入会话”与项目链接。任务列表仍按时间显示；新增“会话未关闭”筛选，筛选、选中项、列表位置与草稿保留。
  • 专业 Agent 进入原终端；native 在桌面 Main 右侧打开，手机是单返回栏的全屏页。项目页补齐 native 入口，手机项目稳定 ID 深链也能打开对应项目。
  • 继续修改复用原 task、executor、native branch / 专业会话及 workspace。native 输入走原任务修订接口，通用 Main 消息接口不能绕过控制。关闭前检查修订、待处理修改、工具、子任务和资源；关闭仅由显式用户操作触发。
  • 新项目任务调用既有 Go 工作区服务：Git 项目开 worktree，非 Git 项目使用实际目录。routing.workspacePreference 引用有效记忆的 memoryId、revision、原文 quote；校验用户、项目、对话、任务范围和可选 base/remote 引文。当前任务参数优先，已绑定工作区不能套用新习惯。决策保留采用的记忆修订与解析回执。

每个子任务有自己的平级目录，不嵌套或复制父对话。parentNativeSessionId 关联 native 父会话；Main 没有 native ID，通过 parentConversationId、parentTaskId 和 rootConversationId 关联。附件沿用现有 ArtifactStore；上下文摘要继续由现有 context_snapshots 管理，日志记录 checkpoint。没有另外创建第二套 context/blobs 存储。

目录 0700，文件 0600；不采用 Agent 自报路径或手改元信息授权。既有 native 仅在任务能够证明唯一原分支时回填；历史回填标记来源，不编造历史调用起点。

一致性、压缩与数据库体积

  1. SQLite schema 12 在消息、调用、任务及关闭变更的同一事务中登记 seq、eventId 和 outbox。投影器非阻塞获取文件锁，写完整 JSONL、fsync 后清空 outbox 正文并推进水位。重试校验 eventId 与摘要；半行从待写事件补齐，中间损坏报错。
  2. 活动日志约 32 MiB、存在超过一天的未封存事件，或用户已关闭时，生成确定性 gzip 分段。校验压缩文件、原始字节、逐事件摘要和序列后登记清单，再裁去活动文件中的已归档前缀。水位未推进时可幂等重试。
  3. 七天以前的原文只在无 queued/running turn 时考虑冷存，保留最近两轮；仅当前正文与归档公开内容完全一致时替换为带 HMAC 的引用。脱敏改变过的正文留在原数据库，不用不完整日志替换。消息历史、上下文、来源校验和工具参数读取统一还原原文；缺失或损坏明确报错。
  4. 冷读按不可变分段建立消息索引，缓存最多 64 MiB；超过预算的分段不常驻。压缩与文件 I/O 放在线程中；不把整个会话重新填入模型窗口。上下文压缩和磁盘归档是两个机制。
  5. Go 备份格式 3 同时校验 SQLite、已登记 native 文件和既有附件；恢复通过持久 journal 分阶段发布，可重复校验。托管写入持有平台维护锁，离线备份不会与写入并行。

保留全部历史，空间仍会增长。归档减少正文重复与日志体积，不承诺固定磁盘上限。主事件流、索引和调度元数据仍保留；SQLite 已释放页面可复用，本实现不在交互期间运行 VACUUM。用户关闭会话不会删文件或历史。现有遗忘、权限和上下文排除继续生效；公开日志不是物理擦除工具。

实测内容

测试结果与边界
“补上负责人”原 native 任务增加一轮，未新增任务；原会话和 worktree 不变。
“补上截止时间”同一会话再续一轮，workspaceId 保持。
“把行动项按优先级排序”第三次续改仍沿用原身份；随后取消关闭、确认关闭、只读历史正常。
Android：“把步骤写清楚”真实触控进入、追加、返回筛选正常；系统键盘 314px，输入区避让。项目深链进入 native、返回同项目，只有一个返回栏，无横向溢出。
结束后观察请求桌面持续观察 6.5 秒，未出现该结束任务或 native 会话的新轮询。
故障与权限事务回滚、落盘后未确认重试、半行恢复、磁盘写失败保留待写、gzip 损坏、冷读重启、缺失文件、跨用户读取、分页、独立子目录、原会话续改与显式关闭。
备份恢复包含活动日志和归档段，校验缺失、篡改、符号链接与重复恢复；不将不完整包标为成功。

浏览器验收使用固定测试模型，检验真实 API、调度、Git worktree 与界面链路；不等于线上大模型的自然语言语义评测。未更改现用模型配置。截图在 PR 的 pr-shots 分支，仓库不保存一次性图片。开发设计文档使用中文，属于 i18n 例外。
