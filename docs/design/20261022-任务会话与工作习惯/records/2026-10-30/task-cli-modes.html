任务提示词与 Agent 自动模式

2026-10-30 · 分支 fix/task-agent-cli-modes

产品设计与用户故事

从项目、会话或文件入口启动专业 Agent 时，默认采用该 Agent 的自动权限模式。 任务提示词优先指引使用 Roami CLI；升级后的用户也应获得新的内置能力说明。 用户编辑过的说明、启动路径、模型参数和明确的权限设置保持有效。

技术设计

frontend/src/agent-command.ts 的统一启动函数补充自动参数，覆盖 TaskComposer、NewSessionModal 和 FilesPage；Pi 不添加不存在的 YOLO 参数。 自定义命令已经包含明确权限参数时沿用原值。

backend/api/agent_capabilities.go 在读取能力说明时，对 #317、#328、#399、#403 发布的完整默认内容计算 SHA-256，只升级匹配的旧默认模板。 升级使用同目录临时文件和 rename，权限保持 0600。自定义内容不覆盖。 历史模板保存在 testdata，验证升级、重复读取和自定义说明保护。

backend/api/prompts/agent-capabilities.md 明确 Roami CLI 优先、派生 shell 后各 Agent 的自动启动参数，并保留 Git、依赖安装和项目测试的原有约定。
