# Agent 产品原型 · v2

入口：[可交互原型](product.html) · [框架设计报告](index.html)。本页是开发评审稿，原型中的消息、项目、任务与结果均为本地示例，没有真实模型调用、文件上传或消息外发。

## 主界面

首页承载 Main Agent 主对话，输入框始终可见。简单问题直接流式回答；需要执行时先给简短接收回执，再展示紧凑任务卡。原型延续 Roami 的颜色、字号、间距与 SVG 图标体系。

桌面左侧保留项目、散会话和最近入口；中间用于聊天；右侧只看后台进度，结果仍回到原对话。手机保留首页、项目、工具、设置四项底部导航；后台任务通过顶部入口展开。项目、工具等页面不在正文重复路由标题。

## 交互

- **快问快答**：输入问题或点“今天做了什么”，直接在主对话回复；后台有任务时仍能提问。
- **选择去向**：输入框默认自动选择，可指定已有项目、已有散会话、新散会话、新项目或直接回答。
- **新建项目**：填写名称与目标后立即返回“已安排”；后台准备项目和会话，完成后给出结果与项目入口。
- **任务跟进**：点击消息卡或后台任务，查看去向、执行 Agent、阶段和回报位置，追加要求或取消任务。
- **完成回报**：任务结果由 Main 在原对话简要说明，附结果入口。用户正在看项目等页面时保持当前页面，不自动跳回首页。
- **离线补收**：演示控制可模拟离线、完成任务和恢复连接；结果先保存，恢复后回报。
- **记忆查看**：每日、任务、对话、项目和偏好分组浏览；记录展示来源，散会话不强制归项目。
- **项目与散会话**：可以查看示例详情，再回到主对话选定目标继续交代事情。

顶栏“演示回报”与“重置”只用于评审，不属于正式产品主流程。自由输入只触发本地示例逻辑，不是已接入模型的回答。

## 评审边界

原型是 `docs/design` 下的中文开发评审文档，未改生产前端，也未新增私有产品翻译层。正式接入时，界面文案须进入 `frontend/src/i18n/` 的中英语言包；现有对话示例作为内容保留。

自适应直接复用 `frontend/src/layout.ts` 的 `getLayout()`，静态构建后内嵌；图标从 `frontend/src/icons.tsx` 渲染后内嵌，未另画一套图标。HTML 无外部脚本、字体或依赖请求，可离线打开。

交互检查涵盖普通问答、已有 / 新散会话、新项目准备与完成、结果入口、取消、五类记忆、离线补收和输入转义；布局覆盖 320–2560px 的九个宽度。粗指针模拟检查触控目标、弹层与四项导航。Android 真机当前锁屏，真实触控和键盘验收尚未完成；不能据此认定移动端生产验收完成。

后续实现需补真实流式断线续传、任务状态、CLI 回执、记忆编辑与删除、通知以及真实附件处理。原型不构成这些能力已实现的证明。

## 手动压缩 · 产品 v2

- 输入 `/` 或 `/comp` 出现 `/compact` 提示，点击或 Tab 补全；输入完整命令后 Enter / 发送执行。可附关注项，例如 `/compact 保留部署决策`。
- 输入框下方提供紧凑的上下文入口，可主动压缩、查看状态和只读摘要。只作用于当前主对话，不受派活去向选择影响。
- 正在回复时先显示等待；完成轮次后运行压缩，工具调用与结果不拆开。用户可以继续输入，后台任务继续工作。
- 以独立控制记录展示排队、处理中、已压缩、无需压缩或取消，不假装是普通 AI 回复。完整聊天记录保留；支持查看摘要与取消尚未完成的压缩。
- 原型的 18k / 24k、压缩后 7k 与摘要均是明确标注的演示值，未读取真实模型上下文。真实产品需提供估算口径、失败重试、断线恢复与自动触发路径。
- `/compact` 是主 Agent 的控制命令，执行器内的同名命令由 Claude Code / Codex 自行管理，不能跨运行时假装已同步压缩。

技术协议见 [上下文压缩](technical/04-context-cache.html) 与 [消息接口](technical/07-transport.html)。修改前产品文件保存在 revisions/before-manual-compact/。

## 斜线命令 · 首批范围

| 命令 | 行为 | 范围 |
|---|---|---|
| `/compact [关注项]` | 压缩、排队与摘要查看 | 当前主对话 / 分支 |
| `/status` | 查看连接、Main、上下文与后台任务概况 | 只读，不调用模型 |
| `/tasks` | 打开后台任务面板，进入详情跟进 | 当前用户可见任务 |
| `/memory` | 打开五类记忆视图 | 用户已有访问范围 |
| `/stop` | 停止当前 Main 生成，保留部分回答 | 不取消后台任务或压缩操作 |
| `/help` | 查看命令说明，点选补全 | 本地帮助 |

输入 `/` 展示列表，输入前缀筛选；建议区最多占三行点击高度，其余内部滚动。点击或 Tab 补全后由用户显式发送，不直接触发操作。未知命令、非预期参数明确报错；多行内容与引用中的 `/compact` 按普通消息处理。除 compact 外，首批命令不接受参数。允许流式回复期间执行查询或 `/stop`，不用先停止回复再查状态；离线可看缓存帮助与状态，写操作不伪报已接收。

首批不提供 `/clear`、`/reset`、`/cancel all` 等破坏性含混命令。`/new` 涉及多对话切换与原始任务回报定位，留到多对话产品一起实施；`/model` 则随真实模型配置与能力探测提供。当前原型没有承诺这些命令已可用。
