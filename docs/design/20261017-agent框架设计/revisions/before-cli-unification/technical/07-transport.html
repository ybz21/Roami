接口与返回语义

接口用途持久化边界
POST /v1/conversations/{id}/messagesrequestKey + text + targetHint?202 表示用户消息与待执行 turn 已 COMMIT
GET /v1/conversations/{id}/messages?afterSeq=...历史分页 / 首次快照返回 branch、messages、snapshotCursor

POST /v1/tasks/{id}/steer追加要求与 revision更新要求、入 job，旧结果不能盖新版本
POST /v1/turns/{id}/interrupt仅停止当前回答部分回复保留 interrupted
POST /v1/tasks/{id}/cancel取消任务与子树先 cancelling，确认停止后终态
GET /v1/memories/search查询记忆与来源默认 active，按 ScopeFilter；不公开任意 SQL

公开地址映射为 /api/agent/*，Go 统一鉴权后转到 Python /v1/*。消息请求不等待模型结束，UI 随后订阅事件；输入确认与用户得到有效答案分别统计。

# 主要事件类型
message.accepted / message.started / message.delta / message.completed
turn.interrupted / task.accepted / task.started / task.updated
 task.completed / task.failed / reply.queued / reply.completed

事件先提交后通知；SSE 查询以数据库游标为事实，内存通知只负责唤醒。先建立订阅、记录水位、补读 DB，再继续追读，不能在“读历史与开始监听”之间漏一段事件。UI 按 eventId 去重，messageId + offset 合并文字。

  • 每个连接缓冲有上限，慢客户端断开后从 lastEventId 重放，不让它反压 Main 推理或 DB writer。
  • 事件归档导致游标早于保留窗口时，返回需重取快照的机器码；UI 先同步 messages + task state，再接新事件。
  • 撤销原有 Go 登录或连接过期后，使用现有连接失效策略；重连再次经过 Go 鉴权，不绕开统一入口。
  • 浏览器关掉只取消该订阅；任务取消必须显式调用取消接口。

FastAPI · StreamingResponse

Go 复用现有鉴权 middleware；创建 httputil.ReverseProxy，使用 Rewrite 映射固定内部目标、清理客户端伪造的身份头，再写入可信 owner。请求体 / SSE 字节透明转发，不在 Go 做事件协议转换。

proxy := &httputil.ReverseProxy{
    Rewrite: func(r *httputil.ProxyRequest) {
        r.SetURL(agentServiceURL)
        r.Out.Header.Del("X-Roami-Owner")
        r.Out.Header.Set("X-Roami-Owner", ownerFromVerifiedContext(r.In))
        // 路径只映射公开 /v1/，私有 CLI Socket 不暴露
    },
    FlushInterval: -1,
}

FlushInterval 可控制转发刷新；还要检查外层 gzip / 缓冲中间件、服务器 WriteTimeout、反向代理空闲超时。SSE 连接使用独立的流超时策略，不能套普通短请求 deadline。

统一 ReplyService 与 CLI

1. 接收回报

本机 CLI report → run / revision 校验与结果落库。

2. 生成回复

Main mailbox 验证当前要求，再生成简短回答与 artifact 引用。

3. 保存与排投递

assistant message、完成事件、delivery 同事务提交。

4. 发到原来源

Web SSE；IM channel adapter；离线保留，失败重试。

CLI 是外部 Agent 的入口；Python Main 直接调用 ReplyService，省去子进程。reply 指令使用同一个服务，不绕过消息存储或投递去重。来源 route 来自 channel_bindings，Worker 无权任意填写外部收件人。

IM 平台若不支持幂等 message key，网络超时可能存在已送达但回执未知的情况；记录 delivery=unknown 并对账，不能盲目重发后承诺绝不重复。Web 以持久 eventId / messageId 去重。
