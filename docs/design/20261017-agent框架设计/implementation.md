## 已实现

Python 拥有持久化对话、分支 / checkpoint Fork、模型循环、流式事件、原对话任务回报、记忆 / 来源 / 版本 / FTS、手动和自动压缩，以及 compact/status/tasks/memory/stop/help 六个命令。Main 与 Worker 分配独立容量；委派有深度 / 并发限制、共享祖先步骤预算与继承的截止时间。

Go 负责统一 CLI、数据库路径 / catalog / 维护锁及既有鉴权后的 HTTP/SSE 透明代理；Python 只监听私有 Unix Socket。内部 report/notify 回调不公开挂载，没有新增第二套鉴权。

Codex / Claude Code 执行复用 Go Agent 参数注册表与应用层会话服务。在 tmux 新会话执行一次性任务，保存启动凭据、会话绑定、退出码和有界输出。Python 释放长期 Worker 占用，由独立监视器收取结果；重启后观察原凭据、不重发。取消保持处理中，直至 runner 返回终态；观察失败不会被当成已经停止。

项目目标通过稳定 projectId 解析，复用现有 Go 项目台账与工作区服务。Git 项目拉取成功后，从固定远端提交创建独立工作区，本地 main 不移动；目录项目保留项目身份。准备操作计入原任务截止时间，最多持续 120 秒。失败不启动编码 Agent，相同 launch key 不再创建工作区；工作区凭据、分支、基线与 startOid 可追溯。Python 在实际启动前展示 preparing，并持久化解析后的目标和准备事件。

## 实际验证

测试覆盖 Go CLI→catalog 登记→Python 私有 Socket→本地 HTTP 模型→持久化回复 / 历史 / 主动消息，以及维护互斥、编码任务取消、Python 重启后继续观察、原对话回报和未知结果不重放。

项目路径使用真实 Go CLI、临时 Git 远端和隔离 tmux 验证：远端领先时使用最新提交、执行发生在新工作区、重试复用同一工作区、失败拉取不创建旧工作区也不启动编码进程。另验证目录项目和未知项目不回退、Python 只传项目身份、工作区绑定不可悄悄变更、子任务截止时间不晚于父任务。

模型和编码可执行文件使用测试替身；没有调用真实模型账号，也没有宣称真实模型延迟、成本或缓存命中已验收。32 项 Python 测试及本地快速质量门禁已通过。补充 Git hook 环境隔离回归：测试夹具不会继承调用方 Git 绑定，工作区操作和编码进程清理跨仓库绑定但保留 Git 认证环境；临时调用方仓库配置保持不变。项目执行测试还放置了必定失败的旧 ttmux 入口，确认新路径只使用统一 roami 和底层 tmux。
