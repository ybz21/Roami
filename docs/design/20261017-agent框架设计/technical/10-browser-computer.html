Browser Use 与 Computer Use 的具体执行

两种能力复用同一个 Agent Loop，差别集中在观察数据与动作驱动。它们运行在 Worker 中，主对话只接短进度与结果。

观察、动作、验证

1. Observe

获取 DOM / 可访问性树或屏幕；生成 observationId 与场景版本。

2. Decide

模型结合任务目标选择一个有界动作，携带所依据的观察 ID。

3. Act

校验资源租约、场景版本和范围，驱动一次操作。

4. Verify

重新观察；检查预期页面、文件或状态，再决定下一步。

Observation = { id, resourceId, sceneEpoch, capturedMs,
  url?, title?, domText?, accessibilityRef?, screenshotRef?,
  screenSize?, viewportSize?, deviceScale?, focusedWindow? }
Action = { observationId, expectedSceneEpoch, kind,
  locator? | normalizedPoint?, text?, key?, scroll?, expectedChange? }
ActionResult = { state, beforeRef, afterRef, changed, evidenceRefs, errorCode? }
不能仅凭动作 API 返回成功就认定目标已完成。验证依据可以是页面状态、下载文件的实际内容、截图或软件输出。

Browser Driver

优先复用已核对的 chrome CLI：tabs / new、text / html、click / fill、eval、screenshot 和 record。通过任务独立 tab 绑定执行，按 tab 标识选择目标；需要更结构化观察时，再用 CDP 适配 DOM / Accessibility 与截图。

# 已有命令示意；Python 使用 argv 调用
roami chrome new <url>
roami chrome --tab <index> text <selector>
roami chrome --tab <index> click <selector>
roami chrome --tab <index> fill <selector> '<text>'
roami chrome --tab <index> screenshot <artifact-path>

索引可能随 tab 新建 / 关闭变化，正式 driver 要绑定稳定 targetId 并在每次动作前解析实际目标，不能长期存一个数字索引。任务新建的 tab 可在收尾关闭；用户已有 tab 只在选定范围内操作并保留。现有登录态沿用当前浏览器，不复制到记忆或简报。

Computer Driver

使用 DesktopDriver 隔离操作系统差异。首版只选择实际部署环境可用的截图、鼠标与键盘驱动；启动时检查 capabilities 与可控桌面，缺失时返回 driver_unavailable，不伪造操作结果。模型需要支持图像输入。

class DesktopDriver(Protocol):
    async def capabilities(self) -> DriverCapabilities: ...
    async def observe(self, desktop_id) -> Observation: ...
    async def act(self, desktop_id, action, lease, cancel) -> ActionResult: ...
    async def release(self, desktop_id, lease): ...

# 坐标依赖当前截图尺寸、裁剪与缩放，禁止复用上一场景坐标
pixel = transform(normalizedPoint, screenshotBounds, deviceScale)
require(action.expectedSceneEpoch == latest_observation.sceneEpoch)

一次桌面只有一个控制租约。屏幕尺寸、缩放、焦点或窗口变化时更新 sceneEpoch；动作前不匹配就重新观察。不能在旧截图上连续盲点，也不能把整段长脚本当成可随时中断的单次操作。

暂停、接管与资源归属

  • 用户接管：先暂停 Agent 输入动作，确认当前有界动作结束，释放控制租约；之后需要恢复时重新观察。
  • 任务取消：停止模型与动作队列，确认当前工具动作停止；桌面租约过期不能让第二个 Agent 在旧控制者未停时直接开始。
  • 共享浏览器或桌面发生用户操作，验证不满足时返回 scene_changed；继续前重新观察，避免与人争抢。
  • 页面、文件和截图内容均是外部数据，不能覆盖系统指令或扩大任务范围。
  • Shell / HTTP 能可靠完成的步骤可由 Worker 选择更直接工具；Browser / Computer 是同一工具体系中的能力。

截图、录像与最终结果

图片存 artifact 并带 sha256、尺寸、来源资源与 taskId。模型只接当前必要画面；大图按当前目标裁剪并保留坐标变换，不能只压缩后沿用原始像素坐标。录像是可选证据，不默认常开；保留时间跟 artifact 策略走。

最终回报包含“做了什么、结果位置、验证证据、剩余阻塞”。例如导出任务检查文件存在、类型和时间范围后给用户文件链接；无法通过验收时回报具体阶段，由 Main 在原对话继续沟通。
