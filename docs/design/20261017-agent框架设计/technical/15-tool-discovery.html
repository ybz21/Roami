模型实际看到哪些工具

类别名字用途
基础read有界读取文件、Skill 正文和附件；图片走现有视觉投影，不只返回 Base64 字符串。
基础bash运行 Roami CLI 和工作区命令。CLI 采用 argv；显式 Shell 模式须绑定实际工作目录。
基础edit基于观察到的文件 hash 精确修改，冲突时拒绝覆盖。
基础write创建或原子写文件，保留源版本检查与变更回执。
发现tool_list统一列出 MCP、Skill 与 CLI，支持分类、关键词和分页，返回用途、版本、位置或命令用法。
编排delegate持久后台任务、Fork、预算、专业智能体派活及原 Main 回报。
交互ask_user真实缺失决策用选择题，纳入等待和恢复；已授权普通投递不重复确认。

Main 总计 7 个，不能宣称只有 4 个。原生编码 Worker 默认基础 4＋tool_list；检索 Worker 使用 read / bash / tool_list。角色目录由宿主配置，Skill 不授予新权限。Codex 等专业智能体保留原生工具集。

取消此前“exec / delegate / ask_user 三工具”提案：bash 是唯一通用命令执行入口，不再保留同义 exec。现有 session_send、web_research、target_search 等业务包装迁移为 CLI 能力与 Skill，不能在七工具之外继续默认挂载。

tool_list 输入与输出契约

tool_list({
  query?: string,                // 可选关键词；省略时列出该分类
  kind?: "all" | "mcp" | "skill" | "cli", // 默认 all
  limit?: integer,               // 默认 10，最多 20
  offset?: integer               // 默认 0
})
CapabilityList = {
  catalogVersion,
  items: [{
    id, kind, name, description,
    version?, location?,          // Skill：read(skill://NAME)
    argv?, inputSchema?, effect?  // CLI：bash(argv)，由运行时绑定上下文
  }],
  total, offset, nextOffset, totals: {mcp, skill, cli}, truncated
}

名称精确匹配优先，连字符与下划线归一，名称词权重高于描述。天气 / 联网等别名指向 web-research；capability_overview 只在明确查询自身时参与，不因描述提到已退休的 web_research 而误命中。指定 kind 没有对应入口时返回 suggestions 与 hint，指向真实 Skill 或 CLI，不伪造工具，也不要求原样重复搜索。搜索不调用生成模型，不读整份 Skill 正文，不执行命令；相同目录版本与查询返回稳定排序。结果按角色、节点、启用策略过滤，目录为空就返回空结果，不能臆造 CLI。

目录只返回已注册、启用且当前角色允许的条目；缺失能力不伪造执行入口。effect 和参数来自同一注册定义，执行时重新校验；检索角色的 browser_act schema 只暴露 goto。MCP 连接是否成功仍以实际调用结果为准。

已知且仍有效的命令可直接运行，无需每次先搜索。Main 对已知公开联网流程直接 delegate 原生 resourceOnly 任务，不先搜索或读取流程手册；研究 Worker 的三个已知浏览器 CLI 参数在工作指令中给出，只有陌生入口才搜索。模型阶段超时保留 MODEL_DEADLINE，其他回合超时标记 AGENT_TURN_DEADLINE，回报不再只剩 EXECUTION_FAILED。tool_list 搜索“怎么做”，项目 / 会话列表等业务数据通过对应 CLI 查询；它不是网页搜索，也不是用户记忆检索。

一次真实派活与一次网页检索

1. 找能力

tool_list 搜索“给项目里的 Codex 发消息”，得到派活 Skill 与真实 CLI。

2. 按需加载

read 对应 SKILL.md；读取 CLI 用法和参数，不加载所有技能。

3. 执行业务

bash 调 CLI 列项目下完整会话，唯一目标可靠提交；歧义才用 ask_user。

4. 实时回报

流式展示查询、投递与状态；已投递与任务完成分开。

网页读取、链接核对及联网问题：Main 直接 delegate 派 resourceOnly 原生检索 Worker，无需先搜已知 Skill。常用统计、目标查询、解析、投递的简短 CLI 契约随 Main 指令提供，已知操作直接执行；复杂流程再按需读 Skill。研究 Worker 同时收到用户原始问题和委派目标，原文界定事实范围，避免主 Agent 转述时改变问题。Worker 用 Chrome CLI，保留来源、采集时间、浏览器身份、租约与操作回执；无需创建代码项目或 Codex 会话。通用 delegate 必须先补资源专属 profile，才能删除 web_research 包装。

目录与执行用同一个事实来源

CLI 注册表 / 能力服务 ── 目录投影 ── tool_list
Skill 注册表（启用、角色、版本） ── 目录投影 ── tool_list
Skill 只读位置 / references ── read
已注册 CLI 路径与参数 ── bash ── 既有业务服务
任务协议 ── delegate ── 既有调度器
用户选项协议 ── ask_user ── 原主对话等待态

这是静态架构示意。CLI 元数据应随真实命令注册与版本发布，避免三份人工维护的帮助文本。目录版本与已加载 Skill 版本进入上下文 fingerprint；执行时重新校验禁用、参数、资源与版本。旧目录不能绕过禁用状态。

Memory、Task、MCP 等缺失 CLI 入口先补齐再迁移；MCP / HTTP / Computer Use 由 CLI 适配承接，不将所有端点或每个业务动作注册为常驻工具。详细现状与缺口见 23 工具处置清单。

记忆是自动机制，不依赖主动搜工具

1. 接收

明确“帮我记下”等请求按用户原文在接收事务落库，不等助手口头回复。

2. 后台提取

对话和任务事件自动触发；用户直接偏好需原文引用与来源校验后自动生效。

3. 自动召回

每轮注入当前对话 / 全局有效偏好和相关事实；去重、限量、按 token 预算。

4. 来源与遗忘

保存 memoryId、版本与原文来源；删除失效，彻底忘记追踪派生回复。

助手输出“记住了”不构成写入凭据。后台自动激活仅允许有可验证用户原文的直接偏好；模型推断、工具结果和助手转述不能自行升级为用户偏好。没有原文证据的候选仍保留待核实，不要求用户逐条确认所有记忆。

自动召回不依赖 tool_list，也不要求模型主动调 memory_search。按用户 / 对话范围过滤，有来源版本记录，注入历史数据而非系统指令；当前用户要求优先。每次最多 8 条、内容预算 2000 预估 tokens；这只是记忆注入预算，模型上下文容量仍来自模型本身。

自动记忆与执行授权独立；记住“优先 Codex”不代表自动放宽账号、资源或操作权限。偏好纠正需保留旧版本与冲突来源，不能由晚到的旧后台任务覆盖更新后的偏好。

能力管理：一个页面，四个顶部 Tab

设置入口统一为“能力管理”，地址 /settings/agent/capabilities。工具 Tab 只列 7 个模型入口及参数；内置项只读并固定启用；MCP Tab 列连接状态和详情，当前配置仍由节点管理；Skill Tab 提供卡片、Markdown 详情和预留上传；CLI Tab 按能力域列命令与操作详情。内置工具、Skill、CLI 均无编辑或启停入口，只有外部接入项允许启停；后端拒绝内置项修改，旧配置中的内置禁用项恢复启用。

旧 /settings/agent/tools 与 /settings/agent/skills 链接仍可打开对应 Tab。Roami Skill 逐项说明项目查询、完整会话分页、精确解析、已有会话投递、项目与散任务创建、Fork、状态、取消和回报，并提供参数与例子。Roami Skill 按项目与会话、Chrome、任务与提醒、记忆与外部能力、节点运维拆分参考手册；模型通过 skill://NAME/references/FILE.md 按需读取，引用版本参与目录 fingerprint，设置页可只读切换手册。标准 CLI 的完整用法与当前 Main / 研究角色开放范围分别说明，不把文档列出的命令当成自动扩权。连续过程条目默认折叠成一组，展开逐项查看时间、状态及输入 / 输出；详情由带 owner、对话和分支校验的只读接口按需获取，不加入每条 SSE 广播，长结果截断并标记，凭据字段和图片 Base64 隐去。散任务使用 directory 指定实际工作目录，baseDir 只用于 new_project 的父目录；任务接收及执行适配器拒绝混淆字段，不能静默退到默认工作区。验收核对真实工作区目录和指定接收端的原样消息，不只匹配回复标记。上传仍明确预留，不伪装为已完成安装。
