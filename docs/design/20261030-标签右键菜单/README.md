# 标签右键菜单稳定性

## 产品设计与用户故事

用户右键页面、会话或文件标签后，可以移入菜单完成固定、关闭及批量关闭操作。标签栏滚动不应提前关闭菜单；点击外部、按 Escape 或执行菜单动作后关闭。菜单沿用现有文案与样式，定位在右键位置。

## 技术设计

`TerminalPane` 的三类标签使用 `TabContextMenu`。组件显式管理打开状态，使用无自动触发器的 antd Dropdown，沿用文件菜单的受控交互模式。以视口内的固定坐标作为定位锚点，避免按指针定位的 rc-trigger 因祖先滚动而关闭菜单，也避免标签滚出视口时带走菜单。

菜单内部的 pointerdown 不关闭弹层；外部 pointerdown/contextmenu 和 Escape 关闭。执行菜单动作时阻止冒泡，保留现有业务回调、标签 ref、排序与脏文件确认逻辑。
