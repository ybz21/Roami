1. 空配置首页：模型、项目、引导进度均为空。
2. 认识模块：首页、项目、能力、文件、浏览器、手机、设置。
3. 配置模型：同一表单填写连接和模型，保存到统一目录。
4. 配置智能体：展示含 OpenCode、Pi 的完整列表；为 Roami 主 / 后台应用模型并验证，展开既有高级配置；Codex 从同一连接选模、应用并验证。

6. 首个任务：使用可编辑的只读示例，明确提交并进入真实会话。
7. 返回引导清单，四项均完成。
