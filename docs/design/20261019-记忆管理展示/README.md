# 记忆管理展示与能力入口排序

2026-10-19。用户指出统一记忆页以日期、计数和删除按钮为主，看不出实际记住的内容；同时要求能力页按 Skill、CLI、MCP、工具排列。

- [HTML 设计说明](index.html)
- [实际验证记录](validation.json)

默认进入「记忆内容」，展示偏好、事实、决定和工作结论；「每日足迹」按日期归组、按项目呈现六项活动计数。二者使用服务端分类后再计数和分页，不把每日统计从当前页简单隐藏，也不修改已有记忆的召回范围、有效期或自动保存机制。

内容卡片按类型 / 状态、主题、正文、适用范围、更新时间与来源组织。正文默认预览，支持展开；来源仍可定位原始消息。删除和彻底忘记收进更多菜单，彻底忘记保留现有确认。候选确认 / 拒绝、搜索、项目 / 对话 / 任务筛选、分页及失败重试继续保留。未知的旧计数显示「未记录」，不填成零。

每日足迹可以跨日期浏览，选择日期时沿用服务端时区聚合，也可选今天 / 所有日期。日期标题每组只出现一次，项目名称优先于 ID。桌面使用按可用宽度自适应的卡片网格，手机一列，来源、展开与更多操作保留真实触控命中区。

能力页顺序为 Skill → CLI → MCP → 工具，默认进入 Skill；已有指向具体分类的旧链接仍打开原分类。内置能力仍只读，外部能力的既有启停规则保持。

接口只在 `/agent/memories/catalog` 增加可选 `category=all|knowledge|activity`；默认 all 兼容旧调用。分类在数据库查询、总数及分页之前生效，活动记录按日期倒序排列。没有数据库迁移，不重写或删除历史数据。

实际验证使用隔离实例，通过真实 API 写入带来源的测试记忆。桌面、Redmi Note 8 真机验证内容 / 足迹切换、搜索、查看原始来源、更多菜单及四项底栏；未操作生产记忆。活动计数是验收种子数据，不是实际生产使用量。样式使用现有设计令牌，新增固定产品文案均接入中英文；本文为开发者文档的 i18n 例外。
