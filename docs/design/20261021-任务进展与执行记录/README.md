# 任务进展与执行记录

关联 #390、#391、#392。

- 主会话显示根任务短主题、服务端状态和详情入口；子任务内部工具步骤、路由解释和内部 ID 放入按需执行记录。保留主会话失败，以及子任务待用户处理或未知结果的必要提示。已恢复的工具失败不作为任务当前告警；未知副作用不冒充已恢复。
- 任务详情的执行记录按需请求同一任务树的活动；参数和输出展开才取，继续执行 owner、分支、已遗忘内容与脱敏校验。完整链路使用现有 task 目标跳转。快照和 SSE 同用展示投影，底层历史保留。
- 已结束任务（成功、失败、取消、中断）不再轮询，包括其资源和文件接口；有未确认控制权时显示核对动作。活跃任务共享请求、隐藏暂停、失败退避。任务事件、重新进入、返回前台和主动操作触发读取，续作后按新状态恢复活跃更新。
- 详情保留现有 revision/run/controlFence；缓存可用于首屏，控制按钮必须等当前读取确认。跨节点/用户隔离，离开后的旧响应不得更新当前任务。

自查：不删除执行记录，不修改实际任务状态，不增加模型请求，不用工具次数推断任务进度。终态停止定时请求是用户明确要求；未知资源改为事件或用户核对，不以资源未释放为由继续轮询。任务详情获取活动应独立于主会话 200 条显示窗口，历史/外部任务保留可读回报。

验证：成功/失败/未知/待用户处理、多层子任务、旧错误恢复、状态事件、续作、终态 60 秒零周期请求、错误退避、节点切换及控制栅栏；全仓门禁、桌面与真实 Android 导航/滚动/展开及截图。

## 子智能体会话与干预

详情保持名称、三行具体内容、默认折叠的下发指令、成果和当前操作。执行记录展开后提供「过程 / 会话 / 回报」；native 默认过程，外部执行器默认回报。会话仅 native 可用，可选择当前或历史执行轮次；过程展示当前任务树，完整历史用链路定位。

| 用户动作 | 行为 |
| --- | --- |
| 查看过程 | 按需读取本任务树的工具与子任务活动；展开某步才读脱敏输入输出 |
| 查看会话 | 只读取当前任务绑定的 native branch；历史轮次只读，不创建额外聊天输入框 |
| 补充要求 / 回答子智能体问题 | 复用 task.steer，绑定任务 revision 和幂等请求，先确认旧执行停止，再继续；界面保留待应用状态 |
| 停止 | 复用 task.cancel，停止确认前不显示已停止 |
| 继续 / 验收 / 交还控制 | 保留现有 revision、run 与 controlFence 条件 |
| 已结束后核对 | 用户主动核对或收到事件才读，不恢复定时轮询 |

会话接口由 taskId/runId 解析绑定分支，不接受任意会话或分支地址；校验任务与会话归属、run 与 task 的绑定、已删除/遗忘来源。UI 展示用户/助手消息与附件，工具输出在过程页查看，不泄露系统指令。跨节点文件链接使用当前源节点。子智能体提问的回答同样走任务干预，不能绕过版本控制直接提交 worker 消息。

评审结论：可复用现有取消/续作/接管链路；新增部分仅为任务范围读取与展示，不增加第二套执行状态或直接发送协议。重点补测历史 run 越权、已删除来源、并发干预、未应用要求、草稿保留、终态无轮询及手机页内导航。

干预输入放在执行记录后，查看完会话即可补充；只保留一个输入框。停止入口仍在任务当前操作区。

轮次隔离：native 续作复用 branch，因此用 task.started/preparing 的 runId→turnId 绑定读取；不能仅按 branch 查询。历史会话不包含后续轮次，当前工具活动不包含旧轮次错误。

草稿按节点和任务保存；查看链路返回仍保留，接受下发后才清空。切换节点的详情重新挂载，旧操作结果不能清掉新节点草稿或重新启用控制。
