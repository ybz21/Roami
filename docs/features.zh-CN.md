“需配置”表示需要对应软件、设备、账号或模型服务；实验性能力单独标明。

## 1. 远程接入与跨设备工作

- 从电脑、平板和手机浏览器访问自托管 Web 控制台。
- 从 Android 原生 App 接入同一台服务，或将网站安装为主屏 Web App。
- 手机、电脑共享开发机上的项目、任务、文件和会话；客户端断开后宿主机任务继续运行。
- 主题、语言、快捷命令和工作区偏好持久保存；不同节点的会话与工作区可分别恢复。
- 桌面导航、项目会话树、工作区标签、可调分栏、文件/Git 检查器与终端工作区。
- 手机四个主入口：首页、项目、工具、设置；消息、任务和记忆使用二级页面。
- 适配软键盘、安全区、触控命中区、手机返回导航与下拉刷新。
- 默认 HTTPS、自签 CA 下载与安装引导；可配合现有 VPN、HTTPS 反向代理或隧道远程访问。

实现入口：[应用路由](../frontend/src/app/AppRoutes.tsx)、[导航](../frontend/src/app/navigation.ts)、[手机安装](deploy/mobile.md)。

## 2. 掌控专业编程 Agent

| Agent | 当前能力 |
|---|---|
| Claude Code | 安装发现、版本检查、安装/升级、启动命令、模型配置、额度信息、持久终端、对话阅读与编程任务委派 |
| Codex | 安装发现、版本检查、安装/升级、启动命令、模型配置、可获得的额度信息、持久终端、对话阅读与编程任务委派 |
| OpenCode | 安装发现、版本检查、安装/升级、启动命令、模型配置、持久终端与支持的对话阅读 |
| Pi | 安装发现、版本检查、安装/升级、启动命令、模型配置与持久终端 |

- 从能力中心统一进入 Agent 管理，查看实际安装版本、程序位置与可确认的登录状态。
- 打开终端完成各 CLI 的登录、交互和模型选择。
- 保存并应用模型服务预设，管理凭证引用与可用配置的恢复。
- 从任意客户端查看输出、追加指令、发送确认按键并接管终端。
- 识别受支持 Agent 的运行、空闲和待确认状态；展示可以可靠取得的上下文、耗时或额度信息。
- 对话阅读支持消息、代码、Markdown、diff、工具过程折叠、复制与文件引用。
- 保留原始 TUI；具体登录、额度和对话解析随 CLI 版本、服务商与已取得的证据显示。

实现入口：[Agent 目录](../frontend/src/components/capabilities/AgentCatalog.tsx)、[安装与版本](../internal/agentinventory/)、[对话组件](../frontend/src/components/chat/)。

## 4. 任务、执行与交付

- 从自然语言或项目入口发起任务，选择已有项目、会话或新的工作目录。
- 按任务目标选择内置执行或受支持的专业编程 Agent，保留任务身份和来源对话。
- 父子任务、排队与并发执行、依赖工作、任务版本与后续修订。
- 在任务详情中追加要求、继续工作、取消执行、验收与查看验证状态。
- 在原有专业会话中持续跟进任务，保留终端、工作区与上下文关联。
- 查看准备、排队、运行、等待用户、验证、成功、失败、中断和取消等真实状态。
- 将任务结果、用户待决事项与执行器报告分别记录，保留可检查的产物和结果证据。
- 产物预览、下载、原始文件来源、执行尝试和错误详情。
- 查看任务占用的浏览器等资源，暂停、恢复或接管受支持资源。
- 中断与重启恢复、幂等提交、执行状态核对和不确定结果记录。
- 工具、任务和模型调用的执行记录、耗时、用量与关联链路查询。

实现入口：[任务界面](../frontend/src/components/agent/AgentTasks.tsx)、[运行时](../agent-runtime/README.md)、[执行 CLI](../cmd/roami/agent-execution.go)。

- 手动保存记忆，后台提取候选，确认或拒绝候选内容。
- 编辑记忆、查看版本和来源、遗忘与撤回来源影响。
- 按日期聚合的工作活动与摘要，使用配置的时区组织每日记录。
- 处理重复偏好和来源有效性，检索时保留范围与来源约束。
- 在设置与首页工作台中管理记忆，手机使用完整二级页。

## 7. Git、Worktree 与竞赛

- 工作区状态、文件差异、暂存/取消暂存、放弃改动、提交与提交详情。
- push、pull、fetch、同步和远端分支信息。
- 分支、标签、stash 与提交图；支持已有的切换、合并、变基、回退等 Git 操作。
- 创建、列出和比较 worktree，查看相对基线的已提交与未提交差异。
- 会话与 worktree 关联、派生子会话、在新 worktree 中派生工作。
- 合并回基线、收尾、移除、残留清理和占用/未提交改动检查。
- 通过已有 `gh` 环境读取分支对应的 PR 信息（需 GitHub CLI 与登录）。
- 多个 Agent 在独立 worktree 竞赛同一任务，选择结果、合并与清理。

实现入口：[Git API](../backend/api/git.go)、[Worktree API](../backend/api/worktree.go)、[竞赛](../backend/api/race.go)。

## 14. Android 原生 App 与主屏 Web App

- Android 8.0+ APK，随服务端 Release 提供固定签名的分发附件。
- 保存多个服务地址，启动进入已选环境，摇一摇返回环境选择。
- WebView 加载同一套最新工作台，保持原生状态栏、安全区与键盘适配。
- 自签服务器证书确认与后续信任记录。
- 文件选择、上传、下载、按需麦克风授权。
- 前台服务长连接接收会话、任务和助手通知，不依赖 Google 推送服务。
- 支持的会话确认可在通知栏选择允许/拒绝。
- 桌面小组件展示运行会话和待处理事项，支持查看、发任务与进入会话；应用角标随状态更新。
- 从服务器安装页下载 APK 并调用系统安装器升级；APK 与服务端版本分别管理。
- Android/iOS 主屏 Web App、Web Push 配置与安装引导。
- Service Worker 保留部分最近内容供断网回看，包括通知、会话/项目概览和最近对话。

通知、角标和 Web Push 依赖设备权限、系统设置与网络。Android App 是远程客户端；设备镜像是独立功能。

实现入口：[Android 工程](../mobile/android/)、[手机安装指南](deploy/mobile.md)。

## 19. 设置、安全与运行管理

- 设置搜索、分组、主题、语言、密度、快捷键、状态栏与快捷命令。
- 内置助手模型、记忆、消息、专业 Agent、浏览器、设备和语音服务配置。
- 语音录音与转写，支持已有豆包/火山和兼容接口配置。
- 环境变量管理、同步预览与会话环境推送。
- 首次设置口令、修改口令、可选 TOTP 两步验证和登录失败锁定。

- Linux/macOS 的 x86-64/ARM64 完整运行包、独立 Python 与生产依赖。
- Linux systemd / macOS launchd 常驻服务、升级检测、运行时监督与空闲升级协调。
- 统一数据库状态、备份、恢复、布局迁移与恢复流程，覆盖受管理的运行时数据与产物。

实现入口：[设置](../frontend/src/components/settings/)、[安装器](../install.sh)、[存储 CLI](../cmd/roami/)。

## 20. CLI 与自动化接口

| 入口 | 能力范围 |
|---|---|
| `roami server` | 控制台服务、地址、前端与 TLS 启动配置 |
| `roami session` | 会话、窗口/窗格、屏幕、输入、历史、父子关系、蜂群和环境 |
| `roami project` | 项目列表、详情、创建、偏好、会话、活动与登记移除 |
| `roami agent` | 对话、消息、任务、执行、产物回报、提醒、记忆、通知、能力与链路 |
| `roami chrome` | 浏览器导航、观察、交互、截图、PDF、录屏与页面生命周期 |
| `roami adb` | 将操作转发给宿主 ADB |
| `roami plugin` / `roami <插件名>` | 插件安装、开发、配置、命令、状态与审计 |
| `roami auth` | CLI 登录、登出与身份状态 |
| `roami db` | 数据库状态、备份、恢复与迁移 |
| `roami help` / `version` / `completion` | 命令发现、版本与 Shell 补全 |

实现入口：[统一 CLI](../cmd/roami/cli.go)、[会话命令](../internal/cli/)。

## 21. 条件性与实验性能力

- **Linux X11 Computer Use**：已有基于屏幕观察、点击、按键与输入的桌面适配器；需要相应运行时开关、X11 环境和支持图片的 Worker 模型。
- **iOS 设备/模拟器镜像适配**：已有 macOS `simctl`/`idb` 后端代码；源码明确保留真 Mac/设备联调要求，作为实验性能力列出。
- **模型图片输入、浏览器/桌面观察、P2P 与设备操作**：按服务商能力、配置和宿主环境启用，界面显示实际可用状态。

依据：[Computer Use](../agent-runtime/README.md)、[iOS 适配器](../backend/phone/ios.go)。
