读取 connectors/ 下的 Skill 与来源定义。记录日期、单位、账号和证据。未接通来源保持未知；通过受支持的项目操作发布，不覆盖确认指针。


采集前对照确认的 metrics、dashboard 定义与实际 HTML。用户要求的字段若尚未定义，交 Main 补充匹配名称、单位、账号/稿件和窗口的指标，并确认看板引用；不得把播放量写进完播率等其他指标。数据成员保留原始证据、采集时间和平台截至时间，Main 独立核验后通过当前修订的 record 操作入库，随后检查确认观测、数据接口与实际卡片。只保存候选文件不等于看板更新；无法取得的值不填 0。
