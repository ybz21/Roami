# OKR 操作手册

AGENTS.md 是职责和规则入口；这些手册说明实际操作。先读取当前项目上下文与宿主能力，命令以已安装 CLI 的 help 和返回协议为准。确认定义、执行取数、发布数据、任务验收和启用排期是不同操作，分别检查回执。

| 要做什么 | 阅读 | 完成的依据 |
| --- | --- | --- |
| 新增或调整卡片、字段、图表 | [看板编辑](dashboard.md) | 确认定义、数据接口及实际页面一致 |
| 取数、保存数字、排查空白卡片 | [取数与入库](data.md) | 来源证据和确认观测，不是聊天声明 |
| 群聊、派工、续派、记忆和验收 | [团队协作](team.md) | 原实例处理、产物与 Main 独立验收 |
| 个人/团队记忆、周/月/年归档 | [记忆](memory.md) | 有来源的长期结论与周期索引 |
| Skill 选择、编写和经验回提 | [Skill](skills.md) | 实际版本、验证与下一轮结果 |
| 自动审核、发布、取数与未知结果对账 | [自动运行](automation.md) | 当前审核版本、平台回执、确认批次与连续下一轮 |
| 每日开工、复盘、定时和故障恢复 | [日常运行](daily.md) | 当前轮次结果与真实日程运行记录 |

项目根目录是工作区；.roami/okr 放机制定义、记忆与确认数据。materials/YYYY-MM-DD/<渠道或工作类型>/<简短主题>/ 放新交付、原始证据与发布回执；任务和运行身份写入清单，旧文件保留并用索引引用。不得把密钥或登录态放进手册、记忆和交付文件。

发布通道与历史流程见[发布操作](publishing.md)。先核对已走通的路径与当前限制，再判断能力缺口。
