# OKR package

Definitions: okr.json and dashboard.json. Custom HTML lives in dashboard/.
Connector Skills: connectors/<name>/SKILL.md with scripts/references.
Coordinator and desired team: agents/. Real identities come from host receipts.
Working knowledge: memory/team.md; important decisions: memory/decisions.md.
Data/evidence/state are published by the host, never invented by the template.
Schedules start disabled and need supported registration plus a real nextDue.
Project workflow instructions are in AGENTS.md in this directory.
