# Confirmed MCP source binding

Before collection, record the actual connection/account, tool and effect/schema,
resource identity, metric IDs, response field mapping, unit, measurement window
and evidence requirements. These values come from discovery and user/project
context, never from a guessed tool name or a template credential.

Unknown effects are not read-only. Retain the existing authorization boundary.
No successful result means unknown; preserve the previous valid snapshot.
