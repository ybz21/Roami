场景规范

产品设计 · 展示与触发规则

本稿先确定内容层级、状态与交互。手机框中的背景仅表示用户正在使用其他应用；胶囊和展开卡片是交互示意，不是 OPPO 系统截图。ColorOS 16／17 的字体、圆角、动画和最终尺寸需以真机为准。

场景收起的胶囊展开后的重点消失时机
完成，可直接测试已完成任务名、做了什么、验证结果、可打开的交付物收起状态展示约 15 秒；点开阅读期间暂停计时
一般完成已完成短结果，不放整段聊天；有未验证部分就明确写出约 15 秒，完整记录保留在对应任务
需要授权待确认要执行什么、影响范围、真实授权选项收到提交成功的反馈，或问题已经失效
单选／多选待选择完整问题、全部选项；多选显示已选数量并明确提交成功提交后；不因点开或收起而清除
需要补充信息待补充缺少什么、简短说明、可填写内容或进入对应聊天信息提交成功后
出错且需要人工处理需处理可读原因、为什么无法继续、下一步动作用户知晓、任务恢复或问题解决；稍后处理不等于修复
并发提醒3项待办按任务分行，点哪项就处理哪项，不把问题拼成一段逐项处理，数量随之减少
执行中、工具重试、短暂断网不出现留在后台执行；只有确实停住并需要人时才升级提醒无任务胶囊

统一内容层级

  1. 胶囊：图标加 2—5 字状态。只显示短状态；任务名与摘要留到展开后。状态文字不换行，不显示分支、进程名或内部编号。
  2. 展开卡片：状态、短任务名、结果或完整问题、必要上下文、当前能做的动作。来源放到次要位置，不占用主标题。
  3. 完成摘要：优先“做了什么＋验证情况＋交付物”。不能把“这一轮回复结束”直接解释成整个项目成功；失败、取消、未验证与完成分别呈现。
  4. 确认选项：不把所有问题都压成允许／拒绝。用真实选项文字；长选项可以换行，不隐藏含义。
  5. 内容清理：去除 Markdown 标记和控制字符，保留正文含义；日志、堆栈和长代码留在对应任务详情。

两条点击路径

点明确的选项、提交或确认按钮：在后台完成该次操作，不把用户带离当前应用。点标题、正文及卡片其他非交互区域：进入同一服务器、同一任务的聊天界面。单击胶囊先展开，不依赖双击手势进入任务。收起只是收起，不能视为已确认。

并发与失败

优先级为待确认／待补充、需要人工处理的错误、完成提醒；同级按到达顺序。任务 A 的点击不能处理任务 B。提交中防止重复点击；网络失败保留原问题与选择；旧问题返回“问题已更新”，不盲发回车到下一题。重连补回未收到的状态，但不弹出一串过期问题。

锁屏与免打扰

锁屏默认只显示任务名和状态，隐藏代码、命令、问题正文与选项，解锁后处理。尊重系统免打扰和用户关闭提醒的选择，不强制点亮屏幕、不主动展开大卡片。

用户故事 · 这套提醒要解决什么
  1. 我正在其他应用里做事，任务完成后只看到一个短胶囊；我决定什么时候点开，不被大卡片打断。
  2. 我点开后能知道哪个任务、做了什么、是否验证过；有页面交付时可以去测试。
  3. 遇到授权或选择，我能看到完整问题和真实选项；不需要为简单决定先找回会话。
  4. 我想读更多上下文时，点正文直接进入当前任务聊天，不返回首页重新寻找。
  5. 几个任务同时有消息时，能逐个处理；确认一项后不会误清掉另外一项。
  6. 任务只是执行中或正在自动重试，不一直占着状态栏。真正卡住时，才告诉我需要补什么或处理什么。
技术设计 · 交互目标与原生能力

“目标交互”用于评审完整选项、卡片内多选与输入的体验，不能据此认定当前 APK 或 ColorOS 原生卡片已经支持这些控件。“当前原生方案”预览使用短标题、正文和有限操作按钮；多选与信息输入进入对应聊天处理。

内容目标当前接入情况／实施条件
胶囊、展开、正文直达聊天在其他应用里查看与进入对应任务已接入 Android 实时更新；用户已确认 OPPO 显示。最终外观由系统绘制。
少量选择真实选项直接提交已有结构化 prompt／choices 和过期问题校验；需逐类真机检查按钮与提交。
超过三个选项全部选项都可读，也可直接选择标准通知最多三个操作按钮，正文保留完整列表；当前快捷操作为前两项加“更多选项”，其余进入对应聊天。完整选项控件不是当前原生模板能力。
多选勾选多个选项后统一提交本稿交互目标；需验证 OPPO 允许的交互模板，否则在对应聊天完成。不能用自定义 RemoteViews 冒充标准实时更新模板。
直接输入不离开当前应用补充简短信息Android 提供 RemoteInput；Roami 尚未接入本稿的输入提交与旧问题校验，OPPO 胶囊内呈现仍待验证。
交付物测试入口、批量汇总能直接打开页面，逐项处理提醒为后续实现项；当前已有每任务通知、胶囊优先级和会话跳转，不等同于已完成此处的汇总卡片。
锁屏隐藏敏感内容只显示安全摘要，解锁后处理后续验收项；需配置通知可见性及公开版本，验证系统锁屏行为。

数据与模块

Agent 真实事件
  → attention 分类：done / approval / choice / input / blocked
  → 内容模型：taskId、session、server、title、summary、question
               choices、selectionMode、artifacts、verification
               promptVersion、occurredAt、sensitive
  → TaskCapsuleState：优先级、并发、去重、超时、断线恢复
  → TaskNotification：原生字段、动作、对应任务的 PendingIntent
  → ActionReceiver：核对问题版本、提交、等待结果、失败保留
  → WebActivity：对应任务聊天或明确交付物入口

真实多选与输入必须先具备相应的 Agent 结构化协议，不能仅从终端文本猜测按键。此稿全部使用本页内存状态；不会连接 API、改写真实任务、请求系统权限或保存登录信息。中文为开发者设计文档和示例任务内容，不是新增产品界面文案。

系统限制与参考

Android 标准通知支持最多三个操作按钮，并提供直接回复接口；实时更新要求使用支持的标准样式，不能设置自定义内容视图。OEM 可增加展示条件。Android 通知操作与直接回复 · Android 实时更新规范。

Android 官方建议已结束事件使用普通通知；“完成后短暂显示胶囊”是本项目已在 OPPO 验证到的产品体验，不保证所有 Android 或 ColorOS 版本都一样。OPPO 专有模板和系统接入仍需按官方要求另行验证，HTML 效果不构成系统展示保证。
