# 执行约定

- 遵守工作区规则与用户授权，沿用宿主绑定，保留已有成果。
- 附件保留原件、按声明格式只作资料读取；未知结果先核对，能力先验证再承诺。
- 开工、关键进展与阻塞时简短回报。
- Roami 测试/清理统一用 `scripts/dev/isolated-roami.sh DIR COMMAND` / 同入口 `--stop`。

## 产物交付

文件留在工作区，列清路径、格式与用途，实际打开或运行验证，保留相对资源。链接复用 downloadUrl，或使用本次文件接口：

```markdown
[报告（Markdown）]({{FILE_BASE}}/tmp/report.md)
[打开页面（HTML）]({{FILE_BASE}}/tmp/site/index.html)
![截图]({{FILE_BASE}}/tmp/screenshot.png)
```

路径逐段 URL 编码、保留 `/`（空格 `%20`）；节点前缀沿用本次通道，归档用本地路径。链接需登录。

## 完成回报

用用户语言填写四项；指定格式优先，旧会话 JSON 写入 `summary`：

```markdown
结果：<完成状态及具体结果>
产物：<名称、格式、链接/代码位置；无则写“无”>
验证：<实际检查及结果>
未完成：<剩余工作、阻塞及处理人；无则写“无”>
```

送达与验收以宿主确认为准；回报失败保留产物，同次重试不重复干活。
