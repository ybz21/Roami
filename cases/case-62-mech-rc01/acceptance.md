# 验收合同

1. Go 的真实响应编号与同一临时账本一致；上游不能覆盖此编号。
2. 401/403/503 与成功响应均保留安全编号和原 HTTP 状态，错误正文不读取。
3. 只有私有桥可传递宿主回执及用量标记；未知字段、非法编号或伪造服务元数据不能变成可信用量。
4. 503、503、200 的脚本化序列必须显示三次宿主请求；未知重试用量保留未知，已观测成功的 11 Token 保留为已知下界。
5. 连接中断、非法用量或缺少回执不能伪造完整用量；实际 Agent 失败 trace 中能找到 Go 编号。
6. Go 指定根测试实际通过，Python 指定 25 项全部执行通过，零跳过/xfail；实现 SHA 保持，隔离实例清理成功。

通过只证明这份协议回归，不证明上游鉴权恢复、原生任务质量通过或正式观察完成。
