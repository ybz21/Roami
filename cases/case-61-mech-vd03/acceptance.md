# 验收

Go 与 Python 两组断言必须全部通过，原始输出与退出码保存在运行目录。任一依赖缺失、执行失败或脚本异常不能标为通过。

1. 大 Read 成功和失败回调都能结束对应工具；错误 JSON、过大的保留元数据、额外 JSON 对象仍拒绝。
2. 只有同一会话和请求的 Stop/idle 能生成正式完成回执；单有文本或文件不能生成 result.json。
3. 从稳定的本地提供方转录中读取回报，严格绑定原请求与工作区；后续用户请求、其他会话、侧链、目录越界或不完整记录不进入回报。
4. 未完成轮次已有的明确回报文件可冻结、预览和下载，保留 provisional 标记；state、result、finished_ms 不伪造，不能触发验收或重新派活。
5. 相对路径按回报目录处理，文件必须仍在原工作区内；不扫描无关文件。重复读取不重复写事件或产物，删除后不复活，其他用户不可读取。
6. 现有正式套件和历史成绩不变。此 Case 的通过只证明上述机制，不代表真实模型质量或两天观察完成。
