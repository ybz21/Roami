# 验收

实际生成可编辑输入，调用外挂 CLI 检查并另存。源文件、未改部件、字体与对象范围保持；并发哈希冲突、无效批次、未知颜色、越界路径不发布，发布后未知状态不重放。

严格执行 79 项独立包测试（含迁移的读取与位置回归）与 1 项真实 NativeExecutor 合同：完整 Skill 包经既有导入读取，Worker 通过普通 bash 执行并明确报告输出链接，已有交付机制保留可下载文件。安装前后基础工具目录与 schema 相同。80 项必须全通过、0 跳过/xfail；实现与输入哈希不变，实例清理成功。不把此确定性合同算成模型自主质量。

单页检查返回原文件哈希、总页数与目标页完整对象/调色板，其他页不混入结果；无效页号不写文件。完整读取兼容，真实NativeExecutor也使用单页检查。多页数据见input/focused-slides.json。

文本替换使用公开合成输入 `input/text-replacement.json`，CLI 跨两个格式片段替换中文及 XML 字符。检查删除、精确匹配次数、多段落与顺序编辑；字段、换行、未知节点、非法文字和失败批次不发布。新文字继承首个匹配片段格式，其余字体、对齐、对象和部件保持。完整包导入交付合同同时执行文本与对齐，原生 PPTX 可重新打开。
