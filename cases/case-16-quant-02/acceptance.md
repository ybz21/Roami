# 验收与可见范围

- 训练 `[0,100)`、验证 `[100,140)`、测试 `[140,180)`；固定三组候选参数。
- 各段分别重置 10000 现金与指标历史；收盘产生信号，下一 bar 开盘成交，费用与滑点各为 0.001。
- 按验证段期末净值选择；平局按 fast、slow 升序。选定后只评估该参数的测试段，不记录未选参数的测试分数。
- 交付 `analysis.py`、`result.json`、`report.md`、`selection-log.json`；实际运行还会明确 JSON 字段合同。
- 宿主判定器独立重跑代码、检查输入未被修改、核对数值及选择记录；参考答案不放进 Agent 工作区。
- `inputs/prices.json` 是公开合成输入，不含当次 receipt。冻结套件时追加 receipt，完整输入及 SHA 随该次套件保存，历史套件不覆盖。
- `tools.json` 是工具需求说明，运行时实际权限由执行器配置和原始执行记录确认，不因文件声明而扩大权限。

这是合成工程任务，不是实际行情回测，也不是交易收益或投研能力证明。
