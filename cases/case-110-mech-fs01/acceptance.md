# 验收

22项无跳过：16项新增、6项既有启动取消检查。三类失败分别在轮次失败记录前/后收到一次或两次取消，原错误记录必须保存，旧轮次不滞留running。

确定已停止的失败可完成取消并应用用户续跑；工作区结果未知或工具写入未知必须保持unknown/interrupted并阻断续跑。模拟工具通过真实ToolGateway记录未知写入，不执行实际外部操作。

无取消的OSError、TimeoutError、预检错误保持原分类，关机取消保留失败及待验证工作供恢复。既有启动取消与无依据结果保护保持。

输入及实现前后冻结。机制通过不表示原CLI偶发超时根因已证实，不替代实模语义或多媒体质量，不更新正式成绩、人工标签或节点配置。
