# 验收

必须完整执行input/conversations.json中全部对话，每轮在下一轮输入前读回真实Runtime的持久化状态：任务数量、持续身份、revision、执行器/项目、要求、输入附件、当前attempt唯一性及澄清状态。只聊天/查状态不能产生新任务；独立新任务不能合并；原任务追加不能换任务或混入其他要求。

fixture模式消费公开脚本，验证设施与状态机，不计语义能力。saved-model模式绝不向模型传expect或fixture，只使用真实用户轮次及正常Runtime上下文；沿节点保存Main路由、参数、能力和Go金额准入，未知用量立刻停批，不重试未知调用。禁止shell、MCP、浏览器或真实会话写入，后台任务结果均为显式合成检查点。

失败、不完整或未测对话不计通过。receipt保留逐轮失败码和实际用量；完整源码与输入SHA256冻结前后须一致。不能把任务存在当成实际交付、把机制回归当真实模型收益或称为最佳对话的主观评分。

任务身份使用持久化来源和持续ID，允许目标文字合理改写；同轮多个新任务用短标题区分。数值及明确字段忽略空白、冒号、引用符，不忽略小数点；JSON、项目、修订和附件严格比较。“不发通知/不部署”核对原始约束来源保留，不用同义措辞判丢失，不宣称验证了真实后台执行是否遵守。
