# 验收

原有 Skill 版本与引用边界检查继续执行。新增自动文稿输入变体由 [materials.json](materials.json) 注册，实际数据由列出的测试构造 PPTX；工具及执行环境见 [tools.json](tools.json)。不依赖真实模型或判定器答案。

1. 真实 NativeExecutor 准备任务时，显式工具调用已被同一执行策略拒绝，自动准备也必须遵守：禁止文件读取时不读取、不注入内容；仅禁止 Skill 时保留允许的文档数据但不注入工作流。
2. 首次 Worker 请求之后替换策略集合，下一次请求不得继续注入已禁用的内容或工作流。已经发出的历史请求不声称撤回。
3. 文件读取 await 期间改变策略，只允许已开始的读取结束；不得继续读取下一个文件或发布先前缓存。重新允许后，同一 intake 实例可恢复准备。
4. 新变体必须实际收集并通过 10 项参数化测试，无跳过；原机制 Case 的严格收集回执继续生效。

这验证能力策略执行，不证明 PPTX、音视频或股票任务质量已通过，不更新历史正式 60 项。

读取及流程必须由显式通用工具请求触发；文件后缀不触发自动读取或上下文注入。策略在调用时生效，旧回执保留为历史，不能绕过当前禁用。原 PPTX 自动准备变体已由通用输入/Skill 策略变体替代，当前规范通过新回执验证，不回填历史分数。
